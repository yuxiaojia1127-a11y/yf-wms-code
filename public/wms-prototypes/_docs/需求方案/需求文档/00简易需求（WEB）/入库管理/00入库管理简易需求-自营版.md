# 入库管理简易需求（自营版）

## 1. 基本信息

- 功能名称：入库管理
- 所属系统：WMS_WEB端 / WMS_APP端
- 页面编号：`WMS-WEB-IN01`
- 所属模块：入库管理
- 文档定位：自营业务版
- 适用范围：采购入库、退货入库、调拨入库、收货、质检、上架、入库差异与入库流水

## 2. 核心结论

### 2.1 WMS管理对象

| 对象 | 主键/编码 | 管理口径 | 作用 |
| --- | --- | --- | --- |
| 入库单 | 入库单号 | 入库业务主单 | 承接采购、退货、调拨等入库来源 |
| 入库明细 | 入库单号 + SKU | 入库商品明细 | 记录应收数量、实收数量、差异数量 |
| 收货任务 | 收货任务号 | 到货收货作业 | 支持扫码收货、数量确认、差异登记 |
| 质检任务 | 质检任务号 | 质量确认作业 | 支持正品、次品、拒收、待处理结果 |
| 上架任务 | 上架任务号 | 入库落位作业 | 将已收/已检商品上架到货位 |
| 入库差异 | 差异单号 | 入库异常记录 | 记录少收、多收、错品、破损、效期异常等 |
| 入库流水 | 入库单号 + 库存动作 | 库存增加记录 | 记录库存增加、待检、冻结、上架等动作 |

### 2.2 核心规则

1. 自营入库类型包括采购入库、退货入库、调拨入库。
2. 入库单是入库业务主对象，收货、质检、上架围绕入库单执行。
3. 采购入库来源于采购单或供应商到货通知。
4. 退货入库来源于售后退货、拒收退回或线下退货任务。
5. 调拨入库来源于调拨单的调入仓到货。
6. 入库收货按SKU、条码、批次、效期、SN和数量校验。
7. 收货完成后进入待质检或待上架状态。
8. 上架完成后增加实物库存并生成库存流水。
9. 入库差异必须记录差异类型、差异数量、原因和处理结果。

## 3. 业务目标

入库管理用于处理自营业务商品进入仓库的全流程，包括入库单创建、到货收货、质检确认、上架落位、差异登记、库存入账和入库记录追溯。

系统通过入库单、收货任务、质检任务、上架任务和入库流水，保证采购、退货、调拨等入库业务的实物、单据和库存一致。

## 5. 入库类型

| 入库类型 | 来源单据 | 典型场景 | 关键动作 |
| --- | --- | --- | --- |
| 采购入库 | 采购单 / 到货通知 | 自营采购商品到仓 | 收货、质检、上架、库存入账 |
| 退货入库 | 退货单 / 售后单 / 拒收退回单 | 消费者退货、拒收退回、线下退货 | 收货、质检、返架、次品处理 |
| 调拨入库 | 调拨单 | 仓间调拨到货 | 到货验收、差异登记、上架 |
| 其他入库 | 手工入库单 | 初始化库存、特殊调整入库 | 审核、收货、上架 |

## 6. 状态流程

### 6.1 入库单状态

| 状态 | 含义 | 规则 |
| --- | --- | --- |
| 草稿 | 已创建未确认 | 可编辑、可取消 |
| 待收货 | 入库单已确认，等待到货收货 | 可执行收货 |
| 收货中 | 正在执行收货 | 可继续收货、登记差异 |
| 待质检 | 已收货，等待质检 | 可执行质检 |
| 待上架 | 已收货或已质检，等待上架 | 可生成或执行上架任务 |
| 上架中 | 正在执行上架 | 可继续上架 |
| 已完成 | 全部入库并完成库存入账 | 可查看、导出、追溯 |
| 已取消 | 入库单终止 | 保留历史记录 |
| 异常 | 存在差异或阻断问题 | 进入异常处理 |

### 6.2 收货状态

| 状态 | 含义 |
| --- | --- |
| 未收货 | 尚未执行收货 |
| 部分收货 | 部分明细已收货 |
| 已收货 | 全部可收明细完成收货 |
| 收货异常 | 存在少收、多收、错品、破损等异常 |

### 6.3 质检状态

| 状态 | 含义 |
| --- | --- |
| 无需质检 | 当前SKU或入库类型不需要质检 |
| 待质检 | 已收货待质检 |
| 质检中 | 正在质检 |
| 质检通过 | 质检结果为正品可上架 |
| 质检不良 | 质检结果为次品、拒收或待处理 |

### 6.4 上架状态

| 状态 | 含义 |
| --- | --- |
| 未上架 | 尚未生成或执行上架 |
| 部分上架 | 部分数量已上架 |
| 已上架 | 全部可上架数量完成上架 |
| 上架异常 | 货位、数量、批次、规则校验异常 |

## 7. 关键流程

### 7.1 采购入库流程

1. 采购人员或系统创建采购入库单。
2. 系统校验SKU、仓库、预计数量、单位和到货信息。
3. 入库单确认后进入待收货状态。
4. 收货员按SKU或条码扫码收货，录入实收数量、批次、生产日期、到期日期和SN。
5. 系统校验商品档案、仓储规则、批次效期规则和收货数量。
6. 需要质检的商品进入待质检状态。
7. 质检通过后进入待上架状态，不良品进入次品或拒收处理。
8. 上架员按推荐库位或指定库位执行上架。
9. 上架完成后增加实物库存并生成入库流水。

### 7.2 退货入库流程

1. 系统根据退货单、售后单或拒收退回单生成退货入库单。
2. 收货员按退货包裹、运单、SKU或条码执行收货。
3. 系统记录退货原因、退货数量、商品状态和外观异常。
4. 质检员登记正品、次品、拒收或待处理结果。
5. 正品进入返架上架流程，次品进入次品区或报损处理。
6. 上架完成后按质检结果增加正品库存或次品库存。

### 7.3 调拨入库流程

1. 调拨单到达调入仓后生成调拨入库任务。
2. 收货员按调拨出库明细验收到货SKU、批次和数量。
3. 系统登记调拨差异，包括少到、多到、破损、批次不一致。
4. 验收通过后生成上架任务。
5. 上架完成后增加调入仓库存并生成调拨入库流水。

### 7.4 上架流程

1. 系统根据SKU仓储规则、货位容量和上下架规则推荐库位。
2. 上架员扫描SKU、批次、SN和目标货位。
3. 系统校验货位状态、容量、品类限制、商品限制、批次混放和临期限制。
4. 校验通过后确认上架数量。
5. 系统更新库位库存、库存汇总和入库单状态。

### 7.5 入库差异处理流程

1. 收货、质检或上架环节发现差异。
2. 系统登记差异类型、差异数量、差异原因、照片或附件。
3. 仓库管理员处理差异，选择补收、拒收、转次品、报损、关闭差异等处理结果。
4. 差异处理完成后更新入库单状态和库存结果。

## 9. 规则要求

### 9.1 入库单规则

- 入库单号全局唯一。
- 来源单号和入库类型组成幂等校验口径。
- 草稿状态可编辑，已进入收货后保留原始单据快照。
- 已完成入库单不可编辑业务明细。
- 已取消入库单不参与收货、质检和上架。

### 9.2 收货规则

- 收货时必须校验SKU、条码、单位和仓储规则。
- 批次管理SKU收货时必须录入批次号。
- 效期管理SKU收货时必须录入生产日期或到期日期。
- SN管理SKU收货时必须逐件采集SN。
- 实收数量可等于、少于或多于预计数量，多收和少收生成差异记录。
- 错品、破损、效期异常和条码异常生成收货异常。

### 9.3 质检规则

- 质检结果包括正品、次品、拒收、待处理。
- 质检通过数量可进入上架流程。
- 次品数量进入次品库存或次品区。
- 拒收数量不进入可用库存。
- 质检结果需记录操作人、操作时间和质检备注。

### 9.4 上架规则

- 上架前必须存在可上架数量。
- 上架时必须校验目标货位状态和货位规则。
- 上架确认后增加库存明细和库存汇总。
- 上架完成后生成库存流水。
- 上架数量不得超过可上架数量。

### 9.5 库存入账规则

- 收货暂存不直接计入可用库存。
- 质检通过并上架后计入正品实物库存。
- 次品上架后计入次品库存。
- 冻结或待处理商品不参与可用库存计算。
- 所有库存增加动作必须生成库存流水。

## 10. 异常场景处理

| 异常场景 | 系统处理 |
| --- | --- |
| 入库单重复 | 按来源单号和入库类型进行幂等处理 |
| SKU不存在或停用 | 阻断收货并提示商品异常 |
| 条码无法识别 | 阻断扫码收货并提示人工处理 |
| 批次缺失 | 阻断批次商品收货 |
| 效期缺失 | 阻断效期商品收货 |
| SN重复 | 阻断SN采集并提示重复SN |
| 多收 | 生成多收差异并进入差异处理 |
| 少收 | 生成少收差异并进入差异处理 |
| 错品 | 生成错品差异并进入异常处理 |
| 破损 | 生成破损差异并进入质检或次品处理 |
| 上架货位停用或锁定 | 阻断上架并提示更换货位 |
| 上架超出货位容量 | 阻断上架并提示容量限制 |
| 库存流水生成失败 | 回滚本次入库动作并进入系统异常队列 |

## 11. 验收要点

- 能按入库类型、入库状态、收货状态、质检状态、上架状态、仓库、入库单号、来源单号、SKU编码、商品名称、条码完成查询。
- 能新建、查看、编辑、确认、取消入库单。
- 能执行采购入库、退货入库、调拨入库。
- 能按SKU或条码执行扫码收货。
- 批次管理SKU收货时能采集批次号。
- 效期管理SKU收货时能采集生产日期或到期日期。
- SN管理SKU收货时能逐件采集SN。
- 能登记正品、次品、拒收、待处理等质检结果。
- 能根据可上架数量生成上架任务。
- 上架时能校验货位状态、容量和上下架规则。
- 上架完成后能增加库存并生成库存流水。
- 多收、少收、错品、破损等差异能生成差异记录并进入异常处理。
- 入库单详情可查看收货、质检、上架、差异和库存流水。

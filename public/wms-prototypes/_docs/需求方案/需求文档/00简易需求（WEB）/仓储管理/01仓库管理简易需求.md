# 仓库管理简易需求

## 1. 基本信息

- 功能名称：仓库管理
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-W01`
- 所属模块：仓储管理
- 当前口径来源：`00原型方案/02WEB端HTML版/01WMS_WEB端高保真原型.html`

## 2. 业务目标

维护仓库主数据，支持仓库查询、查看、新建、编辑、启停及服务能力配置，作为入库、出库、库存、调拨、盘点等业务的仓库基础资料来源。

## 3. 功能范围

- 列表查询
- 列表展示与分页
- 新建仓库
- 编辑仓库
- 查看仓库详情
- 启用/停用仓库
- 导出

不包含：批量导入、批量启停、审批流、地图选址、三方实时同步校验。

## 4. 查询条件

| 字段名称 | 字段类型  | 查询方式 | 说明             |
| ---- | ----- | ---- | -------------- |
| 仓库类型 | 下拉单选  | 精确筛选 | 可选：中心仓、前置仓、共享仓 |
| 仓库名称 | 单行输入框 | 模糊查询 | 按名称关键字搜索       |

## 5. 列表字段

| 字段名称 | 类型   | 说明                |
| ---- | ---- | ----------------- |
| 勾选框  | 选择框  | 支持单行勾选、全选         |

| 仓库名称 | 文本   | 仓库正式名称            |

| 操作   | 按钮组  | 查看 / 编辑 / 启停 / 更多 |

## 8. 关键规则

- 列表默认分页展示，分页区展示总条数、页码、上一页、下一页。
- 翻页后保留当前查询条件。
- 当前筛选结果为空时，展示空态提示。
- 点击“新建仓库”打开新建抽屉；点击“查看/编辑”打开对应模式抽屉。
- 点击抽屉右上角关闭、取消、遮罩空白处时关闭抽屉；点击抽屉内部非关闭区域不应误关闭。
- 点击“保存”时校验必填字段，保存成功后关闭抽屉并刷新列表。
- 点击“启用/停用”时弹出居中确认框，确认后切换状态。
- 服务能力使用多选下拉，已选项以标签展示，点击空白区域自动收起下拉。

## 9. 状态规则

| 状态 | 含义        | 规则                 |
| -- | --------- | ------------------ |
| 启用 | 仓库可参与业务   | 可在相关业务中被引用         |
| 停用 | 仓库不可参与新业务 | 默认不出现在可选范围内，历史数据保留 |

## 10. 验收要点

- 能按仓库类型、仓库名称完成查询
- 能打开新建、查看、编辑抽屉
- 能正常关闭抽屉，不出现误关闭
- 服务能力支持多选，且选项为常温 / 冷藏 / 冷冻
- 点击保存后抽屉关闭并刷新列表
- 点击启用/停用后弹出确认框
- 分页区展示总条数、勾选数、页码切换

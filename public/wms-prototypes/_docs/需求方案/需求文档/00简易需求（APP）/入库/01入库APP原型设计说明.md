# 仓库 APP - 入库管理原型设计说明

> 依据文档：
>
> - 需求：[00入库APP简易需求文档.md](./00入库APP简易需求文档.md)
> - UI 规范：[2606改仓配端APP UI规范.md](../../../../UI规范/2606改仓配端APP UI规范.md)
> - 现有原型参考：`APP端HTML原型/pages/inbound-create.html`、`inbound-list.html`（沿用其骨架）；接单揽货/打包复核/发货的列表卡片、详情多态、底部操作栏、弹层结构。
>
> 本说明覆盖「进入入库 → 查看/筛选入库单 → 新建/编辑入库单 → 扫码/选货加行 → 提交入账 / 保存草稿 → 详情查看 → 作废/删除」全流程。重点补齐：入库时间可编辑、有效期录入、草稿编辑、作废/删除、筛选增强，以及**字段显隐多态**。

---

## 1. 设计目标

- 在不破坏现有 APP 入库原型视觉的前提下，补齐入库作业闭环并落实「简洁/有值才显示」原则。
- 复用现有 APP 组件（列表卡片、状态页签、详情卡片、底部操作栏、底部抽屉、扫码弹层），不新造样式体系。
- 产出可直接交给技术人员/AI 还原的页面级设计说明，配合需求文档即可开发。

---

## 2. 设计范围

### 2.1 本期范围
- 列表页：导航、搜索、状态页签、筛选抽屉、轻量统计条、入库单卡片、上拉加载。
- 新建/编辑页：基本信息（含入库时间选择、入库类型、库房选择、来源单号、备注）、商品明细多态行、扫码弹层、选货抽屉、有效期录入、底部操作栏。
- 详情页：状态 banner、基本信息（动态行）、商品明细多态、金额汇总、入库流水时间线、按状态的底部操作。
- 弹层：扫码、选货、库房选择、入库时间选择、筛选、重复扫码确认、作废确认、删除确认。
- 字段显隐多态与多数据场景演示。

### 2.2 暂不涉及
- 导入/导出 Excel、下载模板（WEB 端能力）。
- 收货任务、质检任务、上架任务、推荐库位、入库差异处理。
- 未知条码手工建档入库。
- 真实扫码硬件、真实接口（原型用内联样例数据）。

## 5. 列表页设计（IN01）

### 5.1 骨架
沿用现有 `inbound-list.html`：顶部导航 → 搜索区 → 状态页签 → （统计条）→ 卡片列表。逻辑尺寸 `375×812`，左右安全边距 `12px`，背景 `--app-bg`，卡片白底圆角 `8px`、间距 `10px`、轻阴影 `--app-shadow-card`。

### 5.2 顶部导航与搜索
- 导航：左返回，居中标题「入库单」(16px/600)，右侧「＋ 新建」主色小胶囊（沿用现有 `new-btn`）。
- 搜索：浅灰胶囊输入框 + 主色「搜索」按钮，placeholder「搜索入库单号」。

### 5.3 状态页签 + 筛选
- 横向 Tab：`全部 / 草稿 / 已入库 / 已作废`，当前项主色下划线（沿用 `.ib-tab`）。
- 页签行右侧增加「筛选」图标按钮（漏斗），点击打开筛选抽屉。

### 5.4 轻量统计条
- 状态页签下方一行小字：`今日 N 单 · 草稿 N`，12px `--app-text-secondary`，不使用大统计卡片（保持简洁）。

### 5.5 入库单卡片
沿用现有 `.ib-order-card`，字段按显隐规则：

```text
RK202606140002                              [已入库]
入库类型     采购入库
库房         piao自营
入库时间     2026-06-14 10:18
商品数量     2（共 18 件）
备注         供应商批量到货
─────────────────────────────
                                     RM 66.60
```

| 元素 | 规格 |
| --- | --- |
| 单号 | 14px/700 等宽字体 |
| 状态标签 | 右上角小胶囊：草稿 `--app-warning` 弱底 / 已入库 `--app-success` 弱底 / 已作废 灰底（沿用 `.ib-badge`） |
| 字段名 | 12px `--app-text-secondary`；字段值 12-13px `--app-text` |
| 商品数量 | 固定行，置于入库时间下方；格式「N（共 M 件）」，N=SKU 种类数、M=总件数 |
| 备注 | 有值才渲染该行 |
| 底部 | 仅右侧合计金额 `--app-danger` 加粗（不再重复「种·件」，已上移到商品数量行）；金额为 0 时弱化为次色 |

### 5.6 分页
列表上拉到底加载下一页，底部展示「加载中…」/「没有更多了」。无数据时空状态：📦 +「没有符合条件的入库单」。

### 5.7 筛选抽屉
底部抽屉，复用选货抽屉骨架：

```text
筛选
入库类型   [全部][采购][退货][调拨][其他]
库房       [全部][piao自营][KL自营仓库]...
入库时间   [开始日期] - [结束日期]
                 [重置]      [确定]
```
- 胶囊单选；确定后回列表按条件过滤并显示当前筛选标记；重置清空。

## 6. 卡片/行字段显隐多态 ★

同一组件按数据完整度呈现不同形态，**无值不渲染、不留「—」**。

### 6.1 列表卡片态
- 固定显示：入库类型、库房、入库时间、商品数量「N（共 M 件）」、合计金额。
- 条件显示：备注（有值才渲染）。
- 单价为 0 的单（如初始化/盘盈），合计金额显示 `RM 0.00` 但弱化为次色。

### 6.2 商品行态（新建/详情通用）
```text
极简态：  老干妈干煸肉丝油辣椒 260g
          数量 10                （无副信息行、无金额价格）

完整态：  乐事鲜浓蕃茄味薯片 90g                 RM 53.40
          老干妈 · 罐头酱菜 · 90g*1桶 · 桶 · 条码6924743915855
          有效期 2026-12-01
          数量 6 × RM 8.90
```
- 副信息行（品牌·分类·规格·单位·条码）只拼接有值项，用「·」分隔；全空则不渲染副信息行。
- 有效期标签：有值才显示。
- 单价为 0：不显示「× RM 0.00」，金额区弱化或省略。

### 6.3 详情基本信息态
- 行顺序固定：入库类型 → 库房 → 入库时间 → 备注。
- 仅渲染有值行；备注放独立区块且备注为空时整块不显示。

## 7. 新建 / 编辑页设计（IN02）

### 7.1 基本信息卡片
沿用现有 `inbound-create.html` 的 `.ib-card` 行结构：

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 入库类型 | 胶囊单选，文案用短词「采购 / 退货 / 调拨 / 其他」（四个一行不换行）；列表/详情仍显示完整「采购入库」等 | 默认采购入库 |
| 目标库房 | 行右侧「选择」→ 库房抽屉 | 必填 |
| 入库时间 | 行右侧时间值 → 点击打开时间选择 | **默认当前，可改历史时间**（新增能力） |
| 备注 | 多行文本域 | 选填，最长 500 |

### 7.2 入库时间选择（新增）
点击入库时间行打开底部日期时间选择（date+time）。约束：不晚于当前时间。原型可用底部抽屉 + 原生 `datetime-local` 或滚轮占位实现。

### 7.3 商品明细卡片
- 卡片标题右侧两个小按钮：`📷 扫码添加`、`＋ 选择商品`（沿用 `.ib-mini-btn`）。
- 空态：「暂无商品，请扫码或从商品列表添加」。
- 商品行（沿用 `.ib-line`）按 6.2 多态渲染，并增加：
  - 数量步进器（沿用 `.ib-stepper`，min 1）。
  - 单价输入（沿用 `.ib-price`）。
  - **有效期**：行内一个「有效期」选填入口（点击弹日期选择；有值后行内显示，未填则只显示弱提示「+ 有效期」小链接，不占大空间）。
  - 删除按钮。

### 7.4 扫码弹层与重复扫码确认
- 扫码弹层沿用现有 `#scanModal`（手输/回车模拟）。
- 命中 SKU 且该 SKU 已在明细中：弹确认弹窗「该商品已存在」→「新增一行 / 累加到已有行」。未命中：toast「条码未匹配到商品」。

### 7.5 选货抽屉 / 库房抽屉
沿用现有 `#pickSheet` / `#whSheet`，搜索按名称/条码，命中可加入；库房抽屉单选。

### 7.6 底部操作栏
沿用现有底部栏：左「N 种 · N 件 / 合计金额」，右「保存草稿」(描边) + 「提交入库」(主色)。编辑态相同。

### 7.7 编辑态
- 顶部标题「编辑入库单」，进入即回填基本信息与商品行。
- 仅草稿可进入编辑。保存/提交后回详情或列表。

### 7.8 提交成功页
沿用现有成功页：图标（提交✓ / 草稿📝）、单号、统计、`查看入库单 / 继续新建`。

## 8. 详情页设计（IN03）

### 8.1 结构
沿用现有 `inbound-list.html` 详情屏：

```text
[banner] RK202606140002  复制                 [已入库]
[基本信息]  入库类型 / 库房 / 入库时间 / (备注)   ← 动态行
[入库明细 (N)]  多态商品行
[金额汇总]  N 种 | N 件 | 合计 RM xx
[入库流水]  创建入库单 → 提交入库·库存入账 (/ 作废入库单)
```

### 8.2 底部操作（按状态）★ 新增
现有详情无操作按钮，本期补底部操作栏：

| 状态 | 底部按钮 |
| --- | --- |
| 草稿 | 删除（描边/红字）· 编辑（描边）· 提交入库（主色） |
| 已入库 | 作废（描边/红字，靠右） |
| 已作废 | 无底部栏（纯只读） |

### 8.3 入库流水时间线
沿用 `.ib-log-node`：创建（＋）→ 已入库追加「提交入库·库存入账」(✓)；已作废追加「作废入库单」(✕)。

## 11. 校验、提示与反馈

## 13. 原型落地规则

- 沿用现有两页骨架升级，**保持单文件自包含**（样例数据 + 控制器内联），与 `inbound-create.html`/`inbound-list.html`/`pickup-*` 约定一致；内联脚本 < 50KB（check 脚本限制）。
- 不新造卡片/弹层/Tab 样式，复用 UI 规范第 9 节 Design Tokens 与现有 APP 组件。
- 入口接线沿用现有约定：`assets/wms-app-page.js` 的 `navigate()` 与 `wms-app-shell.js` 的 `frameUrl()` 中 `create_inbound → inbound-create.html`、`inventory_in_record → inbound-list.html`。
- 工作台「入库」模块卡片在「待退货/待采购」计数下增「入库单」「新建入库单」两个快捷入口；「其他」模块移除重复的「新建入库单/入库记录」。
- APP 菜单目录（`APP菜单目录.html`）「入库」分组下新增「入库单（IB-LIST）→ inbound-list.html」「新建入库单（IB-NEW）→ inbound-create.html」；「入库记录(IV-04)」与入库单为同一页，已从目录收敛。
- 字段显隐用「有值判断 + 不渲染空行」实现，禁止用「—」占位。
- AI 新生成草稿先放 `_drafts/`，确认后再合并正式 APP 原型。

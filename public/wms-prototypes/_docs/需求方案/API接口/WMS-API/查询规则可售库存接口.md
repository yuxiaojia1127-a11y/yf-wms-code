# 查询规则可售库存接口

## 1. 接口定义

| 项目 | 说明 |
| --- | --- |
| API 名称 | 查询规则可售库存 |
| 方法 | `POST` |
| 路径 | `/openapi/v1/inventory/rule-saleable/query` |
| 调用方 | OMS / 第三方电商系统 |
| 优先级 | P0 |

本接口用于按渠道、货主、店铺、履约规则、仓路由和配路由查询 SKU 在当前规则下是否可售。

菜鸟云仓下游映射：

| WMS 处理 | 菜鸟能力 |
| --- | --- |
| 查询仓范围内可售库存 | `CAINIAO_GL_WH_EXTERNAL_INVENTORY_AVAILABLE_QUANTITY_QUERY` |

## 2. 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `saleable_query_type` | 是 | `single_warehouse`、`network_rule` |
| `channel_id` | 是 | 渠道标识 |
| `business_type` | 是 | `self_operated`、`merchant` |
| `owner_id` | 是 | 货主 ID |
| `store_id` | 是 | 履约店铺 ID |
| `fulfillment_rule_code` | 否 | 指定履约规则；未传时按渠道和仓配参数匹配 |
| `receiver_region` | 建议 | 收货区域，用于筛选可服务仓 |
| `warehouse_route_mode` | 是 | `merchant_assign`、`wms_assign` |
| `preferred_warehouse_id` | 条件必填 | 单仓查询或商家指定仓时必填 |
| `delivery_route_mode` | 是 | `merchant_assign`、`wms_assign` |
| `delivery_mode_required` | 否 | 期望配送方式 |
| `service_level` | 否 | 时效约束 |
| `split_mode` | 是 | `by_sku`、`by_sku_qty` |
| `split_delivery_allowed` | 是 | 是否允许多仓组合可售 |
| `sku_list` | 是 | 待查询 SKU 列表 |

`receiver_region`：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `country_code` | 是 | 国家编码 |
| `province` | 否 | 省/州 |
| `city` | 否 | 城市 |
| `district` | 否 | 区县 |
| `postal_code` | 否 | 邮编 |

`sku_list`：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `sku_code` | 是 | WMS SKU 编码 |
| `request_qty` | 否 | 期望购买数量；传入后直接返回是否足量 |

## 3. 请求示例

```json
{
  "saleable_query_type": "network_rule",
  "channel_id": "third_party_platform",
  "business_type": "merchant",
  "owner_id": "OWNER-MY-001",
  "store_id": "STORE-MY-001",
  "fulfillment_rule_code": "FULFILL_005",
  "receiver_region": {
    "country_code": "MY",
    "province": "Selangor",
    "city": "Petaling Jaya",
    "district": "Damansara",
    "postal_code": "47800"
  },
  "warehouse_route_mode": "wms_assign",
  "delivery_route_mode": "wms_assign",
  "delivery_mode_required": "express",
  "service_level": "standard",
  "split_mode": "by_sku_qty",
  "split_delivery_allowed": true,
  "sku_list": [
    {
      "sku_code": "SKU-A",
      "request_qty": 2
    },
    {
      "sku_code": "SKU-B",
      "request_qty": 1
    }
  ]
}
```

## 4. 响应字段

| 字段 | 说明 |
| --- | --- |
| `success` | 查询是否成功 |
| `query_id` | 查询追踪号 |
| `saleable_query_type` | 实际查询口径 |
| `fulfillment_rule_code` | 实际命中的履约规则 |
| `sku_results` | SKU 可售结果 |
| `error_code` | 失败码 |
| `error_message` | 失败说明 |

`sku_results`：

| 字段 | 说明 |
| --- | --- |
| `sku_code` | SKU 编码 |
| `request_qty` | 请求数量 |
| `saleable_qty` | 当前规则下可售数量 |
| `can_sale` | 是否满足请求数量 |
| `saleable_type` | `single_warehouse`、`network_rule` |
| `matched_warehouse_count` | 参与计算的命中仓数量 |
| `reason_code` | 不可售原因 |

## 5. 响应示例

```json

  "success": true,

  "saleable_query_type": "network_rule",
```

## 6. 可售计算规则

| 场景 | 计算口径 |
| --- | --- |
| `single_warehouse` | 只计算指定仓可售 |
| `network_rule` | 先按店铺仓网和仓配规则筛仓，再计算规则范围可售 |
| `split_delivery_allowed=false` | 仅单仓足量才可售 |
| `split_mode=by_sku` | 不同 SKU 可分仓，同一 SKU 不按数量跨仓拼接 |
| `split_mode=by_sku_qty` | 同一 SKU 可按数量跨仓拼接 |

WMS 对菜鸟库存查询的处理摘要：

| WMS 处理 | 菜鸟字段 |
| --- | --- |
| 规则命中的云仓集合 | `warehouseCodes` |
| SKU 映射后的云仓货品 ID | `scItemId` 或 `scItemIdList` |
| 可售库存取值 | `availableQuantity` |

说明：

1. `availableQuantity` 作为下游可销售库存口径参与 WMS 规则计算。
2. `totalAvailableQuantity` 不直接作为前台可售判断字段。
3. 本接口默认返回规则结果，不直接暴露全部仓库存明细。

## 7. 主要错误码

| 错误码 | 说明 |
| --- | --- |
| `SALEABLE_RULE_NOT_FOUND` | 未命中履约规则 |
| `SALEABLE_WAREHOUSE_REQUIRED` | 单仓查询未传指定仓 |
| `SALEABLE_SKU_NOT_FOUND` | SKU 不存在或未完成云仓货品映射 |
| `SALEABLE_ROUTE_NOT_FOUND` | 未找到可参与计算的仓配范围 |
| `SALEABLE_CAINIAO_QUERY_FAILED` | 菜鸟实时库存查询失败 |

- 同一对象在不同文档中状态名称不一致
- 业务状态与页面状态混用

## 2. 使用原则

| 原则        | 说明                               |
| --------- | -------------------------------- |
| 先分层再命名    | 先区分页面状态、业务对象状态、执行状态、异常状态，再定义具体名称 |
| 一个对象一套主状态 | 每个业务对象应有主状态，不与操作结果状态混用           |
| 列表状态可直接筛选 | 列表页使用的状态应尽量可枚举、可筛选、可统计           |
| 异常状态单独表达  | 异常既可作为主状态，也可作为风险标签或结果字段，但应明确层级   |
| 页面反馈状态独立  | 加载中、空数据、无权限等页面状态不与业务状态混用         |

## 3. 页面通用状态

| 状态分类 | 标准口径 | 说明               | 适用范围 |
| ---- | ---- | ---------------- | ---- |
| 页面状态 | 默认   | 页面正常加载并展示最近数据    | 全部页面 |
| 页面状态 | 筛选中  | 带筛选条件展示结果        | 列表页  |
| 页面状态 | 空数据  | 当前条件下无记录         | 列表页  |
| 页面状态 | 加载失败 | 接口失败或网络失败        | 全部页面 |
| 页面状态 | 无权限  | 当前账号无模块或上下文权限    | 全部页面 |
| 操作反馈 | 操作成功 | 保存、确认、重推、导出等操作成功 | 全部页面 |
| 操作反馈 | 操作失败 | 状态冲突、字段校验失败、接口失败 | 全部页面 |

## 5. 入库中心状态

### 5.1 入库单主状态

| 状态    | 说明                  | 备注       |
| ----- | ------------------- | -------- |
| 待受理   | 入库单已创建，尚未由 WMS 接收处理 | 列表默认可筛选  |
| 处理中   | 已进入收货、质检、上架等处理中阶段   | 中间状态     |
| 改约处理中 | 预约时间待调整或改约处理中       | 特殊处理中状态  |
| 已完成   | 入库处理完成，结果已回流库存      | 终态       |
| 已取消   | 入库单已取消，不再继续处理       | 终态       |
| 异常    | 入库存在差异或处理异常，需人工关注   | 风险终态或中断态 |

### 5.2 入库执行节点状态

| 节点 | 建议状态 | 说明          |
| -- | ---- | ----------- |
| 接收 | 已接收  | WMS 已确认接收单据 |
| 收货 | 收货中  | 正在执行收货      |
| 收货 | 已收货  | 收货完成        |
| 上架 | 待上架  | 已完成收货，待上架   |
| 上架 | 上架中  | 正在上架        |
| 上架 | 已上架  | 上架完成        |

## 6. 库存中心状态

### 6.1 库存状态

| 状态 | 说明             | 适用对象      |
| -- | -------------- | --------- |
| 正常 | 可正常参与后续业务处理    | 库存明细      |
| 冻结 | 当前库存被冻结，不可继续流转 | 库存明细、批次库存 |
| 临期 | 接近有效期阈值，需要预警   | 批次库存      |
| 过期 | 已超过有效期，禁止正常流转  | 批次库存      |
| 预警 | 命中低库存或风险阈值     | 库存汇总、预警列表 |

### 6.2 冻结来源状态

| 状态   | 说明             |
| ---- | -------------- |
| 订单冻结 | 因履约或业务单据占用产生冻结 |
| 调拨冻结 | 因调拨业务产生冻结      |
| 风险冻结 | 因风控或人工限制产生冻结   |

## 12. 异常表达建议

| 场景        | 建议表达方式               | 说明                |
| --------- | -------------------- | ----------------- |
| 可作为主状态的异常 | `异常`                 | 用于履约单、退货单、调拨单等主对象 |
| 作为列表标签的风险 | `异常单`、`预警`、`临期`、`过期` | 用于增强识别，不替代主状态     |
| 作为结果字段的失败 | `失败`、`重试失败`          | 用于回调、回传、运单等结果对象   |

## 13. 当前建议统一替换项

| 当前可能混用表述    | 建议统一为              | 说明                  |
| ----------- | ------------------ | ------------------- |
| 处理中 / 执行中   | 处理中                | 主对象状态统一使用“处理中”      |
| 发运中 / 已发货   | 已发运                | Web 履约单主状态统一使用“已发运” |
| 异常单 / 异常    | 异常单用于出库单，异常用于其他主对象 | 区分对象语境              |
| 回调失败 / 投递失败 | 投递失败               | 回调事件结果统一用词          |

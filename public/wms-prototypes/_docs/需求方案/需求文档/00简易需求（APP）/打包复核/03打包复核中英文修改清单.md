## 0. 给 AI 的执行说明（请先读）

1. 本清单只改 **截图中可见的 UI 文案（中文 + 英文）**，不改业务逻辑、不改字段 key、不改接口参数。
2. 所有 `改前` 均取自截图实际显示文案；截图中未出现的页面或字段，不在本次范围。
3. 严格按下方「改前 → 改后」表替换，注意大小写与标点（如 `Order No.` 的点、复数、`Same-day`）。
4. 英文界面下仍显示中文的值（共N张揽货单 / 当日配送 / 尽快送达 等）属漏翻，需翻译（见第 4 节）。
5. 改完后输出「已修改文件 + 行号」清单，便于人工复核。
6. 标注「待确认」的项需产品确认后再改，不要擅自决定。

## 6. 已确认口径

- 列表页标题：打包复核 = **Packing Tasks**（与揽货侧 Picking Tasks 对仗）
- 详情页标题：打包复核 = **Packing Details**（与揽货侧 Picking Details 对仗，中文同步改「打包详情」）
- 揽货详情按钮：中文改「打包详情」，英文 **Packing Details**
- 步进/商品口径：复核 → **打包**（Packed / Items to Pack），界面不出现「复核」
- 物流发货 = **Carrier Shipping**
- 商品数量：标签用 **Qty**，件数单位用 **pcs**（如 `2 (3 pcs)`）
- 售价 = **Price**（不用 Sale）

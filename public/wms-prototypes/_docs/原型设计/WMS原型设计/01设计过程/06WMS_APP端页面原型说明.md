## 2. 全局原型规则

### 2.1 终端框架

| 区域 | 说明 |
| ---- | ---- |
| 顶部栏 | 仓库上下文、角色标签、消息入口 |
| 主内容区 | 卡片、任务列表、任务详情、扫码面板、底部操作栏 |
| 底部导航 | 工作台、任务、扫码、异常、我的 |
| 全局组件 | 状态标签、异常提醒、确认弹窗、重试弹窗 |

### 2.2 作业约束

| 约束 | 说明 |
| ---- | ---- |
| 全流程在线 | 每次扫码和提交都实时校验 |
| 不做离线 | 网络失败仅支持在线重试 |
| 任务锁定 | 接单即锁定任务归属 |
| 角色化展示 | 按作业员、主管、管理员控制菜单与按钮 |
| 危险操作确认 | 出库、物流交接、异常完结、任务转派需二次确认 |
| 术语统一 | 统一使用“备货”，不使用“揽货” |

## 3. 关键页面原型说明

### 3.1 通用基础能力

#### APP-001 登录页

| 项目 | 说明 |
| ---- | ---- |
| 页面目标 | 完成账号登录并加载角色与仓库权限。 |
| 使用角色 | 系统管理类、仓内作业类 |
| 页面入口 | 打开 APP 默认进入 |
| 需求来源 | WMS_APP端 / 通用基础能力 |
| 页面布局 | 见下方页面布局分区 |

页面布局：

| 区域 | 内容 |
| ---- | ---- |
| Logo区 | WMS APP 标识 |
| 登录表单区 | 账号、密码、登录按钮 |
| 提示区 | 网络状态、版本号、登录异常提示 |

字段级细化：
- `Logo区`：独立字段包括 `WMS APP 标识`；原型中按独立字段标签展开，不合并成整句文案。
- `登录表单区`：独立字段包括 `账号`、`密码`；录入类字段需要明确必填、格式校验、默认值和失败提示。
- `提示区`：独立字段包括 `网络状态`、`版本号`、`登录异常提示`；提示信息拆成标题、原因、影响范围和建议动作四类字段展示。

按钮级细化：
- `登录按钮`：提交账号密码并进入鉴权流程；加载中禁用重复点击，失败时保留输入值。

状态与交互补充：
- 页面状态：默认、加载中、空数据、无权限、网络异常；操作失败统一保留当前输入并提供在线重试入口。
- 交互反馈：表单提交、上下文切换、入口跳转都需要明确的成功/失败提示，网络异常优先提示重试。
- 反馈规则：扫码、录入、提交后即时给出成功/失败反馈，网络失败仅支持在线重试，不做离线缓存。

控件类型与属性建议：
- `Logo区`：`WMS APP 标识`使用文本展示；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `登录表单区`：`账号`使用文本输入框；`密码`使用密码输入框；`登录按钮`使用主按钮；提交前需统一做字段校验，错误信息贴字段展示。
- `提示区`：`网络状态`使用告警信息；`版本号`使用告警信息；`登录异常提示`使用提示文案；原型中保持字段名、字段值、状态标签三层信息清晰分离。

校验与提交规则：
- 提交校验：必填输入框为空时禁止提交并贴字段提示。

弹窗/抽屉结构建议：
- 弹层策略：本页以全屏任务页承载为主，仅在轻量维护、选择或高风险确认时使用弹层。

字段属性明细表：

| 所属区域 | 字段/动作 | 属性类型 | 控件类型 | 是否必填 | 默认值/回填 | 占位/文案 | 校验/约束 | 交互/反馈 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 登录表单区 | 账号 | 录入字段 | 文本输入框 | 是 | 默认空 | 请输入账号 | 不允许全空格，限制最大长度 | 聚焦后唤起数字/字母键盘，失焦保留输入 |
| 登录表单区 | 密码 | 录入字段 | 密码输入框 | 是 | 默认空 | 请输入密码 | 不允许全空格，支持显示/隐藏密码 | 输入错误后保留账号，不清空密码以外内容 |
| 登录表单区 | 登录按钮 | 操作按钮 | 主按钮 | - | 未填完前禁用 | 按钮文案：登录 | 账号和密码均有效后才可点击 | 点击后进入loading，禁止重复提交 |
| 提示区 | 网络状态 | 展示字段 | 状态提示条 | - | 实时检测回显 | 网络异常/网络正常 | 文案随网络状态变化 | 异常时优先展示在表单下方 |
| 提示区 | 版本号 | 展示字段 | 弱提示文本 | - | 接口或本地包信息回显 | 版本号：x.x.x | 格式固定为版本号文案 | 常驻底部，不参与校验 |
| 提示区 | 登录异常提示 | 展示字段 | 错误提示条 | - | 登录失败时回填 | 账号或密码错误/网络异常 | 错误文案不宜过长，避免泄露安全信息 | 登录失败后展示并支持再次提交 |

#### APP-002 货主/仓库选择页

| 项目 | 说明 |
| ---- | ---- |
| 页面目标 | 设置当前作业上下文。 |
| 使用角色 | 系统管理类、仓内作业类 |
| 页面入口 | 首次登录后强制进入；顶部栏可再次进入 |
| 需求来源 | WMS_APP端 / 通用基础能力 |
| 页面布局 | 见下方页面布局分区 |

页面布局：

| 区域 | 内容 |
| ---- | ---- |
| 已选上下文区 | 已选货主、仓库标签 |
| 筛选区 | 货主名称、仓库名称、仓库编码 |
| 列表区 | 货主、仓库、权限状态 |
| 底部操作区 | 确认选择、清空、设为默认 |

字段级细化：
- `已选上下文区`：独立字段包括 `已选货主`、`仓库标签`；主键、状态、上下文字段固定前置，保持首屏可见。
- `筛选区`：独立字段包括 `货主名称`、`仓库名称`、`仓库编码`；筛选字段默认首行展开，高频字段前置；支持回车查询、重置后保留默认上下文。
- `列表区`：独立字段包括 `货主`、`仓库`、`权限状态`；列表字段逐列展开，主键列支持点击进入详情，状态类字段使用标签样式。

按钮级细化：
- `确认选择`：提交当前动作结果；高风险动作需二次确认，成功后刷新状态并保留结果回执。
- `清空`：恢复默认条件或清空当前输入，但保留已选货主/仓库上下文。
- `设为默认`：将当前选择写入默认上下文，下一次进入页面自动带出。

状态与交互补充：
- 页面状态：默认、加载中、空数据、无权限、网络异常；操作失败统一保留当前输入并提供在线重试入口。
- 交互反馈：表单提交、上下文切换、入口跳转都需要明确的成功/失败提示，网络异常优先提示重试。
- 风险交互：确认出库、物流交接、提交结果、异常完结等动作需要二次确认，失败后保留现场录入内容。

控件类型与属性建议：
- `已选上下文区`：`已选货主`使用描述字段；`仓库标签`使用描述字段；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `筛选区`：`货主名称`使用下拉单选；`仓库名称`使用下拉单选；`仓库编码`使用下拉单选；筛选区默认首行展示高频字段，其余字段进入高级筛选或展开区。
- `列表区`：`货主`使用文本列；`仓库`使用文本列；`权限状态`使用状态标签列；主键列可点击，数值列右对齐，状态列使用统一标签色。
- `底部操作区`：`确认选择`使用主按钮；`清空`使用次按钮；`设为默认`使用次按钮；主按钮放右侧或底部固定区，次按钮放左侧，警示按钮与主按钮保持明显区分。

校验与提交规则：
- 筛选校验：下拉筛选值仅允许选择预置枚举，禁止自由输入。
- 动作校验：高风险按钮点击后先校验当前对象状态，再弹二次确认层。

弹窗/抽屉结构建议：
- 确认弹层：`确认选择`走底部确认弹层；内容包含当前对象、风险提示、取消按钮、主确认按钮。

| ---- | ---- |

| 使用角色 | 系统管理类、仓内作业类 |
| 页面入口 | 任意在线提交失败后唤起 |

页面布局：

| 区域 | 内容 |
| ---- | ---- |
| 错误摘要区 | 失败原因、失败时间、影响动作 |

| 提示区 | 在线重试说明、不可离线缓存说明 |

字段级细化：
- `错误摘要区`：独立字段包括 `失败原因`、`失败时间`、`影响动作`；统计类字段采用卡片或摘要条展示，需同时给出数值、状态色和最近更新时间。
- `提示区`：独立字段包括 `在线重试说明`、`不可离线缓存说明`；提示信息拆成标题、原因、影响范围和建议动作四类字段展示。

按钮级细化：
- `立即重试`：执行前二次确认，执行后展示成功或失败结果，并记录最近一次处理结果。
- `返回任务`：返回上一页并保留来源筛选条件、滚动位置和页签定位。
- `复制错误信息`：复制当前错误信息或主键到剪贴板，并给出轻提示。

状态与交互补充：
- 页面状态：默认、加载中、空数据、无权限、网络异常；操作失败统一保留当前输入并提供在线重试入口。
- 交互反馈：表单提交、上下文切换、入口跳转都需要明确的成功/失败提示，网络异常优先提示重试。
- 风险交互：确认出库、物流交接、提交结果、异常完结等动作需要二次确认，失败后保留现场录入内容。

控件类型与属性建议：
- `错误摘要区`：`失败原因`使用指标卡/摘要值；`失败时间`使用指标卡/摘要值；`影响动作`使用指标卡/摘要值；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `操作区`：`立即重试`使用警示按钮；`返回任务`使用次按钮；`复制错误信息`使用次按钮；主按钮放右侧或底部固定区，次按钮放左侧，警示按钮与主按钮保持明显区分。
- `提示区`：`在线重试说明`使用提示文案；`不可离线缓存说明`使用提示文案；原型中保持字段名、字段值、状态标签三层信息清晰分离。

校验与提交规则：
- 动作校验：高风险按钮点击后先校验当前对象状态，再弹二次确认层。

弹窗/抽屉结构建议：
- 确认弹层：`立即重试`走底部确认弹层；内容包含当前对象、风险提示、取消按钮、主确认按钮。

页面布局：

| 区域 | 内容 |
| ---- | ---- |
| 顶部栏 | 页面标题、消息入口、未读角标 |
| 账号信息卡 | 头像、姓名、员工编号、角色身份 |
| 权限信息卡 | 国家、负责仓库数量、仓库标签、账号标识 |
| 提醒区 | 消息提醒文案、开启/已开启状态 |

字段级细化：
- `顶部栏`：独立字段包括 `页面标题`、`消息入口`、`未读角标`；消息角标默认展示最近未处理消息数，超过上限时显示 `99+`。
- `账号信息卡`：独立字段包括 `头像`、`姓名`、`员工编号`、`角色身份`；姓名与员工编号作为主识别信息同层展示，角色信息弱化为辅助说明。
- `权限信息卡`：独立字段包括 `国家`、`负责仓库`、`仓库编码摘要`、`仓库标签`、`账号标识`；仓库标签支持多仓换行展示，超长仓库名使用圆角胶囊承载。
- `提醒区`：独立字段包括 `提醒标题`、`提醒说明`、`提醒开关按钮`；提醒说明需要明确开启后的收益，不使用模糊文案。

按钮级细化：
- `消息入口`：进入消息中心或清除未读角标；当前原型中可作为轻交互入口，点击后将未读角标清零。
- `提醒开关按钮`：切换消息提醒状态；按钮需明确区分 `开启` 与 `已开启` 两种态。
- `退出登录`：返回登录页；需清空当前会话态并恢复默认底部导航定位。

状态与交互补充：
- 页面状态：默认、无未读消息、提醒已开启、提醒未开启、无仓库权限、网络异常。
- 展示规则：账号信息卡固定首屏展示；权限信息卡跟随当前已选/已授权仓库实时联动；消息入口角标优先展示在右上角。
- 交互反馈：点击提醒开关后按钮颜色与文案同步变化；点击退出登录后立即收起页面并回到登录页；消息入口清零后角标隐藏。
- 权限差异：作业员、班组长、仓库管理员进入本页时，角色文案、仓库数量、待办摘要需跟随权限方案联动刷新。

控件类型与属性建议：
- `顶部栏`：`页面标题`使用标题文本；`消息入口`使用图标按钮；`未读角标`使用角标徽标。
- `账号信息卡`：`头像`使用头像容器；`姓名`、`员工编号`使用高强调文本；`角色身份`使用辅助说明文本。
- `权限信息卡`：`国家`使用描述字段；`负责仓库`使用摘要值；`仓库编码摘要`使用弱提示文本；`仓库标签`使用标签组；`账号标识`使用辅助说明文本。
- `提醒区`：`提醒标题`使用标题文本；`提醒说明`使用说明文本；`提醒开关按钮`使用主按钮/状态按钮组合样式。
- `底部操作区`：`退出登录`使用次级主按钮，尺寸需大于普通文本按钮，保证易点性。

校验与提交规则：
- 状态校验：消息提醒开关仅做本地示意时可直接切换；若后续接接口，需要校验系统推送授权状态。
- 动作校验：退出登录前如存在进行中的高风险任务，正式产品态需增加二次确认；当前原型先展示直接退出路径。

弹窗/抽屉结构建议：
- `退出登录` 正式上线后建议补充底部确认弹层；内容包括当前账号、是否退出说明、取消按钮、确认退出按钮。

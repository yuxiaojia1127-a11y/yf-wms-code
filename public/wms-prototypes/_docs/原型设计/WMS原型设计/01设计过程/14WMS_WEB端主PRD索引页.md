## 2. WEB端定位

`WMS_WEB端` 是仓储后台管理端，面向开放平台运维、仓库管理员、仓内主管、物流调度专员、售后专员、调拨专员、异常处理专员和结算专员，承担接入运维、主数据承接、入库、库存、出库、履约、物流协同、售后、调拨等后台管理和跟踪能力。

系统边界如下：

- 承接第三方电商系统接入后的后台管理能力，不承接上游电商系统自身页面需求。
- 强调“后台管理、状态跟踪、异常排查和协同回流”，不替代 APP 端的现场执行。
- `WMS_WEB_物流系统` 在需求文档侧独立拆分，但在原型和 Web 端简易版 PRD 中并入 `WMS_WEB端` 的 `物流协同` 模块体现。

## 8. 依赖关系总览

| WEB模块 | 主要依赖 | 说明 |
| ---- | ---- | ---- |
| 开放平台 | 第三方电商系统、回调能力 | 回调配置和日志依赖上游接入与事件推送 |
| 主数据 | 第三方电商系统、仓库配置 | 主数据承接依赖上游同步和后台维护 |
| 入库中心 | 上游入库单来源、库存中心 | 入库处理结果影响库存变化 |
| 库存中心 | 入库中心、出库中心、调拨中心、售后中心 | 库存是多个业务模块的结果汇总视图 |
| 出库中心 | 上游出库单来源、物流中心 | 出库结果影响发货履约链路 |
| 物流中心 | 出库中心、物流协同、回调中心 | 履约以 `shipment_order_id` 为核心对象 |
| 物流协同 | WMS_WEB_物流系统、物流中心、回调中心 | 运单、轨迹、回传和面单依赖物流协同链路 |
| 售后中心 | 上游退货单来源、库存中心、APP 执行端 | 退货质检和处理结果需回流后台查看 |
| 调拨中心 | 入库中心、出库中心、库存中心、APP 执行端 | 调拨结果依赖调出调入执行和库存同步 |

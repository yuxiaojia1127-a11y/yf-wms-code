## 2. 全局原型规则

### 2.1 页面框架

| 区域   | 说明                                           |
| ---- | -------------------------------------------- |
| 顶部栏  | 当前货主、仓库/店铺上下文、全局搜索、通知、账号                     |
| 左侧导航 | 开放平台、基础资料、入库中心、库存中心、出库中心、物流中心、物流协同、售后中心、调拨中心 |
| 主内容区 | 列表、详情、抽屉、标签页、操作区、日志区                         |
| 全局提示 | 成功、失败、异常、无权限、空数据                             |

### 2.2 页面通用规则

| 规则        | 说明                                 |
| --------- | ---------------------------------- |
| 对象主键清晰    | 发货履约场景统一突出 `shipment_order_id`     |
| 上下文可见     | 货主、仓库、店铺、履约模式等必须在关键页面显式展示          |
| 列表优先可追溯   | 每个主业务对象至少支持从列表进入详情                 |
| 风险信息前置    | 临期、冻结、失败回调、差异、异常需前置展示              |
| 高风险操作二次确认 | 回调测试、失败重推、改单、取消、关闭都需要二次确认          |
| 物流模块独立区块  | 运单、包裹、轨迹、回传、账单虽并入 Web，但页面上仍保持独立模块感 |

| 项目   | 说明                         |
| ---- | -------------------------- |
| 页面目标 | 汇总查看接入方状态、回调健康度、调用配额与近期异常。 |
| 使用角色 | 系统管理类 |
| 页面入口 | 开放平台 - 开放平台概览              |
| 需求来源 | WMS\_开放平台                  |
| 页面布局 | 见下方页面布局分区                  |

页面布局：

| 区域    | 内容                      |
| ----- | ----------------------- |
| 接入概览区 | 接入方数量、启用回调数、异常接口数、配额使用率 |
| 健康度区  | 最近回调成功率、最近失败事件、最近测试结果   |
| 配额区   | 调用次数、剩余额度、限流告警          |
| 快捷入口区 | 回调配置、回调日志、测试入口          |

字段级细化：

- `接入概览区`：独立字段包括 `接入方数量`、`启用回调数`、`异常接口数`、`配额使用率`；统计类字段采用卡片或摘要条展示，需同时给出数值、状态色和最近更新时间。
- `健康度区`：独立字段包括 `最近回调成功率`、`最近失败事件`、`最近测试结果`；原型中按独立字段标签展开，不合并成整句文案。
- `配额区`：独立字段包括 `调用次数`、`剩余额度`、`限流告警`；原型中按独立字段标签展开，不合并成整句文案。

按钮级细化：

- `回调配置`：作为当前页面可点击入口使用，需明确点击态、禁用态和成功/失败反馈。
- `回调日志`：作为当前页面可点击入口使用，需明确点击态、禁用态和成功/失败反馈。
- `测试入口`：执行前二次确认，执行后展示成功或失败结果，并记录最近一次处理结果。

状态与交互补充：

- 页面状态：默认、加载中、空数据、加载失败、无权限；列表页需保留筛选条件，详情页需保留当前位置。
- 状态口径引用：业务对象状态、执行结果状态、异常状态统一引用 [15WMS\_WEB端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/15WMS_WEB端状态口径总表.md)，页面内不再单独衍生第二套命名。
- 展示规则：页面中的状态字段统一使用标签或时间线展示，主键字段固定前置；如概览卡、筛选项、时间线节点与总表冲突，以状态口径总表为准。
- 风险交互：测试、重推、取消、重试、确认、提交类动作必须二次确认，并在完成后刷新结果区。

控件类型与属性建议：
- `接入概览区`：`接入方数量`使用指标卡/摘要值；`启用回调数`使用指标卡/摘要值；`异常接口数`使用指标卡/摘要值；`配额使用率`使用指标卡/摘要值；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `健康度区`：`最近回调成功率`使用文本展示；`最近失败事件`使用文本展示；`最近测试结果`使用文本展示；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `配额区`：`调用次数`使用文本展示；`剩余额度`使用文本展示；`限流告警`使用文本展示；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `快捷入口区`：`回调配置`使用按钮；`回调日志`使用按钮；`测试入口`使用次按钮；主按钮放右侧或底部固定区，次按钮放左侧，警示按钮与主按钮保持明显区分。

校验与提交规则：
- 动作校验：高风险按钮点击后先校验当前对象状态，再弹二次确认层。

弹窗/抽屉结构建议：
- 确认弹窗：`测试入口`走轻量确认弹窗；正文展示影响对象、当前状态、风险提示、确认按钮文案。

- 展示规则：页面中的状态字段统一使用标签或时间线展示，主键字段固定前置；如概览卡、筛选项、时间线节点与总表冲突，以状态口径总表为准。
- 风险交互：测试、重推、取消、重试、确认、提交类动作必须二次确认，并在完成后刷新结果区。

控件类型与属性建议：
- `配置概览区`：`当前启用回调数`使用指标卡/摘要值；`失败回调数`使用指标卡/摘要值；`最近测试结果`使用指标卡/摘要值；原型中保持字段名、字段值、状态标签三层信息清晰分离。
- `筛选区`：`接入方`使用下拉单选；`事件类型`使用下拉单选；`状态`使用下拉单选；`最近修改时间`使用日期范围；筛选区默认首行展示高频字段，其余字段进入高级筛选或展开区。
- `列表区`：`回调名称`使用文本列；`事件类型`使用文本列；`目标地址`使用文本列；`状态`使用状态标签列；`最后测试结果`使用状态标签列；主键列可点击，数值列右对齐，状态列使用统一标签色。

校验与提交规则：
- 筛选校验：时间范围需满足开始时间不大于结束时间；下拉筛选值仅允许选择预置枚举，禁止自由输入。
- 动作校验：高风险按钮点击后先校验当前对象状态，再弹二次确认层；保存前校验必填项、格式项和唯一性项，失败时保留已录入数据。

弹窗/抽屉结构建议：
- 维护弹层：`新增配置 / 编辑`走居中弹窗；结构为“标题栏 + 表单区 + 扩展配置区 + 底部取消/保存按钮”，宽度建议 640-720。
- 确认弹窗：`启停 / 回调测试`走轻量确认弹窗；正文展示影响对象、当前状态、风险提示、确认按钮文案。

弹层设计思路：
- `新增配置弹窗`优先承载“新增/编辑回调配置”这类结构化录入任务，目标是让用户在不离开列表页的情况下完成配置创建与修正。
- `回调测试确认弹窗`优先承载“是否立即测试”的风险确认，不再重复展示完整表单，只突出测试对象、目标地址、事件类型、风险提示与确认动作。
- 信息层级遵循“当前对象 > 关键字段 > 风险提示 > 主动作”顺序，避免弹窗内出现第二套复杂导航。
- 设计原则上，新增/编辑弹窗强调录入效率和字段分组；测试确认弹窗强调确认效率和结果预期。

| 新增配置弹窗 | 基础表单区 | 回调名称 | 文本输入框 | 是 | 编辑态回填当前值 | 请输入回调名称 | 去首尾空格，限制最大长度，不允许重复 | 校验失败时字段下方提示 |
| 新增配置弹窗 | 基础表单区 | 接入方 | 下拉单选 | 是 | 新增态默认空，编辑态回填 | 请选择接入方 | 仅允许选择账号有权接入方 | 切换后联动刷新事件类型 |

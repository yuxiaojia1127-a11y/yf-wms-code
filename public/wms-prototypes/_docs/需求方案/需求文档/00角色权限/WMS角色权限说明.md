# WMS角色权限表

## 1. 角色分组

当前版本先按 3 类角色管理，先保证权限边界清楚、表达简单：

| 角色类型/身份 | 包含角色             | 说明                                                                          |
| ------- | ---------------- | --------------------------------------------------------------------------- |
| 系统管理类   | 系统超级管理员、系统运营     | 管平台、管账号、管权限、看全局数据                                                           |
| 仓内作业类   | 仓内管理员、仓内主管、仓内作业员 | 管仓内业务、看仓内进度、执行现场任务                                                          |
| 货主查询类   | 货主、货主员工          | 预约采购入库/生产入库需求、发起调拨需求、查看自家货主相关数据，不参与仓内执行（目前只有自营业务，1.0暂时不提供该功能，待有第三方货主再提供此功能） |

## 2. 简版角色权限总表

| 角色类型  | 角色      | 端       | 主要职责             | 可看数据范围                         | 主要权限                                 | 关键限制                         |
| ----- | ------- | ------- | ---------------- | ------------------------------ | ------------------------------------ | ---------------------------- |
| 系统管理类 | 系统超级管理员 | WEB/APP | 平台治理、账号权限管理、全局排查 | 全量                             | 账号管理、角色管理、权限配置、全局配置、全局业务查看           | 不承担日常仓内作业                    |
| 系统管理类 | 系统运营    | WEB/APP | 平台运营管理、全局排查      | 全量                             | 与系统超级管理员一致                           | 不承担日常仓内作业                    |
| 仓内作业类 | 仓内管理员   | WEB/APP | 仓储业务统筹、现场协同      | 授权货主 + 授权仓库全量数据                | 主数据、入库、库存、出库、发货履约、物流跟踪查看与处理          | 不管理平台账号和全局权限                 |
| 仓内作业类 | 仓内主管    | WEB/APP | 仓内进度跟踪、现场协调      | 授权货主 + 授权仓库范围数据                | 查看任务进度、查看差异、查看异常、协调处理                | 不做平台配置，不做账号授权                |

## 3. 模块权限简表

说明：

- `全权`：可配置、可管理、可查看全量。
- `处理`：可查看并处理业务。
- `查看`：只能查询和查看结果。
- `执行`：只能执行现场作业任务。
- `不可`：默认不可见或不可操作。

| 模块/能力        | 系统超级管理员 | 系统运营 | 仓内管理员 | 仓内主管 | 仓内作业员    | 货主 | 货主员工 |
| ------------ | ------- | ---- | ----- | ---- | -------- | -- | ---- |
| 平台账号、角色、权限配置 | 全权      | 全权   | 不可    | 不可   | 不可       | 不可 | 不可   |
| 店铺管理         | 全权      | 全权   | 处理    | 查看   | 不可       | 查看 | 查看   |
| 入库记录         | 全权      | 全权   | 处理    | 查看   | 执行       | 查看 | 查看   |
| 库存查询         | 全权      | 全权   | 处理    | 查看   | 查看本人任务相关 | 查看 | 查看   |
| 出库记录         | 全权      | 全权   | 处理    | 查看   | 执行       | 查看 | 查看   |
| 销售发货数据       | 全权      | 全权   | 处理    | 查看   | 执行       | 查看 | 查看   |
| 物流结果查询       | 全权      | 全权   | 处理    | 查看   | 查看本人任务相关 | 查看 | 查看   |
| 仓内任务执行       | 全权      | 全权   | 处理    | 处理   | 执行       | 不可 | 不可   |
| 异常上报/处理      | 全权      | 全权   | 处理    | 查看   | 执行上报     | 不可 | 不可   |

## 4. 三类角色的数据边界

| 角色类型  | 数据边界                       |
| ----- | -------------------------- |
| 系统管理类 | 默认全量可见，可看所有货主、仓库、店铺和业务数据   |
| 仓内作业类 | 按授权仓库和货主控制；作业员默认只看本人任务     |
| 货主查询类 | 只看自家货主数据，不看其他货主，不看仓内员工任务数据 |

## 5. 当前口径

| 项目     | 说明                                             |
| ------ | ---------------------------------------------- |
| 当前主角色  | 先收敛为 7 个：系统超级管理员、系统运营、仓内管理员、仓内主管、仓内作业员、货主、货主员工 |
| 当前表达方式 | 先按 3 大类角色表达，不再拆太多专员角色                          |
| 货主权限重点 | 明确可看自家 `库存 / 入库 / 出库 / 发货 / 物流结果`，不可看其他货主数据    |
| 后续如需细化 | 再从仓内作业类中拆出物流、售后、调拨、异常等专员角色                     |

# WMS_APP端信息架构

## 1. 产品定位

`WMS_APP端` 是 WMS 的仓内一线执行端，负责承接后台下发的仓内作业任务，完成收货、上架、备货、扫码核销、复核、出库、物流交接、退货质检、调拨执行、仓内作业和异常上报等动作。

与当前版本原型结构一致，物流能力不再独立拆系统，而是作为 `WMS_APP端` 内的现场物流协同模块处理，重点承接出库后的物流方式选择、交接确认、运单回看和现场物流异常反馈。

## 2. 使用角色

| 角色类型 | 主要职责 | 数据范围 | 关键限制 |
| ---- | ---- | ---- | ---- |
| 系统管理类 | 登录排查、权限确认、全局巡检 | 全量或只读巡检范围 | 当前不承担日常仓内作业 |
| 仓内作业类 | 入库、上架、备货、复核、交接、调拨、异常上报与现场协调 | 按授权仓库和货主控制；作业员默认本人任务 | 不负责平台级账号权限配置 |
| 货主查询类 | 当前版本不使用 APP 端 | 不适用 | 当前默认不开放 APP 端使用 |

## 4. 全局规则

### 页面标准结构

后续文档按“两层结构”表达页面信息，避免页面清单与页面原型说明字段不一致：

| 字段 | 说明 |
| ---- | ---- |
| 页面清单字段 | `页面目标 / 使用角色 / 页面入口 / 优先级 / 核心操作` |
| 页面原型说明补充字段 | `需求来源 / 页面布局` |
| 使用原则 | 页面清单保持轻量，页面原型说明负责补足来源、布局、状态和交互细节 |

| 规则 | 说明 |
| ---- | ---- |
| 在线作业 | 所有扫码、核销、提交均实时请求 WMS |
| 任务锁定 | 接单后任务锁定到当前作业人，避免重复处理 |
| 上下文统一 | 所有任务和数据受当前货主/仓库上下文影响 |
| 店铺只在必要任务展示 | 发货履约任务、退货任务显示店铺；入库和调拨任务默认按货主+仓库执行 |
| 高风险操作确认 | 出库确认、物流交接确认、异常完结、任务转派需二次确认 |
| 统一术语 | 使用“备货”代替旧稿中的“揽货” |

## 5. 任务中心模型

### 5.1 任务类型

| 任务类型 | 说明 |
| ---- | ---- |
| 发货履约任务 | 对发货履约单进行备货、扫码核销、复核、出库确认 |
| 入库收货任务 | 承接采购入库、调拨入库、退货入库的现场收货 |
| 上架任务 | 承接收货完成后的货位确认和上架提交 |
| 调拨出库任务 | 承接调拨单的备货、复核和发运 |
| 调拨入库任务 | 承接调拨到仓后的收货和上架 |
| 物流交接任务 | 承接出库后的物流方式选择、交接确认、运单回看 |
| 退货处理任务 | 承接退货收货、质检、回库或报损 |
| 仓内作业任务 | 承接加工单、库内转移单 |
| 异常处理任务 | 对现场异常进行提报和跟进 |

### 5.2 状态模型

| 任务类型 | 状态流转 |
| ---- | ---- |
| 发货履约任务 | 待接单 -> 待备货 -> 待复核 -> 待出库 -> 待物流交接 -> 已完成 |
| 入库收货任务 | 待接单 -> 待收货 -> 待上架 -> 已完成 |
| 调拨出库任务 | 待接单 -> 待备货 -> 待复核 -> 待物流交接 -> 已发运 |
| 调拨入库任务 | 待接单 -> 待收货 -> 待上架 -> 已完成 |
| 物流交接任务 | 待交接 -> 已交接 / 交接异常 |
| 退货处理任务 | 待接单 -> 待收货 -> 待质检 -> 已完成 |
| 仓内作业任务 | 待接单 -> 处理中 -> 已完成 |

### 5.3 任务关键动作

| 动作 | 说明 |
| ---- | ---- |
| 接单 | 锁定任务归属到当前作业人 |
| 开始收货 | 进入收货录入流程 |
| 开始备货 | 进入扫码与核销流程 |
| 扫码核销 | 在线校验 SKU、批次、数量是否匹配 |
| 复核提交 | 校验实操结果与任务计划是否一致 |
| 上架确认 | 提交货位、批次、数量上架结果 |
| 物流交接确认 | 选择物流方式、记录交接人和时间 |
| 运单回看 | 查看出库后生成的运单和当前状态 |
| 异常登记 | 记录破损、少收、批次不符、码不匹配、物流交接异常 |
| 完成提交 | 触发 WMS 更新库存、单据状态或结果回传 |

## 6. 功能模块结构

| 一级模块 | 二级菜单/功能 | 说明 | 需求来源 |
| ---- | ---- | ---- | ---- |
| 工作台 | 数据概览、快捷入口 | 展示待收货、待备货、待复核、待上架、待交接等统计 | WMS_APP端 / 作业工作台 |
| 上下文选择 | 货主/仓库切换 | 选择当前作业仓库与任务范围 | WMS_APP端 / 通用基础能力 |
| 任务中心 | 全部任务、我的任务、任务详情 | 统一处理不同任务类型 | WMS_APP端 / 作业工作台、通用任务承载 |
| 扫码作业 | 备货扫码、收货扫码、复核扫码 | 仓内扫码核心入口 | WMS_APP端 / 出库作业、入库作业 |
| 入库作业 | 收货录入、上架确认 | 采购入库、调拨入库、退货入库执行 | WMS_APP端 / 入库作业 |
| 出库作业 | 发货履约、调拨出库 | 备货、复核、出库确认 | WMS_APP端 / 出库作业、调拨作业 |
| 物流协同 | 物流交接、运单回看 | 出库后的现场物流处理模块 | WMS_APP_物流系统 |
| 售后作业 | 退货质检 | 收货、质检、回库/报损 | WMS_APP端 / 售后作业 |
| 仓内作业 | 加工与库内转移 | 非标准仓内任务 | WMS_APP端 / 仓内作业 |
| 异常中心 | 异常上报、异常处理记录 | 保证现场问题闭环 | WMS_APP端 / 异常作业、WMS_APP_物流系统 / 物流异常作业 |
| 我的 | 账号、权限、版本信息 | 查看个人范围和系统状态 | WMS_APP端 / 通用基础能力 |

## 8. 第一批原型范围建议

| 模块 | 页面方向 |
| ---- | ---- |
| 登录与上下文 | 登录页、货主/仓库上下文选择 |
| 工作台与任务中心 | 工作台、全部任务、我的任务 |
| 发货履约执行 | 发货任务详情、备货扫码、复核与出库确认 |
| 物流协同 | 物流交接确认、运单回看 |
| 入库执行 | 收货任务详情、收货录入页 |
| 异常处理 | 异常上报页、网络重试提示 |

## 9. 原型设计注意事项

| 注意项 | 说明 |
| ---- | ---- |
| 不再出现独立物流系统视角 | 现场物流能力放在 App 的物流协同模块 |
| 任务以仓库执行为中心 | 默认围绕货主+仓库处理任务，不以门店作为主上下文 |
| 发货任务展示店铺但不以店铺作库存归属 | 发货履约单仅在履约对象层展示店铺 |
| 扫码反馈要强实时性 | 扫码成功/失败要即时反馈，不允许弱提示 |
| 物流交接要和出库动作衔接 | 出库确认后直接进入交接确认，不增加割裂流程 |
| 高并发冲突要可感知 | 已被他人接单、任务失效、状态变更需有明确提示 |

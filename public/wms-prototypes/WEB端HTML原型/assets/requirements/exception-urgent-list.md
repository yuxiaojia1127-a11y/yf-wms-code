# WMS-WEB 超时/紧急列表简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 超时/紧急列表 |
| 所属模块 | 异常中心 |
| 页面定位 | 承接驾驶舱“超时 / 紧急待办”模块的下钻查看与处理入口 |
| 页面编码 | `WMS-WEB-032A` |
| 适用端 | WMS-WEB 管理端 |

## 2. 业务说明

超时/紧急列表用于集中承接驾驶舱中“超时 / 紧急待办”模块的明细数据，帮助仓内管理角色从卡片浏览切换到列表处理模式。

页面需与驾驶舱当前模块保持同一批待办数据口径，只改变展示形态，不额外引入新的业务口径。用户进入页面后，可通过查询条件快速筛选待办记录，支持导出当前筛选结果，并可查看单条待办详情，定位当前责任人、所属仓库、待办类型、等待时长和处理建议。

## 3. 功能描述

- 支持从驾驶舱“超时 / 紧急待办”模块点击进入超时/紧急列表页面。
- 支持在异常中心菜单下新增“超时/紧急列表”菜单入口。
- 支持列表展示与驾驶舱当前模块一致的待办数据。
- 支持按仓库、待办类型、紧急等级、处理人、关键词进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持点击“查看详情”后以抽屉形式查看单条待办详情。

## 4. 查询条件

| 字段名称 | 字段类型 | 查询方式 | 暗字提示 |
| ---- | ---- | ---- | ---- |
| 仓库 | 下拉单选 | 精确筛选 | 默认全部授权仓库 |
| 待办类型 | 下拉单选 | 精确筛选 | 如待入库、待接单揽货、待揽货、待打包复核、待发货、待接单、重新派单 |
| 紧急等级 | 下拉单选 | 精确筛选 | 全部 / 紧急 / 预警 |
| 处理人 | 下拉单选 | 精确筛选 | 默认全部处理人 |
| 关键词 | 输入框 | 模糊查询 | 支持单号 / 仓库 / 摘要关键词 |

## 5. 列表字段

| 字段名称 | 字段类型 | 是否必填 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 单号 | 文本 | 是 | `SO-240603-218` | 待办或异常单号 |
| 待办类型 | 标签 | 是 | 待入库 | 展示当前待办类型，与驾驶舱作业漏斗节点状态保持一致 |
| 仓库 | 文本 | 是 | 2号仓库 | 展示当前责任仓库 |
| 摘要信息 | 文本 | 是 | 2号仓库 · 即时配送 · 已等待 132 分钟 | 与驾驶舱模块口径一致 |
| 处理人 | 文本 | 是 | 陈晨 | 当前责任人或领取人 |
| 等待时长 | 数值 | 是 | 132 分钟 | 用于判断紧急程度 |
| 紧急等级 | 标签 | 是 | 紧急 / 预警 | 根据等待时长与卡片等级展示 |
| 更新时间 | 时间 | 是 | 2026-06-04 10:30 | 最近一次同步时间 |
| 操作 | 按钮 | 是 | 查看详情 | 查看当前待办详情 |

## 6. 翻页与空态

- 默认按等待时长倒序展示。
- 默认每页展示 10 条。
- 支持分页查看。
- 当前筛选条件下无数据时，列表展示空态并保留查询条件。

## 7. 查看详情

- 点击“查看详情”后，从页面右侧打开详情抽屉。
- 详情抽屉至少展示：单号、待办类型、仓库、摘要信息、处理人、等待时长、紧急等级、当前状态、推荐处理动作。
- 当前状态按等待时长判定：超过 60 分钟为 `已超时`，否则为 `待处理`。
- 详情抽屉支持点击右上角关闭按钮、遮罩空白处关闭。
- 详情抽屉底部提供“进入对应页面”按钮，用于跳转到相关业务页面继续处理。

## 8. 关键规则

- 页面数据口径与驾驶舱“超时 / 紧急待办”模块保持一致。
- 待办类型与驾驶舱作业漏斗节点状态保持一致：待入库、待接单揽货、待揽货、待打包复核、待发货、待接单、重新派单。
- 驾驶舱入口默认跳转到该页面，不再直接进入“异常与工单”列表。
- 紧急等级按当前驾驶舱模块规则展示，红色项优先显示。
- 处理人属于必展示字段，用于快速定位当前责任对象。
- 导出范围为当前筛选结果，不导出未命中的记录。

## 9. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在待办数据 | 展示查询区、列表、分页与详情 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无异常中心权限 | 展示无权限提示，不显示列表 |
| 数据延迟 | 数据刷新存在延迟 | 页面顶部展示更新时间说明 |

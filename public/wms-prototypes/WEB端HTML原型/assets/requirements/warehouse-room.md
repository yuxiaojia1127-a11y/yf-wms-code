# 库房管理原型设计说明

**版本**：v1.0  
**日期**：2026-06-10  
**页面编号**：`WMS-WEB-W07`  
**所属模块**：仓储管理  
**依赖文档**：库房管理简易需求文档

---

## 1. 设计目标

库房管理作为仓库管理的下辖模块，为 WMS 引入"仓库 → 库房"两级履约结构。本文档定义库房管理页面的信息架构、页面结构、字段规则、交互逻辑，以及全局 UI 规范。

---

## 2. 信息架构

```text
仓储管理
├─ 仓库管理（已有）
└─ 库房管理（新增）
   ├─ 库房列表
   ├─ 库房详情（右侧抽屉）
   └─ 库房新增/编辑（右侧抽屉）
```

货位管理层级同步调整：

```text
仓库 → 库房 → 货位（原：仓库 → 库区 → 货位）
```

---

## 3. 页面结构

### 3.1 库房列表页

```text
顶部标题区
├─ 页面标题：库房管理
└─ 关键统计：库房总数 / 启用库房 / 停用库房

筛选区（横向展开）
├─ 所属仓库（下拉单选，必填筛选项）
├─ 库房类型（下拉单选）
├─ 库房状态（下拉单选：启用 / 停用）
├─ 库房编码（输入框，模糊搜索）
└─ 库房名称（输入框，模糊搜索）

页面级操作区（筛选区右侧对齐）
├─ 查询
├─ 重置
├─ 新建库房
└─ 导出

列表区
├─ 勾选框
├─ 库房编码
├─ 库房名称
├─ 所属仓库
├─ 库房类型
├─ 面积（㎡）
├─ 货位数量（可跳转货位管理）
├─ 状态（标签）
├─ 创建时间
└─ 操作（查看 / 编辑 / 启用·停用）

分页区
└─ 总条数 / 已选条数 / 页码切换
```

### 3.2 库房详情 / 新增 / 编辑（右侧抽屉）

```text
抽屉标题
├─ 新增模式：新建库房
├─ 查看模式：库房详情
└─ 编辑模式：编辑库房

内容分组

【基础信息】
├─ 库房编码（新增时系统生成，只读；编辑/查看时回显）
├─ 库房名称（必填）
├─ 所属仓库（必填，下拉，仅展示当前用户有权限的启用仓库）
├─ 库房类型（下拉：常温库 / 冷藏库 / 冷冻库 / 危化品库 / 其他）
└─ 状态（必填，下拉：启用 / 停用）

【空间信息】
├─ 面积（㎡）（数字输入框）
└─ 备注（多行输入框）

【关联信息】（查看模式展示，新增/编辑隐藏）
└─ 货位数量（文本，点击跳转货位管理并过滤当前库房）

抽屉底部操作
├─ 查看模式：关闭 / 去编辑
├─ 新增/编辑模式：取消 / 保存
```

## 4. 字段规则

| 字段 | 规则说明 |
|------|---------|
| 库房编码 | 新建时系统自动生成，格式建议 `WH{仓库编码}-R{序号}`；同一仓库下唯一，不可重复 |
| 库房名称 | 同一仓库下唯一，不可重复；最大长度 50 字符 |
| 所属仓库 | 联动过滤下游字段（货位管理的仓库-库房级联）；停用仓库不可选 |
| 库房类型 | 选填，默认为"常温库" |
| 状态 | 默认"启用"；停用后该库房不出现在新建单据的库房选项中，但已有在途/未完结单据不受影响 |

---

## 5. 列表操作规则

### 4.1 启用 / 停用

- 点击"停用"弹出居中确认弹框，提示："停用后该库房将不可用于新建单据，是否确认停用？"
- 确认后切换状态，列表状态标签实时刷新
- 已停用库房点击"启用"直接切换，无需二次确认

### 4.2 删除

- 当前版本不提供删除入口（软删除策略，通过停用替代）
- 如后续引入删除，需校验：该库房下无启用货位、无在途单据

### 4.3 货位数量跳转

- 列表"货位数量"列为可点击蓝色文本链接
- 点击后跳转至货位管理页，自动带入"所属库房=当前库房"筛选条件

---

## 6. 单据联动改造说明

### 5.1 通用改造（所有单据）

所有 WMS-WEB 单据新增"库房"字段，规则：
- 位于"仓库"字段之后
- 库房选项根据已选仓库动态联动过滤（仅展示启用状态库房）
- 历史数据演示原型阶段：统一按所属仓库配置一个默认库房进行回填

### 5.2 调拨单专项改造

调拨单字段结构扩展为：

| 字段顺序 | 字段名称 | 规则 |
|---------|---------|------|
| 1 | 源仓库 | 调出实体仓库 |
| 2 | 源库房 | 联动源仓库，展示启用库房 |
| 3 | 目标仓库 | 调入实体仓库 |
| 4 | 目标库房 | 联动目标仓库，展示启用库房 |

## 7. 货位管理层级改造说明

货位管理中新增"所属库房"字段，层级调整为：

```text
仓库 → 库房 → 货位
```

- 货位列表筛选区新增"所属库房"（联动所属仓库）
- 货位新增/编辑抽屉中，选择仓库后，库房选项联动过滤
- 货位编码建议规则延伸：`WH{仓库}-R{库房}-{原货位编码}`

## 11. 前端 UI 规范

### 10.1 导航方式

- **菜单位置**：库房管理挂载在左侧一级菜单"仓储管理"下，作为二级菜单项，排在"仓库管理"之后
- **路由规则**：`/warehouse/room`，与仓库管理 `/warehouse` 同级目录下
- **面包屑**：`仓储管理 / 库房管理`，详情抽屉不单独产生新的面包屑层级
- **菜单高亮**：进入库房管理页面后，左侧"库房管理"菜单项保持高亮选中态
- **页面内跳转**：货位数量点击跳转使用路由跳转（非新开 Tab），跳转后目标页筛选条件自动带入并执行查询

### 10.2 页面布局

- **整体布局**：左侧固定导航栏（折叠宽 64px / 展开宽 220px）+ 右侧内容区，内容区顶部为全局面包屑与页面标题
- **筛选区**：横向一行排列，超出换行，右侧对齐"查询 / 重置 / 新建 / 导出"操作按钮组
- **列表区**：标准表格，行高 48px，首列为勾选框，末列为操作列固定右侧（sticky）
- **分页区**：表格底部左对齐展示"共 N 条"，右侧为页码切换器，默认每页 20 条，可选 10 / 20 / 50
- **右侧抽屉**：宽度 480px，从右侧滑入覆盖，不遮挡左侧导航；抽屉内容区可滚动，底部操作按钮固定在抽屉底部

### 10.3 组件行为

**下拉联动**
- 选择"所属仓库"后，"库房"下拉立即清空并重新加载该仓库下启用的库房列表
- 切换仓库时，库房字段自动 reset，不保留上一次选项

**表单校验**
- 保存时统一触发全字段校验，校验不通过的字段下方展示红色错误提示文案
- 必填项输入框边框变红色（`#FF4D4F`）
- 错误提示文案示例："库房名称不能为空"、"该仓库下库房名称已存在"

**抽屉关闭**
- 点击抽屉右上角 × 按钮、点击遮罩层空白区域、点击"取消"按钮均可关闭抽屉
- 若表单有未保存修改，关闭前弹出二次确认："当前修改尚未保存，是否放弃？"，确认后关闭，取消后返回抽屉

**表格行为**
- 行 hover 时背景变浅蓝灰色（`#F5F7FA`）
- 操作列默认展示"查看 / 编辑"，启停操作根据当前状态切换显示"停用" or "启用"
- 多操作超出时收入"更多"下拉菜单

**空态**
- 列表无数据时居中展示空态插图 + 提示文案："暂无数据，请调整筛选条件"
- 若是首次进入无任何库房，额外展示"新建库房"引导按钮

### 10.4 状态颜色规范

| 状态 | 标签文案 | 标签底色 | 文字颜色 | 说明 |
|------|---------|---------|---------|------|
| 启用 | 启用 | `#F6FFED` | `#52C41A` | 绿色，表示可用 |
| 停用 | 停用 | `#FFF2F0` | `#FF4D4F` | 红色，表示不可用 |

通用状态色参考：

| 语义 | 颜色值 | 使用场景 |
|------|--------|---------|
| 成功 / 启用 | `#52C41A` | 成功状态、启用标签 |
| 警告 | `#FAAD14` | 在途状态、待处理提示 |
| 错误 / 停用 | `#FF4D4F` | 停用标签、校验错误 |
| 信息 / 链接 | `#1677FF` | 可点击文本链接（如货位数量跳转） |
| 中性 / 禁用 | `#D9D9D9` | 禁用按钮、只读字段边框 |

### 10.5 操作反馈

| 操作 | 反馈方式 | 反馈文案 |
|------|---------|---------|
| 新建保存成功 | 右上角 Toast（绿色，3s 自动关闭） | "库房创建成功" |
| 编辑保存成功 | 右上角 Toast（绿色，3s 自动关闭） | "库房信息已更新" |
| 停用成功 | 右上角 Toast（绿色，3s 自动关闭） | "库房已停用" |
| 启用成功 | 右上角 Toast（绿色，3s 自动关闭） | "库房已启用" |
| 保存失败（校验不通过） | 表单内联报错（字段级红色提示） | 各字段对应错误文案 |
| 保存失败（接口错误） | 右上角 Toast（红色，5s 自动关闭） | "保存失败，请稍后重试" |
| 导出触发 | 右上角 Toast（蓝色，3s 自动关闭） | "正在导出，请稍候…" |
| 导出完成 | 右上角 Toast（绿色，3s 自动关闭）+ 浏览器下载 | "导出完成" |
| 停用二次确认 | 居中 Modal 弹框 | "停用后该库房将不可用于新建单据，是否确认停用？" 操作按钮：取消 / 确认停用 |
| 放弃编辑确认 | 居中 Modal 弹框 | "当前修改尚未保存，是否放弃？" 操作按钮：继续编辑 / 放弃 |

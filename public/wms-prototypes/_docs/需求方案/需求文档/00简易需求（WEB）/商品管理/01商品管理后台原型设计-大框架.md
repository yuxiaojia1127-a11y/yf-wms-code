# 商品管理后台原型设计（大框架）

## 1. 设计目标

商品管理后台原型按“角色工作台 + 商品治理对象”组织，先解决不同用户进入系统后看到什么、处理什么、从哪里进入下一层的问题。

本阶段只定义页面结构、角色入口、主视图和模块关系，不展开字段级、按钮级和交互细节。

## 2. 角色与使用场景

### 2.1 角色划分

| 角色 | 使用目标 | 数据范围 | 核心关注点 |
| --- | --- | --- | --- |
| 货主用户 | 查询和维护本货主商品 | 本货主商品 | 商品是否已建档、是否启用、是否同步成功、仓储规则是否正确 |
| WMS商品运营 | 管理全量货主商品 | 全部货主商品 | 多货主商品查询、商品状态、同步状态、货主资料质量 |
| WMS商品治理 | 管理商品识别档案和异常 | 全部识别档案和异常数据 | 同品识别、识别冲突、跨货主供给候选、异常处理闭环 |

### 2.2 工作台划分

商品管理后台拆成三个工作台：

| 工作台 | 面向角色 | 页面定位 |
| --- | --- | --- |
| 我的商品 | 货主用户 | 货主查看和维护自己的商品数据 |
| 货主商品管理 | WMS商品运营 | WMS查看所有货主的商品数据 |
| 商品识别与异常治理 | WMS商品治理 | WMS查看商品识别档案、同品候选和异常数据 |

这三个工作台使用同一套底层商品数据，但展示口径、默认筛选、可操作范围不同。

## 3. 顶层信息架构

```text
商品管理
├─ 我的商品
│  ├─ 商品列表
│  ├─ 商品详情
│  ├─ 商品新增/编辑
│  └─ 同步记录
├─ 货主商品管理
│  ├─ 全量商品列表
│  ├─ 货主商品详情
│  ├─ 商品同步管理
│  └─ 商品变更日志
└─ 商品识别与异常治理
   ├─ 商品识别档案
   ├─ 同品候选归集
   ├─ 识别冲突处理
   ├─ 供给关系候选
   └─ 异常处理记录
```

## 4. 导航设计

### 4.1 菜单结构

| 一级菜单 | 二级菜单 | 面向角色 | 说明 |
| --- | --- | --- | --- |
| 商品管理 | 我的商品 | 货主用户 | 货主默认入口 |
| 商品管理 | 货主商品管理 | WMS商品运营 | WMS运营默认入口 |
| 商品管理 | 商品识别档案 | WMS商品治理 | 查看识别商品ID、归集商品和识别摘要 |
| 商品管理 | 识别异常处理 | WMS商品治理 | 处理冲突待处理、规则不兼容、重复候选 |
| 商品管理 | 供给关系管理 | WMS商品治理 / WMS商品运营 | 管理跨货主供给关系 |

### 4.2 首页入口策略

| 登录角色 | 默认进入页面 | 默认数据范围 |
| --- | --- | --- |
| 货主用户 | 我的商品 | 当前货主 |
| WMS商品运营 | 货主商品管理 | 全部货主 |
| WMS商品治理 | 商品识别与异常治理 | 全部识别档案和异常 |

## 5. 页面框架设计

### 5.1 我的商品

页面定位：货主侧商品自助管理页面。

主区域结构：

```text
顶部标题区
├─ 页面标题：我的商品
├─ 关键统计：商品总数 / 启用商品 / 同步失败 / 异常提示

筛选区
├─ 商品状态
├─ 同步状态
├─ 商品类型
├─ 货主SKU编码
├─ 商品名称
└─ 条码

列表区
├─ 货主SKU编码
├─ 商品名称
├─ 条码
├─ 基础单位
├─ 规格关键值
├─ 仓储规则
├─ 商品状态
├─ 同步状态
└─ 操作

详情抽屉
├─ 基础资料
├─ 规格与计量
├─ 仓储规则
└─ 同步记录
```

货主用户关注“我的商品能不能正常入库、出库、同步”，页面不突出全平台识别档案和跨货主供给治理能力。

### 5.2 货主商品管理

页面定位：WMS运营查看和管理全量货主商品。

主区域结构：

```text
顶部标题区
├─ 页面标题：货主商品管理
├─ 关键统计：货主数 / 商品总数 / 同步失败 / 识别异常 / 停用商品

筛选区
├─ 货主
├─ 商品状态
├─ 同步状态
├─ 识别状态
├─ 供给状态
├─ 货主SKU编码
├─ WMS商品编码
├─ 识别商品ID
├─ 商品名称
└─ 条码

列表区
├─ 货主
├─ WMS商品编码
├─ 货主SKU编码
├─ 商品名称
├─ 识别商品ID
├─ 主条码
├─ 基础单位
├─ 规格关键值
├─ 仓储规则
├─ 识别状态
├─ 供给状态
├─ 商品状态
├─ 同步状态
└─ 操作

详情抽屉
├─ 货主商品资料
├─ WMS商品编码与识别信息
├─ 仓储规则
├─ 同步记录
└─ 操作日志
```

WMS商品运营关注“全量商品是否可控、资料是否完整、同步是否正常、异常是否可追踪”。

### 5.3 商品识别与异常治理

页面定位：WMS治理商品识别档案、同品候选和异常。

主区域结构：

```text
顶部标题区
├─ 页面标题：商品识别与异常治理
├─ 关键统计：识别档案数 / 候选中 / 已生效 / 冲突待处理 / 供给候选

左侧任务分组
├─ 全部识别档案
├─ 同品候选
├─ 冲突待处理
├─ 供给候选
└─ 已处理记录

主列表区
├─ 识别商品ID
├─ 主条码
├─ 基础单位
├─ 规格关键值
├─ 仓储规则摘要
├─ 关联货主商品数
├─ 识别状态
├─ 异常类型
└─ 更新时间

右侧详情区/抽屉
├─ 识别档案摘要
├─ 关联货主商品
├─ 冲突字段对比
├─ 处理动作
└─ 处理日志
```

商品识别与异常治理页面关注“系统识别出来的同品关系是否准确、冲突是否处理、供给关系是否具备配置基础”。

## 6. 三类页面之间的关系

### 6.1 数据关系

```text
货主商品
  ├─ 生成 WMS商品编码
  ├─ 进入 WMS商品识别档案
  ├─ 形成 同品候选/识别异常
  └─ 进入 跨货主供给关系配置范围
```

### 6.2 页面跳转关系

| 来源页面 | 触发点 | 目标页面 |
| --- | --- | --- |
| 我的商品 | 查看详情 | 货主商品详情 |
| 货主商品管理 | 点击识别商品ID | 商品识别档案详情 |
| 货主商品管理 | 点击识别异常 | 识别异常处理 |
| 商品识别档案 | 查看关联商品 | 货主商品管理过滤结果 |
| 识别异常处理 | 完成处理 | 商品识别档案详情 |
| 商品识别档案 | 配置供给关系 | 供给关系管理 |

## 7. 权限与展示差异

| 能力 | 货主用户 | WMS商品运营 | WMS商品治理 |
| --- | --- | --- | --- |
| 查看本货主商品 | 支持 | 支持 | 支持 |
| 查看全量货主商品 | 不支持 | 支持 | 支持 |
| 新增/编辑本货主商品 | 支持 | 支持 | 按授权支持 |
| 启用/停用商品 | 支持本货主 | 支持全量 | 按授权支持 |
| 查看识别商品ID | 弱展示 | 支持 | 支持 |
| 查看识别档案详情 | 不作为主入口 | 支持跳转 | 支持 |
| 处理识别异常 | 不支持 | 可查看 | 支持 |
| 维护供给关系 | 不支持 | 可查看或提交 | 支持审核生效 |
| 查看同步日志 | 支持本货主 | 支持全量 | 支持 |

## 8. 原型第一版页面优先级

### 8.1 第一优先级

| 页面 | 目标 |
| --- | --- |
| 我的商品 | 建立货主视角的商品查询和维护入口 |
| 货主商品管理 | 建立WMS视角的全量商品管理入口 |
| 商品识别档案 | 建立WMS商品识别结果查看入口 |

### 8.2 第二优先级

| 页面 | 目标 |
| --- | --- |
| 识别异常处理 | 支持冲突待处理和字段对比 |
| 供给关系管理 | 支持跨货主供给配置和状态控制 |
| 商品同步日志 | 支持同步失败排查 |

## 9. 大框架结论

商品管理后台原型按“两类角色、三个工作台”设计：

1. 货主用户使用“我的商品”，只处理本货主商品资料、仓储规则和同步状态。
2. WMS商品运营使用“货主商品管理”，查看和管理所有货主商品。
3. WMS商品治理使用“商品识别与异常治理”，处理识别档案、同品候选、冲突异常和供给关系基础数据。

第一版原型先完成菜单结构、三类工作台、列表主视图、详情抽屉和页面跳转关系，再进入字段细节和交互细节设计。

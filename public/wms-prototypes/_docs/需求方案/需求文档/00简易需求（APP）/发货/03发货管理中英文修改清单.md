## 0. 给 AI 的执行说明（请先读）

1. 本清单只改 **截图中可见的 UI 文案（中文 + 英文）**，不改业务逻辑、不改字段 key、不改接口参数。
2. 所有 `改前` 均取自截图实际显示文案；截图中未出现的页面或字段，不在本次范围。
3. 严格按下方「改前 → 改后」表替换，注意大小写与标点（如 `Order No.` 的点、`Same-day`、`Postcode`）。
4. 英文界面下仍显示中文的值（当日配送 / 尽快送达 / 订单处理弹窗整体）属漏翻，需翻译（见第 4、7 节）。
5. 改完后输出「已修改文件 + 行号」清单，便于人工复核。
6. 标注「待确认」的项需产品确认后再改，不要擅自决定。

## 8. 已确认口径

- 模块名：发货 = **Shipping**（工作台 Delivery → Shipping）
- 待发货 = **To Ship**（To Dispatch / Pending → To Ship）
- 物流发货 = **Carrier Shipping**（Standard Ship / Logistics → Carrier Shipping）
- 统一发货 = **Ship Together**（Ship All → Ship Together）
- 配送方式 = **Delivery Method**；用户预约时间/送达时间选择 = **Scheduled Delivery Time**
- 邮编 = **Postcode**；商品数量标签 = **Qty**；商品缺货时 = **Stockout Handling**；订单备注 = **Order Note**；下单用户 = **Ordered By**
- 订单处理弹窗英文界面需整体翻译

> 本清单暂无待确认项；「Continue & Refund OOS」改写为完整句如需更简短可由产品再定。

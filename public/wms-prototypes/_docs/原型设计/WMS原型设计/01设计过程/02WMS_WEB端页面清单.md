# WMS_WEB端页面清单

## 1. 页面优先级说明

| 优先级 | 定义 |
| ---- | ---- |
| P0 | 第一批必须进入原型，覆盖接入运维、库存、出入库、履约主链路 |
| P1 | 第二批进入原型，补齐物流协同、调拨、扩展主数据和执行跟踪 |
| P2 | 第三批进入原型，补齐退货、面单和物流账单等次高频页面 |
| P3 | 后续增强能力，可在主链路稳定后展开 |

## 4. 页面状态要求

每个列表页至少考虑以下状态：

| 状态 | 说明 |
| ---- | ---- |
| 默认 | 展示当前货主和当前上下文下的最近数据 |
| 筛选中 | 支持货主、店铺、仓库、状态、时间、关键字筛选 |
| 空数据 | 当前条件下无记录 |
| 加载失败 | 接口失败或网络失败 |
| 无权限 | 当前账号无对应模块或上下文权限 |
| 操作成功 | 保存、确认、重推、导出等操作成功 |
| 操作失败 | 状态冲突、字段校验失败、接口失败 |

## 5. 关键操作控件建议

| 场景 | 控件形态 |
| ---- | ---- |
| 查询与筛选 | 顶部筛选区 + 高级筛选抽屉 |
| 列表操作 | 行内操作 + 批量操作 + 状态标签 |
| 详情查看 | 详情页优先，轻量内容可用抽屉 |
| 回调测试/重推 | 二次确认弹窗 + 返回结果面板 |
| 状态时间线 | 纵向时间线 + 节点说明 |
| 物流轨迹 | 模式标签 + 节点时间线 + 失败原因面板 |
| 风险字段 | 临期、过期、失败、异常使用醒目标签 |

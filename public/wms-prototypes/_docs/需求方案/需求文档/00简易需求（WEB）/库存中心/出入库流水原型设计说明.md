# 出入库流水原型设计说明

## 1. 设计目标

- 基于 [stock-flow.md](../../../../../WEB端HTML原型/assets/requirements/stock-flow.md) 输出可直接用于绘制原型的页面设计说明
- 覆盖出入库流水列表页、流水详情抽屉两个页面
- 帮助仓库管理员、财务对账人员快速追溯：哪个 SKU、在哪个仓库、因哪笔业务单据发生了库存增减，以及变动当时的余额快照

---

## 2. 设计范围

### 2.1 本期范围

- 出入库流水列表页（含筛选区 + 列表区）
- 流水详情抽屉（右侧滑出式）

### 2.2 暂不涉及

- 批次维度流水的效期信息展开（待批次管理模块完善后补充）
- 库位维度流水下钻至货位库存（由库存明细列表承载）
- 流水异常标记与处理入口（属库存异常模块）

| 来源页面 | 触发动作 | 目标页面 | 带入参数 |

## 6. 页面级原型设计

### 6.1 出入库流水列表页

**页面目标**

供仓库管理员、财务对账人员查询任意时间段内某 SKU、某仓库的库存流水明细，核对每次变动的数量与余额快照，追溯入库 / 出库 / 调整等业务来源。

**页面布局**

```text
标题区
├─ 标题：出入库流水
└─ 说明文字：记录库存每次变动明细及变动时余额快照，仅支持查询与导出

统计概览区（4 张指标卡，基于当前查询结果实时统计）
├─ 流水总条数
├─ 入库流水条数（流水类型=入库）
├─ 出库流水条数（流水类型=出库）
└─ 调整 / 其他流水条数（调整 + 盘点 + 冻结 + 解冻 + 锁定 + 解锁）

查询筛选区（两行布局，每行 4 个字段）
第一行
├─ 仓库（下拉单选，默认全部授权仓库）
├─ SKU 编码（输入框，精确 / 模糊）
├─ 商品名称（输入框，模糊）
└─ 商品分类（级联下拉，支持多级展开，选中父级包含所有子级）
第二行
├─ 流水类型（下拉多选：入库 / 出库 / 调整 / 盘点 / 冻结 / 解冻 / 锁定 / 解锁）
├─ 业务类型（下拉多选，与流水类型联动：采购入库 / 退货入库 / 调拨入库 / 销售出库 / 调拨出库 / 报损出库 / 库存调整 / 盘点 / 其他）
├─ 来源单号（输入框，精确查询）
└─ 变动方向（下拉单选：全部 / 增加(+) / 减少(-)）
操作时间（日期范围选择器，独占一行，默认最近 7 天，最大 90 天）
操作按钮：【查询】【重置】【导出】，右对齐

流水列表区
列表字段（从左至右）：
├─ 流水号（文本，可点击复制）
├─ 发生时间（精确到秒，默认倒序）
├─ 仓库
├─ 库房
├─ 商品信息（商品名称 + SKU 编码，两行展示）
├─ 商品分类（完整路径，多级以 > 分隔）
├─ 流水类型（标签：入库=绿色 / 出库=红色 / 调整=蓝色 / 盘点=紫色 / 冻结=橙色 / 解冻=青色 / 锁定=灰色 / 解锁=浅灰）
├─ 业务类型（文本）
├─ 来源单号（文字链接，可点击跳转源单）
├─ 批次号（有批次时显示，无则「-」）
├─ 变动数量（正数绿色加「+」，负数红色加「-」，含单位）
├─ 变动前库存（实物库存快照，数值 + 单位）
├─ 变动后库存（实物库存快照，数值 + 单位）
├─ 变动前可用（可用库存快照，数值 + 单位；可用 = 实物 − 锁定 − 冻结）
├─ 变动后可用（可用库存快照，数值 + 单位；可用 = 实物 − 锁定 − 冻结）
├─ 操作人（系统触发显示「系统」）
└─ 操作列：【查看详情】

分页器
└─ 默认每页 20 条，支持切换 50 / 100 条
```

**核心交互**

- 统计概览区指标卡可点击，点击「入库流水条数」自动带入「流水类型=入库」并触发查询；其他卡同理。
- 商品分类筛选器使用级联选择器，逐级展开，选中任意层级时包含该层级下所有子级商品，选中值以完整路径文字展示（如「日化 > 洗护 > 洗衣液」）。
- 流水类型与业务类型联动：选中流水类型后，业务类型下拉自动缩小至对应的子选项范围；未选流水类型时业务类型显示全量选项。
- 变动数量正数用绿色，负数用红色，加减符号显式展示，便于快速区分增减方向。
- 变动前库存 / 变动后库存展示实物库存快照（含锁定和冻结）；变动前可用 / 变动后可用展示扣除锁定和冻结后的可用库存快照；四列均为历史快照值，不随当前库存变化而更新。
- 来源单号为可点击文字链接，点击在新标签页打开对应入库单 / 出库单详情页。
- 流水号列支持点击复制，复制成功后行内显示「已复制」气泡提示。
- 操作时间超过 90 天时，查询按钮触发后弹出提示：「查询范围最大为 90 天，请缩短时间范围或使用导出功能获取更长周期数据」。
- 点击【查看详情】从页面右侧滑出详情抽屉，不跳页，列表区同步遮罩。

### 6.2 流水详情抽屉

**抽屉目标**

展示单条流水的完整信息，重点呈现变动前后各库存口径的余额快照，以及关联来源单据，供对账与异常追溯使用。

**触发方式**

点击流水列表中的【查看详情】按钮，从页面右侧滑出，背景半透明遮罩。

**抽屉布局**

```text
抽屉标题栏
├─ 标题：流水详情
├─ 副标题：流水号（如 FL-20260609-000123，支持复制）
└─ 右上角关闭按钮（×）

① 流水基础信息（两列布局）
├─ 流水号
├─ 发生时间（精确到秒）
├─ 仓库
├─ 库房（有则显示，无则隐藏该行）
└─ 货位（有则显示，无则隐藏该行）

分割线

② 商品信息（两列布局）
├─ 商品名称
├─ SKU 编码（支持复制）
├─ 规格
├─ 基础单位
├─ 主条码
├─ 所属分类（完整路径，如：日化 > 洗护 > 洗衣液）
├─ 批次号（有批次管理时显示）
├─ 生产日期（有效期管理时显示）
└─ 到期日期（有效期管理时显示）

分割线

③ 变动信息（两列布局）
├─ 流水类型（标签，配色同列表）
├─ 业务类型
├─ 变动方向（增加 / 减少，带颜色）
└─ 变动数量（绿色正数 / 红色负数，含单位）

分割线

④ 余额快照（对比卡片布局：左侧「变动前」/ 右侧「变动后」）
每侧展示：
├─ 实物库存
├─ 锁定库存
├─ 冻结库存
└─ 可用库存
注：锁定 / 冻结 / 解冻类流水实物库存前后一致，变化体现在锁定 / 冻结字段

分割线

⑤ 来源信息（两列布局）
├─ 来源单号（文字链接，点击跳转源单详情）
├─ 来源单类型（如：采购入库单）
└─ 关联订单号（有则显示，如电商平台订单号）

分割线

⑥ 操作信息（两列布局）
├─ 操作人（系统触发显示「系统」）
├─ 操作时间
└─ 备注（有则显示，无则显示「-」）

抽屉底部操作区
└─ 【关闭】按钮
```

**核心交互**

- 抽屉宽度建议 480px，高度 100vh，内容超长时抽屉内部纵向滚动，标题栏和底部按钮固定不滚动。
- 余额快照区采用「变动前 / 变动后」左右对比卡片布局，两侧对齐展示四个库存口径，直观呈现变动影响。
- 锁定 / 冻结 / 解冻类流水的实物库存字段在变动前后值一致，无需特殊标注；锁定、冻结字段的变化以颜色区分（增加用绿色，减少用红色）。
- 来源单号点击后在新标签页打开，抽屉不关闭。
- SKU 编码、流水号字段旁附复制图标，点击后图标变为 ✓ 并显示「已复制」。
- 点击遮罩区域或右上角 × 或底部【关闭】按钮，抽屉收起，列表恢复正常。
- 商品无批次管理时，批次号行隐藏；商品无效期管理时，生产日期和到期日期行隐藏；字段按需显示，不留空行。

## 7. 状态页设计

### 7.1 列表空态

| 场景 | 空态文案 | 辅助操作 |
| ---- | ---- | ---- |
| 有筛选条件，无结果 | 未查询到符合条件的流水记录 | 提供【重置筛选】入口 |
| 无筛选条件（首次进入） | 暂无流水数据，入库或出库操作后将自动生成 | 无 |
| 时间范围超过 90 天 | 查询范围最大 90 天，请缩短时间范围 | 提供【重置为最近 7 天】快捷入口 |

### 7.2 流水类型标签配色

| 流水类型 | 标签颜色 | 标签文字 |
| ---- | ---- | ---- |
| 入库 | 绿色 | 入库 |
| 出库 | 红色 | 出库 |
| 调整 | 蓝色 | 调整 |
| 盘点 | 紫色 | 盘点 |
| 冻结 | 橙色 | 冻结 |
| 解冻 | 青色 | 解冻 |
| 锁定 | 中灰色 | 锁定 |
| 解锁 | 浅灰色 | 解锁 |

### 7.3 变动数量颜色规则

| 变动方向 | 数字颜色 | 前缀符号 | 示例 |
| ---- | ---- | ---- | ---- |
| 增加 | 绿色 | + | +120 箱 |
| 减少 | 红色 | - | -36 箱 |
| 无实物变动（锁定 / 冻结类） | 默认灰色 | — | — |

### 7.4 列表加载态

- 数据加载中展示骨架屏（标题区、统计区、筛选区保持正常，列表区替换为骨架行），不显示空态插画。

## 8. 组件规范

### 8.1 查询筛选区

- 查询条件两行排布，第一行与第二行各 4 个等宽字段；操作时间单独占最后一行，选择器占满整行。
- 操作按钮（查询 / 重置 / 导出）固定右对齐，紧跟操作时间行右侧。
- 商品分类使用级联选择器（Cascader），展示完整分类路径，选中父级时值显示父级名称并在查询时自动包含所有子级。
- 流水类型与业务类型为多选下拉（MultiSelect），已选项以 Tag 形式在输入框内展示，超出折叠为「已选 N 项」。

### 8.2 统计概览区

- 4 张指标卡横向均分排列，每张卡片：上方数字（大号字体，加粗）+ 下方标签文字。
- 卡片可点击，点击后自动将对应流水类型条件写入筛选区并触发查询，卡片高亮显示当前激活状态。
- 统计数值基于当前筛选结果实时计算，筛选条件变更后同步刷新。

### 8.3 流水列表区

- 表格采用标准后台样式，细分割线区分行，无斑马纹（流水记录密度高，斑马纹反而增加视觉负担）。
- 商品信息列两行展示：第一行商品名称（常规字重），第二行 SKU 编码（浅色小字）。
- 商品分类列展示完整路径文字（如「日化 > 洗护 > 洗衣液」），超出列宽时截断并在 hover tooltip 展示完整路径。
- 变动数量列数值右对齐，颜色与符号规则见 §7.3。
- 变动前余额与变动后余额列数值右对齐，字体与变动数量保持一致，配色为默认正文色（非绿非红）。
- 操作人列：人工操作显示姓名，系统触发显示「系统」（浅灰色斜体，与人工操作视觉区分）。
- 来源单号列为文字链接样式，hover 下划线，点击新标签页打开。
- 流水号列支持悬停时展示复制图标，点击复制。

### 8.4 详情抽屉

- 抽屉宽度：480px，从右侧滑入，背景遮罩半透明（opacity 0.45）。
- 抽屉内容区 padding：上下 24px，左右 20px。
- 分组之间用细分割线（1px，浅灰）隔开，分组标题使用加粗小字（12px，灰色，全大写或加粗中文）。
- 余额快照区采用两列卡片对比布局：左卡「变动前」，右卡「变动后」，每卡内四行数据（实物 / 锁定 / 冻结 / 可用），卡片背景浅灰，圆角。
- 有变化的余额字段在「变动后」卡片中以颜色标注（增加=绿色，减少=红色），未变化字段保持默认色。
- 标题栏和底部按钮区固定定位，中间内容区超长时独立滚动。

### 8.5 商品分类筛选器交互细节

- 级联面板最多支持 3 级（一级 > 二级 > 三级），每级面板宽度 160px，横向展开。
- 选中任意层级后，输入框显示完整路径（如「日化 / 洗护 / 洗衣液」），右侧附清除按钮（×）。
- 选中父级节点时，查询逻辑自动下探，包含该父级下所有子级商品，无需逐一勾选。
- 支持在输入框内直接输入关键词搜索分类名称，实时过滤匹配的分类节点。

## 10. 原型输出顺序

**第一阶段（主框架）**

- 流水列表页整体框架（标题区 + 统计概览区 + 筛选区骨架 + 列表区骨架）

**第二阶段（字段与样式）**

- 筛选区字段填充（含商品分类级联组件、流水类型与业务类型多选联动）
- 列表区字段填充 + 流水类型标签配色 + 变动数量颜色规则

**第三阶段（详情与交互细节）**

- 流水详情抽屉（六个分组 + 余额快照对比卡片）
- 统计概览卡点击联动筛选
- 来源单号跳转、流水号复制等微交互

**第四阶段（异常与边界态）**

- 空态（有筛选 / 无筛选 / 超时间范围）
- 骨架屏加载态
- 无批次 / 无效期时字段隐藏规则验证

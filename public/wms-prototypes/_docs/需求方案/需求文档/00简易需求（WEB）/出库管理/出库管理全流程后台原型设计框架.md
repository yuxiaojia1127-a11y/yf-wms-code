# 出库管理全流程后台原型设计框架

## 1. 设计目标

出库管理用于支撑自营业务的仓库发货作业，覆盖从出库单生成、揽货接单、库存锁定、揽货、复核、打包到发货出库的完整流程。

后台原型应优先解决以下问题：

1. 运营人员可以查看所有出库单的处理状态。
2. 揽货人员可以从待接单池手动接单并承接出库任务。
3. 仓库人员可以按照任务完成揽货、复核、打包、发货作业。
4. 系统可以记录接单、库存锁定、库存扣减、出库差异和出库流水。
5. 管理人员可以及时识别待接单、待处理、异常、超时和库存不足的出库任务。

## 2. 功能结构

```text
出库管理
├─ 出库单管理
├─ 揽货接单
├─ 库存锁定
├─ 揽货管理
├─ 复核打包
├─ 发货管理
├─ 出库差异
└─ 出库流水
```

## 4. 页面设计

### 4.1 出库单管理

页面目标：

1. 统一查看销售出库、调拨出库、报损出库、其他出库。
2. 查看出库单从待接单到已发货的处理进度。
3. 对异常出库单进行取消、重试库存锁定、转差异处理。

核心筛选：

| 条件   | 说明                                     |
| ---- | -------------------------------------- |
| 出库单号 | 支持精确查询                                 |
| 来源单号 | 销售订单号、调拨单号、报损单号等                       |
| 出库类型 | 销售出库、调拨出库、报损出库、其他出库                    |
| 出库状态 | 待接单、已接单、待锁定、待揽货、揽货中、待复核、待发货、已发货、已取消、异常 |
| 接单状态 | 待接单、已接单、揽货中、已揽货、已释放、接单异常               |
| 仓库   | 查询指定仓库出库任务                             |
| 揽货人员 | 查询指定人员揽货接单                             |
| SKU  | 查询包含指定 SKU 的出库单                        |
| 创建时间 | 按时间范围查询                                |
| 异常状态 | 正常、库存不足、揽货异常、复核异常、发货异常                 |

列表字段：

| 字段    | 说明                             |
| ----- | ------------------------------ |
| 出库单号  | WMS 出库单唯一编号                    |
| 出库类型  | 销售、调拨、报损、其他                    |
| 来源单号  | 上游业务单据编号                       |
| 仓库    | 出库仓库                           |
| 接单状态  | 当前接单处理状态                       |
| 揽货人员  | 当前接单人员                         |
| 接单时间  | 揽货人员接单时间                       |
| SKU 数 | 出库单包含的 SKU 数量                  |
| 计划数量  | 应出库数量                          |
| 已揽数量  | 已完成揽货数量                        |
| 已发数量  | 已确认发货数量                        |
| 出库状态  | 当前处理状态                         |
| 异常状态  | 当前异常标识                         |
| 创建时间  | 出库单创建时间                        |
| 操作    | 查看、接单、释放接单、转派、取消、重试库存锁定、生成揽货任务 |

详情区域：

1. 基础信息：出库单号、来源单号、出库类型、仓库、状态、创建时间。
2. 商品明细：SKU、商品名称、条码、批次、效期、计划数量、锁定数量、揽货数量、复核数量、发货数量。
3. 作业进度：接单、库存锁定、揽货、复核、打包、发货节点。
4. 异常记录：异常类型、异常数量、处理结果、处理人、处理时间。
5. 库存流水：锁定、释放、扣减记录。

### 4.2 揽货接单

页面目标：

1. 将出库指令下发后的任务集中进入待接单池。
2. 支持揽货人员手动接单，明确任务承接人。
3. 支持仓库管理员查看接单进度、释放接单、转派任务和处理接单异常。
4. 为未来系统自动派单预留分配规则和任务状态。

核心筛选：

| 条件   | 说明                       |
| ---- | ------------------------ |
| 出库单号 | 查询指定出库任务                 |
| 来源单号 | 销售订单号、调拨单号、报损单号等         |
| 出库类型 | 销售出库、调拨出库、报损出库、其他出库      |
| 接单状态 | 待接单、已接单、揽货中、已揽货、已释放、接单异常 |
| 仓库   | 查询指定仓库                   |
| 揽货人员 | 查询指定人员揽货接单               |
| 优先级  | 查询普通、加急等任务               |
| 下发时间 | 按出库指令下发时间查询              |

列表字段：

| 字段     | 说明                      |
| ------ | ----------------------- |
| 揽货接单号  | 揽货接单编号                  |
| 出库单号   | 关联出库单                   |
| 来源单号   | 上游业务单据编号                |
| 出库类型   | 销售、调拨、报损、其他             |
| 仓库     | 出库仓库                    |
| SKU 数  | 出库单包含的 SKU 数量           |
| 计划数量   | 应出库数量                   |
| 优先级    | 任务处理优先级                 |
| 接单状态   | 当前接单状态                  |
| 揽货人员   | 当前接单人员                  |
| 下发时间   | 出库指令下发时间                |
| 接单时间   | 揽货人员接单时间                |
| 开始揽货时间 | 揽货人员开始处理时间              |
| 完成揽货时间 | 揽货完成时间                  |
| 操作     | 接单、开始揽货、完成揽货、释放接单、转派、查看 |

页面操作：

| 操作   | 说明                    |
| ---- | --------------------- |
| 接单   | 揽货人员从待接单池手动承接任务       |
| 开始揽货 | 接单后确认开始处理任务           |
| 完成揽货 | 揽货完成后进入后续仓内作业         |
| 释放接单 | 仓库管理员释放未完成接单关系        |
| 转派   | 仓库管理员将任务转给其他揽货人员      |
| 标记异常 | 记录无人接单、超时未揽货、人员不可用等异常 |

APP 揽货任务：

1. 查看本人可接任务和已接任务。
2. 在待接单池选择任务并接单。
3. 接单成功后展示出库单、仓库、SKU 数、计划数量和优先级。
4. 点击开始揽货，系统记录开始时间。
5. 完成揽货后提交完成确认。
6. 无法继续处理时提交接单异常。

自动派单预留：

1. 第一阶段采用手动接单。
2. 后续可按仓库、库区、人员班次、人员负荷、任务优先级、出库时效自动派单。
3. 自动派单生成的任务仍复用接单状态、揽货人员和操作日志。

### 4.3 库存锁定

页面目标：

1. 查看出库单对库存的占用情况。
2. 识别库存不足、批次不足、库位不足等问题。
3. 支持取消出库后释放锁定库存。

核心视图：

| 视图    | 说明              |
| ----- | --------------- |
| 按出库单  | 查看每张出库单的锁定结果    |
| 按 SKU | 查看 SKU 被哪些出库单占用 |
| 按库位   | 查看库位库存被占用情况     |
| 按异常   | 查看库存锁定失败或部分锁定记录 |

关键字段：

| 字段   | 说明                |
| ---- | ----------------- |
| 出库单号 | 关联出库单             |
| SKU  | 被锁定商品             |
| 仓库   | 出库仓库              |
| 库区   | 库存所在库区            |
| 库位   | 库存所在货位            |
| 批次   | 库存批次              |
| 效期   | 商品效期              |
| 计划数量 | 出库需求数量            |
| 锁定数量 | 已锁定库存数量           |
| 锁定状态 | 已锁定、部分锁定、锁定失败、已释放 |

### 4.4 揽货管理

页面目标：

1. 将待揽货出库单生成可执行的揽货任务。
2. 支持按仓库、库区、波次、单据维度组织揽货。
3. 跟踪揽货完成进度和揽货差异。

核心筛选：

| 条件    | 说明                   |
| ----- | -------------------- |
| 揽货任务号 | 支持精确查询               |
| 出库单号  | 查询关联出库单              |
| 仓库    | 查询指定仓库任务             |
| 揽货状态  | 待揽货、揽货中、已揽货、揽货异常、已取消 |
| 揽货员   | 查询人员任务               |
| 创建时间  | 按时间范围查询              |

列表字段：

| 字段    | 说明           |
| ----- | ------------ |
| 揽货任务号 | 揽货任务编号       |
| 出库单号  | 关联出库单        |
| 仓库    | 作业仓库         |
| 库区    | 作业库区         |
| SKU 数 | 任务 SKU 数量    |
| 计划数量  | 应揽数量         |
| 已揽数量  | 已揽商品数量       |
| 揽货员   | 当前任务执行人      |
| 揽货状态  | 当前任务状态       |
| 操作    | 分配、取消、查看、转异常 |

APP 揽货任务：

1. 扫描或选择揽货任务。
2. 按库位路径展示待揽商品。
3. 扫描库位、商品条码、批次确认揽货。
4. 输入实揽数量。
5. 发现缺货、错货、破损时提交揽货异常。

### 4.5 复核打包

页面目标：

1. 校验已揽商品是否与出库单一致。
2. 完成商品复核、装箱、称重、打包。
3. 在发货前拦截错揽、少揽、多揽、批次不一致等问题。

核心筛选：

| 条件   | 说明                |
| ---- | ----------------- |
| 出库单号 | 查询待复核出库单          |
| 复核状态 | 待复核、复核中、复核通过、复核异常 |
| 仓库   | 查询指定仓库            |
| 复核员  | 查询人员作业            |
| 创建时间 | 按时间范围查询           |

复核字段：

| 字段    | 说明      |
| ----- | ------- |
| 出库单号  | 关联出库单   |
| SKU   | 复核商品    |
| 应复核数量 | 出库单计划数量 |
| 已揽数量  | 揽货完成数量  |
| 实复核数量 | 实际复核数量  |
| 批次    | 商品批次    |
| 效期    | 商品效期    |
| 复核状态  | 当前复核结果  |

APP 复核任务：

1. 扫描出库单号或包裹号。
2. 扫描商品条码进行复核。
3. 校验 SKU、数量、批次、效期。
4. 录入箱号、包裹重量、包材信息。
5. 复核通过后进入待发货。
6. 复核不通过时生成出库差异。

### 4.6 发货管理

页面目标：

1. 对已复核打包的出库单完成发货确认。
2. 记录物流信息、交接信息和出库完成时间。
3. 触发库存实物扣减和出库流水生成。

核心筛选：

| 条件   | 说明               |
| ---- | ---------------- |
| 出库单号 | 查询指定出库单          |
| 发货状态 | 待发货、发货中、已发货、发货异常 |
| 物流单号 | 查询物流包裹           |
| 仓库   | 查询指定仓库           |
| 发货时间 | 按时间范围查询          |

列表字段：

| 字段   | 说明          |
| ---- | ----------- |
| 出库单号 | 关联出库单       |
| 来源单号 | 上游业务单据编号    |
| 仓库   | 出库仓库        |
| 包裹数  | 发货包裹数量      |
| 发货数量 | 确认发货数量      |
| 物流公司 | 承运商         |
| 物流单号 | 运单号         |
| 发货状态 | 当前发货状态      |
| 发货时间 | 完成发货时间      |
| 操作   | 查看、确认发货、转异常 |

APP 发货任务：

1. 扫描包裹号或物流单号。
2. 校验包裹是否已复核通过。
3. 确认物流交接。
4. 完成发货。

### 4.7 出库差异

页面目标：

1. 集中处理出库过程中的异常和差异。
2. 记录差异原因、处理方式和处理结果。
3. 保证库存、单据状态和业务结果一致。

差异类型：

| 类型   | 说明            |
| ---- | ------------- |
| 库存不足 | 可用库存不足，无法完成锁库 |
| 少揽   | 实揽数量小于计划数量    |
| 多揽   | 实揽数量大于计划数量    |
| 错揽   | 实揽商品与计划商品不一致  |
| 批次不符 | 实揽批次与分配批次不一致  |
| 复核不符 | 复核结果与揽货结果不一致  |
| 发货异常 | 包裹无法正常交接或发运   |

处理方式：

| 处理方式  | 适用场景           |
| ----- | -------------- |
| 继续出库  | 差异确认不影响发货      |
| 部分出库  | 实际库存不足，只发出部分商品 |
| 重新揽货  | 揽货错误或漏揽        |
| 取消出库  | 业务取消或无法履约      |
| 转库存调整 | 发现库存账实不符       |

### 4.8 出库流水

页面目标：

1. 查询出库相关库存变动记录。
2. 支撑库存追溯、异常排查和账务核对。

流水类型：

| 类型   | 说明            |
| ---- | ------------- |
| 库存锁定 | 出库单占用可用库存     |
| 锁定释放 | 出库取消或差异处理释放库存 |
| 揽货确认 | 商品完成揽货作业      |
| 发货扣减 | 发货后扣减实物库存     |
| 差异调整 | 出库差异导致的库存变动   |

列表字段：

| 字段   | 说明          |
| ---- | ----------- |
| 流水号  | 库存流水唯一编号    |
| 出库单号 | 关联出库单       |
| 来源单号 | 上游业务单据编号    |
| 流水类型 | 锁定、释放、扣减、调整 |
| SKU  | 商品 SKU      |
| 仓库   | 库存仓库        |
| 库区   | 库存库区        |
| 库位   | 库存库位        |
| 批次   | 商品批次        |
| 变动数量 | 本次库存变动数量    |
| 操作人  | 作业人员或系统     |
| 操作时间 | 流水生成时间      |

## 7. 优先级

第一阶段：

1. 出库单管理
2. 揽货接单
3. 库存锁定
4. 揽货管理
5. 复核打包
6. 发货管理

第二阶段：

1. 出库差异
2. 出库流水
3. APP 揽货、复核、发货作业优化
4. 自动派单

第三阶段：

1. 波次揽货
2. 揽货路径优化
3. 自动称重与面单打印
4. 出库效率看板

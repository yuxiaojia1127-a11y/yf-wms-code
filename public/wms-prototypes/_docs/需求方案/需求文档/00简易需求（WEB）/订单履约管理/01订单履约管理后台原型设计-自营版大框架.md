# 订单履约管理后台原型设计（自营版大框架）

## 1. 设计目标

订单履约管理用于承接上游销售系统下发的发货指令，将业务发货请求转化为WMS可执行的履约单，并按销售渠道履约仓、前置仓库存、即采即销能力拆分揽货单，再生成出库单进入仓内作业。

后台原型应优先解决以下问题：

1. 订单运营可以查看所有发货指令和履约单处理状态。
2. 系统可以按销售渠道履约仓配置完成揽货单拆单。
3. 系统可以将前置仓无法满足的SKU缺口分配到即采即销仓。
4. 仓库管理员可以查看履约单、揽货单与出库单之间的衔接关系。
5. 客服人员可以查询履约进度、换货、退款备注、包裹和物流结果。
6. 系统管理员可以处理接口接收、回传失败和系统异常。

## 2. 功能结构

```text
订单履约管理
├─ 履约单管理
├─ 销售渠道履约仓
├─ 揽货单拆单
├─ 合单复核
├─ 即采即销异常
├─ 指令接收记录
├─ 出库关联
├─ 包裹物流
├─ 履约异常
└─ 履约回传
```

## 4. 页面设计

### 4.1 履约单管理

页面目标：

1. 统一查看销售发货、补发发货、换货发货、手工发货。
2. 查看履约单从已接收到已发货的处理进度。
3. 支持履约单挂起、释放、取消、重新校验、生成出库单。

核心筛选：

| 条件 | 说明 |
| --- | --- |
| 履约单号 | 支持精确查询 |
| 外部发货指令号 | 按上游发货指令号查询 |
| 来源单号 | 按销售订单、补发单、换货单查询 |
| 销售渠道 | 按发货指令所属渠道查询 |
| 履约来源 | 销售发货、补发发货、换货发货、手工发货 |
| 履约状态 | 已接收、校验中、拆单中、待揽货接单、待生成出库、已生成出库、出库中、待合单复核、已发货、已取消、已挂起、异常 |
| 拆单状态 | 未拆单、拆单中、已拆单、拆单异常 |
| 合单复核状态 | 无需合单、待合单、合单中、已合单、合单异常 |
| 即采即销状态 | 不涉及、待采购揽货、采购揽货中、已采购揽货、无货待确认、已换货、部分退款待回传、整单退款拦截 |
| 出库关联状态 | 未生成、已生成、出库中、出库完成、出库异常、出库取消 |
| 回传状态 | 待回传、回传中、回传成功、回传失败、无需回传 |
| 仓库 | 查询指定履约仓库 |
| SKU | 查询包含指定SKU的履约单 |
| 创建时间 | 按履约单创建时间查询 |

列表字段：

| 字段 | 说明 |
| --- | --- |
| 履约单号 | WMS内部履约单号 |
| 外部发货指令号 | 上游发货指令编号 |
| 来源单号 | 上游业务单据编号 |
| 销售渠道 | 发货指令所属渠道 |
| 履约来源 | 销售、补发、换货、手工 |
| 仓库 | 主履约仓库或首选履约仓库 |
| 揽货单数 | 拆单后生成的揽货单数量 |
| SKU数 | 履约单包含的SKU数量 |
| 应发数量 | 指令要求发货数量 |
| 已发数量 | 实际已发数量 |
| 履约状态 | 当前履约状态 |
| 拆单状态 | 当前揽货单拆单状态 |
| 合单复核状态 | 当前合单复核状态 |
| 即采即销状态 | 当前即采即销状态 |
| 出库关联状态 | 当前出库处理状态 |
| 回传状态 | 当前回传状态 |
| 创建时间 | 履约单创建时间 |
| 操作 | 查看、挂起、释放、取消、重新校验、生成出库单 |

详情区域：

1. 基础信息：履约单号、外部发货指令号、来源单号、履约来源、仓库、状态。
2. 收货信息：收货人、电话、地址。
3. 商品明细：SKU、商品名称、条码、应发数量、已发数量、异常数量。
4. 拆单结果：揽货单号、履约仓库、SKU、分配数量、拆单原因、是否即采即销。
5. 合单结果：合单复核号、合单状态、包裹号、合单异常。
6. 出库关联：出库单号、出库状态、揽货接单状态、发货时间。
7. 包裹物流：包裹号、物流单号、承运商、重量、发货状态。
8. 换货退款：原SKU、替换SKU、消费者确认结果、退款备注、拦截状态。
9. 异常记录：异常类型、异常原因、处理结果、处理人、处理时间。
10. 回传记录：回传类型、回传状态、失败原因、回传时间。

### 4.2 销售渠道履约仓

页面目标：

1. 查看销售渠道允许使用的前置仓和即采即销仓。
2. 支撑履约拆单时筛选可用仓库。
3. 明确仓库优先级、服务范围、仓库类型和启停状态。

核心字段：

| 字段 | 说明 |
| --- | --- |
| 销售渠道 | 发货指令所属销售渠道 |
| 仓库 | 可用履约仓库 |
| 仓库类型 | 前置仓、即采即销仓 |
| 仓库优先级 | 同等条件下的分配优先级 |
| 服务范围 | 仓库可覆盖的区域 |
| 是否启用 | 是否参与履约拆单 |
| 是否默认仓 | 销售渠道默认优先履约仓 |
| 操作 | 查看、启用、停用、调整优先级 |

3. 支持拆单异常查看和重新拆单。

核心筛选：

| --- | --- |
| 履约单号 | 查询指定履约单 |
| 揽货单号 | 查询指定揽货单 |
| 销售渠道 | 查询指定销售渠道 |
| 履约仓库 | 查询指定仓库 |
| 仓库类型 | 前置仓、即采即销仓 |
| 拆单状态 | 未拆单、拆单中、已拆单、拆单异常 |
| SKU | 查询指定SKU分配结果 |

列表字段：

| 字段 | 说明 |
| --- | --- |
| 履约单号 | WMS内部履约单号 |
| 揽货单号 | 拆单后生成的揽货执行单 |
| 销售渠道 | 发货指令所属渠道 |
| 履约仓库 | 揽货单对应仓库 |
| 仓库类型 | 前置仓、即采即销仓 |
| SKU | 分配SKU |
| 应发数量 | 原始履约数量 |
| 分配数量 | 当前揽货单承接数量 |
| 库存满足方式 | 单仓满足、多仓补齐、即采即销 |
| 拆单原因 | 最近仓满足、库存缺口补齐、即采即销补齐等 |
| 拆单状态 | 当前拆单结果 |
| 操作 | 查看、重新拆单、查看出库单 |

### 4.4 合单复核

页面目标：

1. 查看同一订单下满足条件的揽货单合单复核情况。
2. 支持复核打包环节合并同仓揽货结果。
3. 识别合单过程中的SKU、数量、批次、包裹异常。

合单条件：

| 条件 | 说明 |
| --- | --- |
| 同一订单 | 必须属于同一个履约单或外部发货指令 |
| 同一履约仓库 | 跨仓默认不做物理合单 |
| 同一配送方式 | 配送方式一致才允许合单 |
| 同一收货信息 | 收货人、电话、地址一致 |
| 无阻断异常 | 不存在无货待确认、退款拦截、换货待确认 |

列表字段：

| 字段 | 说明 |
| --- | --- |
| 合单复核号 | 合单复核任务编号 |
| 履约单号 | 关联履约单 |
| 揽货单数 | 参与合单的揽货单数量 |
| 履约仓库 | 合单所在仓库 |
| SKU数 | 合单复核SKU数量 |
| 应发数量 | 合单应发数量 |
| 实复核数量 | 实际复核数量 |
| 包裹数 | 合单后包裹数量 |
| 合单复核状态 | 待合单、合单中、已合单、合单异常 |
| 操作 | 查看、处理异常 |

### 4.9 履约异常

页面目标：

1. 集中处理履约过程中的阻断问题。
2. 记录异常原因、处理方式和处理结果。
3. 保证履约单、出库单和回传结果一致。

异常类型：

| 类型 | 说明 |
| --- | --- |
| 指令异常 | 指令格式错误、必填字段缺失、重复指令冲突 |
| 商品异常 | SKU不存在、停用、条码异常 |
| 仓库异常 | 指定仓库不存在、停用、不可发货 |
| 库存异常 | 可用库存不足 |
| 拆单异常 | 销售渠道无可用履约仓、SKU无法分配、数量拆分受限 |
| 即采即销异常 | 供应商无货、换货待确认、部分退款备注待处理 |
| 合单异常 | 合单复核数量不一致、SKU不一致、包裹异常 |
| 退款拦截异常 | 退款订单已发货或拦截失败 |
| 出库异常 | 出库单生成失败、出库作业异常 |
| 回传异常 | 回传失败或上游拒收 |

处理方式：

| 处理方式 | 适用场景 |
| --- | --- |
| 重新校验 | 基础资料或库存已修正 |
| 重新拆单 | 仓库库存或履约仓配置变化 |
| 重新生成出库 | 出库单生成失败后重试 |
| 换货处理 | 即采即销无货且消费者同意换货 |
| 退款拦截 | 消费者不同意换货或上游取消订单 |
| 挂起履约 | 业务待确认，暂停处理 |
| 取消履约 | 业务取消或无法继续履约 |
| 回传重试 | 回传失败后重新同步 |

| 回传时间 | 按回传时间查询 |

列表字段：

| 字段 | 说明 |

## 7. 优先级

第一阶段：

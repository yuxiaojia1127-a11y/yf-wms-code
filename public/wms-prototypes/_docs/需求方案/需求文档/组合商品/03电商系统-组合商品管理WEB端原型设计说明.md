# 电商系统 - 组合商品管理 WEB 端原型设计说明（1.0）

> 依据文档：
>
> - 需求：[01电商系统-组合商品管理简易需求文档.md](./01电商系统-组合商品管理简易需求文档.md)
> - UI 规范：[WMS前端UI规范.md](../../../../UI规范/WMS前端UI规范.md)
> - 现有原型参考：`WEB端HTML原型/pages/my-product.html`（商品列表/筛选/详情抽屉骨架）；商品管理后台的「侧边栏 + 顶部栏 + 页面标题区 + 筛选区 + KPI + 主表格 + 抽屉」标准布局。
>
> 本说明覆盖「进入组合商品 → 查询/筛选组合 → 新建/编辑组合（含组件 SKU 明细、价格分摊、退货策略、门店与生效配置）→ 上下线 → 详情查看 → 销量统计」全流程。组合的下单展开与价格固化为后端能力，原型以字段与规则呈现，不做消费者端交互。

---

## 1. 设计目标

- 在不破坏现有 WEB 后台视觉（浅灰背景、白面板、主色 `#00ab95`、248px 侧边栏、sticky 顶部栏）的前提下，落地组合商品的「建、改、上下线、看、统计」闭环。
- 复用商品管理后台已有组件（侧边栏、顶部栏、筛选区、KPI 卡片、主表格、抽屉、弹窗、状态标签），不新造样式体系。
- 重点呈现组合特有逻辑：**组件 SKU 明细维护、展示价与组件分摊价校验、退货策略、版本快照、门店与生效配置**。
- 产出可直接交给技术人员/AI 还原的页面级设计说明。

---

## 2. 设计范围

### 2.1 本期范围
- 列表页：页面标题区、KPI 区、筛选区、组合商品主表格、行内上下线/编辑/查看动作。
- 新建/编辑页：基本信息（名称、主图、展示价、退货策略）、组件 SKU 明细表（选 SKU、数量、分摊价、赠品标识）、分摊校验、门店范围配置、生效时间配置、保存草稿/提交上线。
- 详情页（抽屉或独立页）：状态、基本信息、组件明细、版本信息、销量统计入口、操作区。
- 统计：组合销量/转化/关联 SKU 明细（列表页 KPI + 详情页统计块，或独立统计页）。
- 弹层/抽屉：选 SKU 抽屉、主图上传、门店选择、生效时间选择、上线/下线/暂停确认、删除确认。

### 2.2 暂不涉及
- 消费者端组合展示、加购、下单交互（电商系统另行细化）。
- 组合下单展开、价格固化、订单快照的后端实现（原型仅呈现规则与字段）。
- WMS 履约、缺货、退货流程（见 02 WMS 文档）。
- 真实接口（原型用内联样例数据）。

## 5. 列表页设计（COMBO-01）

### 5.1 骨架
沿用商品后台标准布局：侧边栏 248px → sticky 顶部栏（面包屑/搜索/门店切换/用户）→ 主内容区（页面标题区 → KPI → 筛选区 → 主表格）。主内容 `min-width:0`，背景 `#f5f5f7`，面板白底 16-20px 圆角、轻阴影。

### 5.2 页面标题区
- 标题「组合商品」24-28px/600；右侧主色胶囊按钮「＋ 新建组合」。
- 副标题一行小字说明（可选）：组合为营销售卖单元，履约按组件 SKU 出库。

### 5.3 KPI 区（一行，最多 4-5 卡）
| KPI | 取值 |
| --- | --- |
| 组合总数 | 全部组合数 |
| 上线中 | status=上线 |
| 暂停/下线 | status=暂停 + 下线 |
| 本月组合销量 | 统计口径，份数 |

KPI 数字 28-36px 等宽数字，卡片 16-20px 圆角。

### 5.4 筛选区
四列布局（容器 ≥1080px 时四列同排，按 UI 规范响应式降列）：

- 组合名称 / 编码（输入）
- 状态（全部 / 草稿 / 上线 / 暂停 / 下线）
- 门店（下拉，支持门店集合）
- 生效时间范围（日期范围）
- 退货策略（全部 / atomic / splittable）
- 动作：查询（主色）/ 重置

### 5.5 组合商品主表格
12-13px 表格字号、浅灰表头、行分隔线、状态标签。列：

| 列 | 说明 |
| --- | --- |
| 组合编码 | `combo_code` |
| 主图 | 缩略图 |
| 组合名称 | `combo_name` |
| 展示价 | `display_price`，币种 |
| 组件数 | 组件 SKU 行数（如「3 个 SKU」） |
| 退货策略 | `atomic` 整组退 / `splittable` 可拆退（标签） |
| 门店范围 | 全部 / N 个门店 |
| 生效时间 | 开始～结束（无则「长期」） |
| 状态 | 草稿 / 上线 / 暂停 / 下线（状态色标签） |
| 版本 | `version` |
| 销量 | 累计/本月份数 |
| 操作 | 查看 / 编辑 / 上线·暂停·下线（按状态显隐） |

行内操作按状态：草稿→编辑/提交上线/删除；上线→查看/编辑/暂停/下线；暂停→查看/编辑/恢复上线/下线；下线→查看/恢复。

## 6. 新建/编辑组合页（COMBO-02）

### 6.1 基本信息卡片
| 字段 | 控件 | 校验 |
| --- | --- | --- |
| 组合名称 | 输入 | 必填 |
| 主图 | 上传/选择 | 必填，前台展示用 |
| 展示价 | 数字 + 币种 | 必填，>0；作为组合成交价 |
| 退货策略 | 单选 `atomic`/`splittable` | 默认 atomic；含赠品时锁定 atomic 不可改 |
| 状态 | 草稿/上线（保存动作决定） | — |

### 6.2 组件 SKU 明细卡片（组合核心）
表格 + 「选择 SKU」按钮（打开选 SKU 抽屉，可多选）：

| 列 | 控件 | 说明/校验 |
| --- | --- | --- |
| SKU 编码 | 只读（选入） | 关联 WMS SKU |
| 商品名称/规格 | 只读 | 档案带出 |
| 数量 | 数字输入 | 单份组合中该 SKU 数量，必须 >0 |
| 分摊价 | 数字输入 | 该组件分摊单价，≥0 |
| 赠品 | 开关 | 开启则该组合强制 atomic |
| 操作 | 删除行 | — |

**分摊校验条**（明细表底部常驻）：实时计算「各组件行金额合计 = Σ(数量×分摊价)」并与展示价比对：

```
组件金额合计 RM XX.XX   |   展示价 RM XX.XX   |   ✔ 一致 / ✘ 不一致（红色，阻断提交）
```

合计与展示价不一致时禁止提交上线（可存草稿），提示「分摊价合计需等于展示价」。

> 同一 SKU 在不同组合/单买中各自独立定价，组合内只维护本组合的分摊价，不影响其他场景。

### 6.3 门店范围卡片
- 单选：全部门店 / 指定门店集合。
- 选「指定」时弹门店选择抽屉（支持门店集合）。

### 6.4 生效时间卡片
- 开始时间 / 结束时间（可空=长期）。
- 时段限制（可选，按需配置每日时段）。

### 6.5 底部操作栏
- 左：统计（组件 N 个 SKU / 合计金额 / 与展示价是否一致）。
- 右：保存草稿（不校验分摊一致）/ 提交上线（强校验：名称、主图、展示价、组件≥1、数量>0、分摊合计=展示价、生效配置）。
- 编辑已上线组合时，提交后 `version+1`，并提示「版本将 +1，已成交订单不受影响，仍按下单时快照履约」。

### 6.6 提交成功
成功提示（toast 或成功页）：组合编码 + 状态，提供「查看组合 / 继续新建」。

## 7. 组合详情页/抽屉（COMBO-03）

- 状态 banner：组合编码（可复制）+ 状态标签 + 版本号。
- 基本信息：名称、主图、展示价、退货策略、门店范围、生效时间。
- 组件 SKU 明细：SKU / 名称规格 / 数量 / 分摊价 / 赠品，底部显示合计金额与展示价一致性。
- 销量统计块：累计/本月组合销量（份）、转化、关联 SKU 出货数量（按 `combo_group` 反查）。
- 操作区：按状态显隐——编辑、上线/暂停/下线/恢复、删除草稿。

| --- | --- | --- |
| 选 SKU 抽屉 | 组件明细「选择 SKU」 | 搜索 SKU（编码/名称/条码）+ 多选 + 确认追加 |

| 删除确认 | 草稿删除 | 二次确认（仅草稿可删） |

## 9. 状态与可执行操作

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| 草稿 | 已创建未上线 | 编辑、删除、提交上线 |
| 上线 | 前台可售卖 | 查看、编辑（version+1）、暂停、下线 |
| 暂停 | 临时不可售卖 | 查看、编辑、恢复上线、下线 |
| 下线 | 停止售卖 | 查看、恢复（回到上线/暂停） |

## 10. 字段口径与提示（与需求文档一致）

1. 展示价 = 组合成交价；组件分摊价合计必须等于展示价（清关/计费要求）。
2. 退货策略默认 `atomic`；任一组件标为赠品时强制 `atomic` 且不可改。
3. 编辑组件/价格触发 `version+1`；已成交订单永远按下单时快照履约，不受改动影响。
4. 组件数量为「单份组合」的数量；下单数量为 N 时由后端展开成 N 个独立组合实例（原型不展示展开过程，仅在帮助提示中说明）。
5. 组合只是营销售卖单元，WMS 按组件 SKU 出库，不新增组合库存（页面辅助提示注明，避免运营误解为实体套装）。

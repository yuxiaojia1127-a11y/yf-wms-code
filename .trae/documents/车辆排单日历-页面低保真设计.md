# 车辆排单日历（Desktop-first）页面低保真设计

> 聚焦布局与组件层级；组件命名偏通用，便于快速搭原型。

## 全局（Global）

### Layout

* 桌面优先：`Header(固定)` + `Main(左右分栏)`。

* 主体采用 CSS Grid：`grid-template-columns: 280px 1fr;`（左资源栏固定宽，右日历自适应）。

* 页面内滚动：日历主体为独立滚动容器，Header 固定。

### Meta Information

* Title：车辆排单日历

* Description：车辆排单日历原型，用于查看与安排车辆任务

* Open Graph：同 Title/Description（原型可占位）

### Global Styles（低保真 Token）

* 背景：#F7F7F7

* 容器底色：#FFFFFF

* 边框：#E5E7EB（1px）

* 文字：主 #111827 / 次 #6B7280

* 主按钮：#111827（hover #000000）

* 链接/强调：#2563EB

* 状态色（用于卡片左边条或背景浅色块）：

  * 进行中：#3B82F6

  * 已完成：#10B981

  * 已取消：#9CA3AF

  * 冲突/异常：#EF4444

* 字体层级：H1 18/24，H2 16/22，正文 14/20，辅助 12/16

## 页面 1：车辆排单日历页

### Page Structure

1. 顶部 Header 工具栏（固定）
2. 主体 Main（左右分栏）

   * 左：资源列表面板

   * 右：日历面板（含二级工具条 + 日历网格）
3. 全局浮层：Modal / Drawer / Popover（覆盖在页面之上）

### Sections & Components

#### A. 顶部 Header（固定，64px）

* 左侧：页面标题「车辆排单日历」

* 中部：日期导航组（Button Group）

  * 上一段、今天、下一段

  * 当前日期范围文本（例如：2026-03-XX \~ 2026-03-XX）

* 右侧：主操作区

  * Search Input（placeholder：搜索车辆/任务）

  * 视图切换 Segmented Control：日 / 周 / 月（或周为默认）

  * Filter Button（打开“筛选抽屉”）

  * Primary Button：新增排单（打开“新增排单弹窗”）

#### B. 左侧资源列表面板（280px，独立滚动）

* Panel Header

  * 标题：资源（车辆/车组）

  * 资源搜索输入框

* 分组列表（Accordion）

  * 分组行：分组名 + 数量 + 展开/收起

  * 资源行（List Item）：车牌/名称 + 状态点 +（可选）小标签

  * 选中态：整行浅灰底 + 左侧强调条

* 空态：无资源/无匹配

#### C. 右侧日历面板（自适应宽，纵向占满）

##### C1. 二级工具条（与日历同宽，48px）

* 左：图例 Legend（小色块 + 文案：进行中/已完成/已取消/冲突）

* 右：缩放/显示密度（可选）

  * 例如：时间粒度 30min / 60min（原型可用下拉占位）

##### C2. 日历网格（核心区域，独立滚动）

* 结构：

  * 顶部：日期表头行（Date Columns Header）

  * 左侧：时间刻度列（Time Ruler，固定）

  * 中心：网格内容区（Grid Body）

* 网格表现：

  * 纵向：按时间刻度画横线（细线）

  * 横向：按日期列画竖线（细线）

  * 今日列高亮：表头或背景浅色

  * 当前时间线：一条红线（可选）

##### C3. 排单卡片（Schedule Item Card）

* 放置：绝对定位在网格中（以 start/end 时间决定 top/height；以日期/资源决定列/行）

* 内容（低保真）：

  * 第一行：任务标题（1 行截断）

  * 第二行：车牌/资源名 + 时间段（小字）

  * 右上角：状态小标签（可选）

* 交互：

  * 点击：打开“排单详情抽屉”

  * 悬浮：Tooltip 显示更全信息（标题、车辆、起止）

## 关键弹窗/抽屉（Overlay Spec）

### 1) 新增/编辑排单弹窗（Modal，宽 520–640px）

* Header：标题（新增排单/编辑排单）+ 关闭 X

* Body（表单区，单列栅格）

  * 任务标题 Input

  * 车辆/车组 Select（带搜索）

  * 起止时间：DateTime Range Picker（或两个控件）

  * 状态 Select

  * 备注 Textarea（可选）

* Footer：次按钮「取消」+ 主按钮「保存」

* 校验态：必填项红色提示文案（低保真可用占位）

### 2) 排单详情抽屉（Right Drawer，宽 420–520px）

* Header：

  * 标题 + 状态 Tag

  * 关闭

* Body：

  * 信息块（Description List）

  * Tab（可选）：概览 / 时间 / 车辆 / 备注

* Footer（固定在底部）：

  * 按钮：编辑（打开编辑弹窗）/ 关闭

### 3) 筛选抽屉（Drawer，建议右侧；宽 360px）

* Header：筛选 + 关闭

* Body：

  * 状态多选（Checkbox Group）

  * 车辆分组多选（Tree/Checkbox List）

  * （可选）时间范围（Date Range）

* Footer：重置 / 应用

### 4) 冲突提示弹窗（Modal，宽 520px）

* Header：排单冲突

* Body：

  * 冲突摘要（红色提示条）

  * 冲突列表（List）：冲突项标题 + 时间段 + 资源

* Footer：返回修改 / 关闭（或继续保存）

### 5) 快捷操作浮层（Popover / Context Menu）

* 触发：卡片右上角“更多”或右键

* 菜单项：查看详情、编辑、复制（可选）、删除（可选）

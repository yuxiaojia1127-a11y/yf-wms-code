# WMS-WEB 库存查询简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 库存查询 |
| 所属模块 | 库存中心 |
| 页面定位 | 以商品 SKU 和存放仓库为主视角的库存汇总查询页 |
| 页面编码 | `WMS-WEB-012` |
| 适用端 | WMS-WEB 管理端 |

## 2. 业务说明

库存查询用于承接库存中心中最常用的库存查看需求，帮助仓库管理员、仓内主管和运营人员快速查看某个 SKU 当前存放在哪些仓库、库存数量是多少、可售库存是否充足以及锁定/冻结占用情况。

页面口径参考现有库存管理大框架中的“库存汇总”设计，同时结合现有 WMS 库存查询习惯，列表优先展示商品 SKU 信息和存放仓库数据，满足“先定位商品，再查看仓库存量”的使用路径。

当前版本聚焦 SKU 维度库存汇总，不展开批次、库位、流水等明细能力；如需继续下钻，由“查看明细”进入后续库存明细页或抽屉。

## 3. 功能描述

- 支持在库存中心菜单下进入“库存查询”页面。
- 支持按仓库、SKU 编码、商品名称、条码、商品分类、库存类型进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持以列表方式展示商品 SKU 信息及对应仓库存量数据。
- 支持点击“查看明细”后查看该 SKU 在当前仓库下的库存明细。
- 支持从驾驶舱“可用库存总量”等库存类入口跳转进入，并自动带入当前仓库筛选。

## 4. 查询条件

| 字段名称 | 字段类型 | 查询方式 | 暗字提示 |
| ---- | ---- | ---- | ---- |
| 仓库 | 下拉单选 | 精确筛选 | 默认全部授权仓库 |
| SKU 编码 | 输入框 | 精确 / 模糊查询 | 请输入商品 SKU 编码 |
| 商品名称 | 输入框 | 模糊查询 | 请输入商品名称 |
| 条码 | 输入框 | 精确 / 模糊查询 | 请输入主条码 / 商品条码 |
| 商品分类 | 下拉单选 | 精确筛选 | 支持按一级 / 二级分类筛选 |
| 库存类型 | 下拉单选 | 精确筛选 | 全部 / 正品 / 次品 / 冻结 / 待检 |

## 5. 列表字段

| 字段名称 | 字段类型 | 是否必填 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 商品信息 | 组合文本 | 是 | 洗衣液 2L / DETERGENT-2L | 展示商品名称、SKU 编码、规格、主条码 |
| 仓库 | 文本 | 是 | 1号仓库 | 优先展示当前 SKU 存放仓库 |
| 商品分类 | 文本 | 否 | 日化 > 洗护 | 用于辅助识别商品所属分类 |
| 基础单位 | 文本 | 是 | 箱 | 展示库存计量单位 |
| 实物库存 | 数值 | 是 | 18 箱 | 当前账面实物库存 |
| 可售库存 | 数值 | 是 | 9 箱 | 当前可用于销售 / 分配的库存 |
| 锁定库存 | 数值 | 否 | 6 箱 | 已被订单、任务等占用的库存 |
| 冻结库存 | 数值 | 否 | 3 箱 | 因异常、质检、禁售等冻结的库存 |
| 在途库存 | 数值 | 否 | 5 箱 | 已创建入库但尚未入账的库存 |
| 批次数 | 数值 | 否 | 4 | 当前 SKU 在该仓库下的批次数量 |
| 库位数 | 数值 | 否 | 12 | 当前 SKU 在该仓库下分布的库位数 |
| 更新时间 | 时间 | 是 | 2026-06-04 10:30 | 最近库存汇总刷新时间 |
| 操作 | 按钮 | 是 | 查看明细 | 进入库存明细查看该 SKU 仓库下的详细库存 |

## 6. 排序与展示规则

- 列表默认按更新时间倒序展示最新库存数据。
- 列表字段优先级遵循“商品 SKU 信息优先、仓库数据优先、库存数量其次”的展示原则。
- 同一 SKU 在不同仓库存放时，按仓库分别展示多行数据，不在当前页做合并折叠。
- 可售库存低于安全阈值时，可在可售库存字段上展示预警样式或文案提示。
- 当前筛选条件下无数据时，保留查询条件并展示空态。
- 默认每页展示 10 条。

## 7. 查看明细

- 点击“查看明细”后，进入库存明细页面或打开右侧详情抽屉。
- 详情至少展示：SKU 信息、仓库、库位分布、批次分布、库存状态、锁定记录摘要、最近库存流水摘要。
- 当前页面不直接承载库存调整、冻结/解冻等操作，仅提供查询与下钻。

## 8. 关键规则

- 页面数据口径为 SKU + 仓库维度库存汇总，不等同于库位级明细页。
- 驾驶舱“可用库存总量”点击后，默认跳转至本页面，并自动带入当前仓库筛选。
- 列表必须优先体现商品 SKU 信息和存放仓库，不以业务单据或批次信息作为主列。
- 实物库存、可售库存、锁定库存、冻结库存口径需保持同源，避免字段间计算冲突。
- 导出范围为当前筛选结果。

## 9. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在库存汇总数据 | 展示查询区、列表、分页与查看明细能力 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无库存中心权限 | 展示无权限提示，不显示列表 |
| 数据延迟 | 汇总数据未完成刷新 | 页面顶部展示更新时间说明 |

## 10. 菜单与入口

| 入口位置 | 入口说明 | 跳转结果 |
| ---- | ---- | ---- |
| 库存中心 > 库存查询 | 菜单常驻入口 | 进入库存查询页面 |
| 驾驶舱 > 可用库存总量 | 驾驶舱库存总览入口 | 跳转库存查询，并自动带入当前仓库 |
| 驾驶舱 > 库存风险 Top | 商品库存风险下钻 | 跳转库存查询，并自动带入对应商品 / 仓库 |

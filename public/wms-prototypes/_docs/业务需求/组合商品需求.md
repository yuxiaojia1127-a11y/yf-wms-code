# 组合商品功能清单（评审版）

> 说明：
>
> - 本文件仅保留“组合商品上架售卖”相关需求
> - 当前口径：库存仍按单品管理；WMS 不新增实体组合库存；APP 只负责按组件 + SKU 拣货
> - 本清单用于评审确认，确认后再合并进全量功能清单

| ---- | ---- | ---- | ---- | ---- | ---- | ---- |

| 商品管理 | 组合商品 | 组合商品编辑 | 业务功能 | Web | 编辑组合商品的组件 SKU、数量、展示价、适用门店与上下架状态。 | 新增 |
| 商品管理 | 组合商品 | 组合商品上下线 | 业务功能 | Web | 支持组合商品上线、暂停、下线与恢复。 | 新增 |
| 商品管理 | 组合商品 | 门店范围配置 | 业务功能 | Web | 配置组合商品在指定门店或门店集合生效。 | 新增 |
| 商品管理 | 组合商品 | 生效时间配置 | 业务功能 | Web | 配置组合商品的开始时间、结束时间与时段限制。 | 新增 |
| 商品管理 | 组合商品 | 关联 SKU 明细维护 | 业务功能 | Web | 维护组合商品与组件 SKU 的对应关系及数量。 | 新增 |
| 商品管理 | 组合商品 | 组合商品统计 | 业务功能 | Web | 查看组合商品销量、转化、售卖数量与关联 SKU 明细。 | 新增 |

## 电商系统

| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 商品展示 | 组合商品上架 | 组合商品展示 | 业务功能 | API/Web | 支持在前台直接展示组合商品、展示价与售卖数量。 | 新增 |
| 购物车 | 组合商品 | 组合商品下单 | 业务功能 | API/Web | 用户下单组合商品后，按组合商品作为订单行成交。 | 新增 |

## WMS仓储系统

| 模块 | 菜单/功能 | 功能点 | 类型 | 客户端 | 描述 | 状态 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 订单履约 | 任务识别 | 组合商品任务识别 | 系统能力 | API/Web | 识别订单中的组合商品行，并映射到对应的单品履约任务。 | 新增 |
| 订单履约 | 拣货提示 | 组件 SKU 关联展示 | 业务功能 | Web/App | 在履约任务中展示组合商品对应的组件 SKU 与数量。 | 新增 |
| 订单履约 | 拣货提示 | 按单品履约出库 | 业务功能 | Web/App | 仍按单品库存进行预扣、拣货、复核与出库。 | 新增 |
| 库存中心 | 库存模型 | 不新增组合库存 | 非功能 | Web/API | 维持库存按 SKU + 仓库 + 仓位 + 批次 + 状态管理。 | 新增 |

## 仓库APP（原揽货配送端APP）

| 模块 | 菜单/功能 | 功能点 | 类型 | 客户端 | 描述 | 状态 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 订单发货 | 作业展示 | 组合商品提示 | 业务功能 | App | 在发货任务中提示该单为组合商品及对应展示信息。 | 新增 |
| 揽货 | 组件提示 | 组件 SKU 展示 | 业务功能 | App | 显示组合商品所对应的组件 SKU、数量与揽货顺序。 | 新增 |
| 揽货 | 作业引导 | 拣货顺序提示 | 业务功能 | App | 对组合商品的组件拣货给出系统推荐顺序。 | 新增 |
| 扫码作业 | 扫码确认 | 扫码确认组件 | 业务功能 | App | 扫码确认组件 SKU 已完成拣货与核销。 | 新增 |

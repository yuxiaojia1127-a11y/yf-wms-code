# WMS-WEB 仓内作业跟踪明细列表简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 仓内作业跟踪明细列表 |
| 所属模块 | 仓内作业 |
| 页面定位 | 承接驾驶舱“今日作业漏斗”中仓内作业跟踪节点的下钻明细页 |
| 页面编码 | `WMS-WEB-030A` |
| 适用端 | WMS-WEB 管理端 |

## 2. 业务说明

仓内作业跟踪明细列表用于承接驾驶舱“今日作业漏斗”中仓内作业跟踪分组的节点下钻需求，帮助仓内管理角色从卡片视图切换到列表式明细处理视图，聚焦仓内节点积压、超时和责任人分布。

页面承接以下节点：

- 待入库
- 待接单揽货
- 待揽货
- 待打包复核
- 待发货

用户点击驾驶舱仓内作业跟踪分组中的任一节点时，进入本页面并自动带入对应节点筛选；用户也可从仓内作业菜单直接进入本页面查看全部仓内节点明细。

## 3. 使用角色

| 角色类型 | 角色 | 操作权限 | 数据权限 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 管理角色 | 仓内管理员 / 仓内主管 | 查询、导出、查看详情 | 所属权限仓库 | 查看仓内节点积压、超时和处理人分布 |
| 协同角色 | 运营协调岗 | 查询、查看详情 | 所属协同仓库 | 用于协调揽货、复核、发货等异常处理 |
| 作业角色 | 仓内作业员 | 无页面权限 | 不开放 | 不直接使用该页面 |

## 4. 功能描述

- 支持从驾驶舱“今日作业漏斗”中仓内作业跟踪任一节点点击进入本页面。
- 支持在仓内作业菜单下新增“仓内作业跟踪明细列表”入口。
- 支持自动带入作业节点筛选。
- 支持按仓库、作业节点、渠道类型、处理状态、关键词查询。
- 支持重置筛选条件。
- 支持导出当前筛选结果。
- 支持点击“查看详情”后从右侧抽屉查看单据详情。

## 5. 查询条件

| 字段名称 | 字段类型 | 查询方式 | 暗字提示 |
| ---- | ---- | ---- | ---- |
| 仓库 | 下拉单选 | 精确筛选 | 默认当前驾驶舱所选仓库 |
| 作业节点 | 下拉单选 | 精确筛选 | 支持自动带入漏斗节点 |
| 渠道类型 | 下拉单选 | 精确筛选 | 即时配送 / 快递 / 自提 |
| 处理状态 | 下拉单选 | 精确筛选 | 全部 / 待处理 / 已超时 / 已完成 |
| 关键词 | 输入框 | 模糊查询 | 支持单号 / 联系人 / 地址编码 |

## 6. 列表字段

| 字段名称 | 字段类型 | 是否必填 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 单号 | 文本 | 是 | SO-240603-121 | 当前节点对应业务单号 |
| 作业节点 | 标签 | 是 | 待打包复核 | 标识当前节点类型 |
| 仓库 | 文本 | 是 | 2号仓库 | 单据归属仓库 |
| 渠道类型 | 文本 | 否 | 快递 | 即时配送 / 快递 / 自提 |
| 当前状态 | 标签 | 是 | 已超时 / 待处理 | 用于标识节点处理状态 |
| 等待时长 | 数值 | 是 | 34 分钟 | 当前节点等待时间 |
| 处理人 | 文本 | 否 | 李昊 | 当前责任人 |
| 更新时间 | 时间 | 是 | 2026-06-03 10:20 | 最近一次状态更新时间 |
| 操作 | 按钮 | 是 | 查看详情 | 打开右侧详情抽屉 |

## 7. 排序与展示规则

- 默认按等待时长倒序展示，超时单优先。
- 当前筛选条件下无数据时，保留查询条件并展示空态。
- 默认每页展示 10 条。
- 页面仅展示仓内作业跟踪分组节点，不展示履约链路节点。

## 8. 查看详情

- 点击“查看详情”后，从页面右侧打开详情抽屉。
- 抽屉至少展示：联系人、单号、地址邮编、配送距离、商品数量、下单时间、作业节点、仓库、渠道类型、处理状态、等待时长、处理人、承诺时间、更新时间、节点摘要、推荐处理动作。
- 抽屉底部提供“进入对应页面”按钮，用于继续处理当前节点。

## 9. 关键规则

- 页面数据口径承接驾驶舱“今日作业漏斗”中的仓内作业跟踪分组，不新增新的节点定义。
- 点击任一仓内作业跟踪节点进入时，需自动带入对应节点筛选。
- 页面不展示履约链路跟踪相关节点，也不提供分组切换。
- 导出范围为当前筛选结果。

## 10. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在节点明细数据 | 展示查询区、列表、分页与详情抽屉 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无仓内作业权限 | 展示无权限提示，不显示列表 |

## 11. 菜单与入口

| 入口位置 | 入口说明 | 跳转结果 |
| ---- | ---- | ---- |
| 驾驶舱 > 今日作业漏斗 > 仓内作业跟踪任一节点 | 漏斗节点下钻入口 | 跳转仓内作业跟踪明细列表，并自动带入节点筛选 |
| 仓内作业 > 仓内作业跟踪明细列表 | 菜单常驻入口 | 进入仓内作业跟踪明细列表 |

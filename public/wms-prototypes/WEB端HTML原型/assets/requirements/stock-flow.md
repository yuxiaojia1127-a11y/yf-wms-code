# WMS-WEB 出入库流水简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 出入库流水 |
| 所属模块 | 库存中心 |
| 页面定位 | 以库存变动事件为主视角的出入库流水查询页，记录每次出入库的变动明细 |
| 页面编码 | `WMS-WEB-014` |
| 适用端 | WMS-WEB 管理端 |

---

## 2. 业务说明

出入库流水用于记录和查询每一次出入库库存变动的完整明细，包括变动类型（入库 / 出库）、业务类型、来源单据、变动数量，形成库存账本视角的流水台账。

与现有功能的定位关系如下：

| 页面 | 主视角 | 核心关注 |
| ---- | ---- | ---- |
| 库存查询（WMS-WEB-012） | SKU + 仓库 | 当前库存汇总量 |
| 库存明细列表（WMS-WEB-013） | 仓库 + 库区 + 货位 | 货位级当前库存状态 |
| **出入库流水（WMS-WEB-014）** | **库存变动事件** | **每次出入库变动的时间、业务类型、数量** |

本页面不承载任何库存控制动作，仅提供查询与导出。

---

## 3. 流水生成规则

每次出入库发生真实变动时，系统自动生成一条流水记录，不可人工新建、删除或修改。

| 触发来源 | 触发节点 | 流水类型 | 变动方向 |
| ---- | ---- | ---- | ---- |
| WEB 端手动入库单提交 | 入库明细入账 | 入库流水 | 增加（+） |
| 揽货 APP 完成发货 | 系统自动生成出库单 | 出库流水 | 减少（-） |
| WEB 端手动出库单提交 | 出库明细扣减 | 出库流水 | 减少（-） |

---

## 4. 功能描述

- 支持在库存中心菜单下进入「出入库流水」页面。
- 支持按仓库、库房、SKU 编码、商品名称、商品分类、流水类型、业务类型、来源单号、操作时间范围进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持数据概览卡片：入库流水数量（次数）、销售出库流水数量（次数）、其他出库流水数量（次数），点击卡片快速筛选。
- 支持以列表方式展示每条流水的变动信息。
- 支持点击「查看详情」查看单条流水的完整信息。
- 支持从库存查询页、库存明细列表页的列表行点击「查看流水」下钻进入，自动带入对应 SKU + 仓库 + 库房（库存明细另带入货位）筛选条件。

## 6. 数据概览

| 卡片名称 | 统计口径 | 底部说明 |
| ---- | ---- | ---- |
| 入库流水 | 流水类型 = 入库的流水条数 | 次数 |

## 8. 排序与展示规则

- 列表默认按发生时间倒序展示，最新流水在前。
- 同一 SKU 同一时间点若有多条流水（如入库单含多个 SKU），按单号正序展示。
- 变动数量列正数（增加）使用绿色文字，负数（减少）使用红色文字，加减符号显式展示。
- 来源单号有值时为可点击的文字链接，点击跳转至对应销售订单详情；无来源时展示「-」。
- 当前筛选条件下无数据时，保留查询条件并展示空态。
- 默认每页展示 20 条，支持切换至 50 条 / 100 条。

---

## 9. 查看详情

点击「查看详情」后，打开右侧详情抽屉，展示以下内容：

| 信息分组 | 展示字段 |
| ---- | ---- |
| 流水基础信息 | 出入库单号、发生时间、仓库、库房、库区（若有）、货位（若有）|
| 商品信息 | 商品名称、SKU 编码、规格、单位、条码、所属分类（完整路径，如：日化 > 洗护 > 洗衣液）、批次号、效期（若有）|
| 变动信息 | 流水类型、业务类型、变动方向、变动数量 |
| 来源信息 | 来源单号（销售出库为销售订单号链接，其他为「-」）、来源单类型 |
| 操作信息 | 操作人、操作时间、备注 |

---

## 10. 关键规则

- 流水记录由系统在出入库变动发生时自动生成，**不支持人工新建、编辑或删除**。
- 业务类型固定为八类：采购入库、退货入库、调拨入库、其他入库、销售出库、调拨出库、报损出库、其他出库。
- 来源单号目前仅销售出库关联销售订单号；其他业务类型暂无来源单，展示为空（-）。
- 销售出库流水由系统自动触发生成，操作人固定为「系统」。
- 同一来源单号可对应多条流水（一张销售订单含多个 SKU，每个 SKU 独立生成一条流水）。
- 查询时间范围最大为 90 天；如需更长周期数据，通过导出功能获取。
- 导出范围为当前筛选结果，单次导出上限 10,000 条。

---

## 11. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在流水数据 | 展示查询区、流水列表、分页与详情能力 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无库存中心权限 | 展示无权限提示，不显示列表 |
| 时间范围过大 | 查询范围超过 90 天 | 提示用户缩短时间范围或使用导出 |

# 商品管理后台原型设计

## 1. 设计目标

- 基于 [00商品管理简易需求.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/需求方案/需求文档/00简易需求/商品管理/00商品管理简易需求.md) 输出可直接用于绘制后台原型的页面设计说明
- 先明确商品管理的大框架、角色视图、页面关系和主流程
- 将 `货主商品`、`WMS商品编码`、`WMS商品识别档案` 三类对象在页面上拆开表达
- 保证商品管理页面既能满足货主日常使用，也能满足 WMS 商品治理和异常处理

## 2. 设计范围

### 2.1 本期范围

- 商品管理主框架
- 我的商品
- 货主商品管理
- 商品识别档案
- 识别异常处理

### 2.2 二期预留

- 供给关系管理
- 同步日志详情页
- 跨货主自动履约来源联查

## 3. 角色与视图

### 3.1 角色划分

| 角色 | 页面入口 | 数据范围 | 核心目标 |
| --- | --- | --- | --- |
| 货主用户 | 我的商品 | 仅本货主 | 查询、维护、同步自己的商品资料 |
| WMS商品运营 | 货主商品管理 | 全量货主 | 查看全量商品、定位数据质量问题、追踪同步状态 |
| WMS商品治理 | 商品识别档案 / 识别异常处理 | 全量识别数据 | 管理识别档案、处理识别冲突、支撑供给关系 |

### 3.2 设计结论

商品管理后台采用 `一个一级菜单 + 多个角色视图 + 同一底层数据对象` 的设计方式，不拆成两套完全独立系统。

- 货主用户看“我的商品”
- WMS商品运营看“货主商品管理”
- WMS商品治理看“商品识别档案”和“识别异常处理”

## 5. 页面关系

| 来源页面 | 触发动作 | 目标页面 |
| --- | --- | --- |
| 我的商品 | 查看商品 | 商品详情抽屉 |
| 我的商品 | 新建/编辑 | 新建/编辑抽屉 |
| 货主商品管理 | 查看商品 | 商品详情抽屉 |
| 货主商品管理 | 点击识别商品ID | 商品识别档案 |
| 货主商品管理 | 点击识别状态异常 | 识别异常处理 |
| 商品识别档案 | 查看关联商品 | 货主商品管理筛选结果 |
| 识别异常处理 | 查看商品明细 | 货主商品管理筛选结果 |

## 6. 顶层框架

### 6.1 页面共性布局

所有商品管理页面采用统一的后台布局：

```text
页面标题区
├─ 页面标题
├─ 页面说明
└─ 右侧操作区

统计概览区
├─ 核心指标卡
└─ 异常提醒入口

查询筛选区
├─ 条件字段
└─ 查询 / 重置 / 导出

主内容区
├─ 列表区或主表格
└─ 详情抽屉 / 右侧侧板 / 异常对比区
```

### 6.2 视觉层级建议

- 顶部标题区突出页面定位，不堆太多辅助说明
- 统计概览区采用轻量数字卡，体现“同步失败”“识别异常”等重点问题
- 列表区保持高信息密度，避免过多卡片化
- 详情采用右侧抽屉或侧板，减少频繁跳页

## 7. 主流程原型

### 7.1 商品建档与识别主流程

```text
货主维护商品
  -> 系统生成WMS商品编码
  -> 系统生成/归并识别商品ID
  -> 列表展示同步状态与识别状态
  -> WMS查看识别档案或异常
```

### 7.2 WMS运营排查主流程

```text
进入货主商品管理
  -> 按货主/状态/识别状态筛选
  -> 查看商品详情
  -> 查看同步日志或识别商品ID
  -> 如存在冲突则进入识别异常处理
```

### 7.3 WMS治理处理主流程

```text
进入商品识别档案
  -> 查看识别档案归集结果
  -> 发现冲突或异常
  -> 进入识别异常处理
  -> 对比字段差异
  -> 完成异常处理闭环
```

## 8. 页面级原型设计

### 8.1 我的商品

**页面目标**

- 给货主提供商品查询、维护、同步入口
- 让货主快速确认商品是否已建档、是否启用、是否同步成功

**使用角色**

- 货主用户

**页面布局**

```text
标题区
├─ 标题：我的商品
└─ 右侧按钮：新建商品

统计区
├─ 商品总数
├─ 启用商品
├─ 同步失败
└─ 待处理异常提示

查询区
├─ 商品状态
├─ 同步状态
├─ 商品类型
├─ 货主SKU编码
├─ 商品名称
└─ 条码

列表区
├─ 货主SKU编码
├─ 商品名称
├─ 条码
├─ 基础单位
├─ 规格关键值
├─ 仓储规则
├─ 商品状态
├─ 同步状态
└─ 操作
```

**核心交互**

- 点击 `新建商品` 打开右侧抽屉
- 点击 `查看/编辑` 打开详情抽屉
- 点击 `同步` 触发同步并刷新当前行状态
- 货主默认看不到全量货主筛选和异常处理入口

### 8.2 货主商品管理

**页面目标**

- 给 WMS 商品运营提供全量商品视图
- 支撑商品排查、同步追踪、识别状态联查

**使用角色**

- WMS商品运营

**页面布局**

```text
标题区
├─ 标题：货主商品管理
└─ 右侧按钮：导出

统计区
├─ 货主数
├─ 商品总数
├─ 同步失败
├─ 识别异常
└─ 停用商品

查询区
├─ 货主
├─ 商品状态
├─ 同步状态
├─ 识别状态
├─ 货主SKU编码
├─ WMS商品编码
├─ 识别商品ID
├─ 商品名称
└─ 条码

列表区
├─ 货主
├─ WMS商品编码
├─ 货主SKU编码
├─ 商品名称
├─ 识别商品ID
├─ 条码
├─ 基础单位
├─ 规格关键值
├─ 仓储规则
├─ 识别状态
├─ 商品状态
├─ 同步状态
└─ 操作
```

**核心交互**

- 点击 `识别商品ID` 跳转商品识别档案
- 点击 `识别状态` 异常标签跳转识别异常处理
- 点击 `查看日志` 打开底部日志面板或抽屉

### 8.3 商品识别档案

**页面目标**

- 展示系统自动生成的 WMS 商品识别档案
- 支撑 WMS 查看一个识别商品ID下归集了哪些货主商品

**使用角色**

- WMS商品治理
- WMS商品运营

**页面布局**

```text
标题区
├─ 标题：商品识别档案
└─ 右侧辅助说明：用于同品候选归集与履约匹配

统计区
├─ 识别档案数
├─ 候选中
├─ 已生效
└─ 冲突待处理

查询区
├─ 识别商品ID
├─ 主条码
├─ 识别状态
├─ 基础单位
└─ 规格关键值

主列表区
├─ 识别商品ID
├─ 主条码
├─ 基础单位
├─ 规格关键字段
├─ 仓储规则摘要
├─ 关联货主商品数

└─ 更新时间

右侧详情侧板
```

- 点击列表行，右侧展开详情侧板
- 在侧板中查看关联货主商品及差异字段
- 从侧板跳转回货主商品管理查看单个商品

### 8.4 识别异常处理

**页面目标**

- 处理条码相同但单位、规格、仓储规则冲突的数据
- 给 WMS 商品治理提供异常闭环页面

**使用角色**

- WMS商品治理

**页面布局**

```text
标题区
├─ 标题：识别异常处理
└─ 右侧按钮：导出异常

统计区
├─ 冲突待处理
├─ 今日新增异常
└─ 已处理异常

查询区
├─ 异常类型
├─ 条码
├─ 货主
├─ 识别状态
└─ 更新时间

异常列表区
├─ 异常条码
├─ 涉及货主数
├─ 冲突字段
├─ 当前状态
└─ 更新时间

右侧对比区
├─ 商品A关键字段
├─ 商品B关键字段
├─ 冲突项高亮
└─ 处理记录
```

**核心交互**

- 选中异常记录后，右侧展示字段对比
- 高亮冲突字段，帮助快速定位是单位、规格还是仓储规则问题
- 展示处理记录，便于追踪异常闭环

## 9. 状态页设计

### 9.1 商品列表状态

- 初始态：展示默认查询结果
- 空态：无数据时展示空态插画和“新建商品”入口
- 加载态：列表骨架屏
- 同步失败态：列表行突出失败状态并可查看日志

### 9.2 识别档案状态

- 候选中：正常展示黄色轻提示标签
- 已生效：正常展示绿色标签
- 冲突待处理：红色标签，并提供异常入口

### 9.3 异常处理状态

- 无异常：展示“当前无识别异常”
- 有异常：默认按更新时间倒序展示
- 已处理：支持切换查看处理记录

## 10. 组件规范

### 10.1 查询区

- 查询条件最多每行 4 个单位宽度
- 同行字段等宽排列
- 按钮紧跟最后一个查询条件

### 10.2 列表区

- 采用标准后台表格
- 关键状态字段使用标签化展示
- 编码类字段支持点击复制

### 10.3 详情抽屉/侧板

- 商品详情使用右侧抽屉
- 识别档案和异常对比优先使用右侧侧板
- 侧板宽度明显大于普通详情抽屉，保证对比可读性

## 12. 设计结论

商品管理后台原型建议按 `两类角色、四个核心页面` 设计：

1. `我的商品`：货主使用，聚焦本货主商品维护与同步
2. `货主商品管理`：WMS运营使用，聚焦全量商品查询与排查
3. `商品识别档案`：WMS治理使用，聚焦系统识别结果查看
4. `识别异常处理`：WMS治理使用，聚焦冲突数据处理

原型第一版先完成页面框架、分区结构、列表布局和跳转关系，再进入字段排序、按钮权限和细节交互设计。

# 库存管理后台原型设计（自营版大框架）

## 1. 设计目标

库存管理后台原型面向自营WMS业务，围绕库存汇总、库存明细、批次效期、锁定记录、库存流水和库存异常组织页面。

本阶段定义页面结构、导航入口、主视图和模块关系，不展开字段级和交互细节。

## 2. 角色与使用场景

| 角色 | 使用目标 | 核心关注点 |
| --- | --- | --- |
| 仓库管理员 | 管理仓内库存 | 库存数量、库位分布、批次效期、冻结调整 |
| 仓内主管 | 监控库存作业状态 | 库存异常、锁定占用、库位占用、盘点差异 |
| 运营人员 | 查询可用库存 | SKU可用量、缺货风险、临期风险 |
| 财务/对账人员 | 核对库存流水 | 库存变化、业务单据、账实差异 |
| 系统管理员 | 处理系统异常 | 流水异常、库存负数风险、任务卡滞 |

## 8. 原型第一版页面优先级

### 8.2 第二优先级

| 页面 | 目标 |
| --- | --- |
| 批次效期 | 支持临期、禁售、过期库存监控 |

| 库存异常 | 支持库存不足、负库存风险和流水异常处理 |

## 9. 大框架结论

库存管理后台原型按“库存查询 + 库存追溯 + 异常处理”设计：

1. 库存汇总提供SKU和仓库维度的库存总览。
2. 库存明细提供库位、批次和状态维度的实物库存视图。
3. 批次效期提供食品类商品的临期、禁售和过期风险视图。
4. 库存锁定提供业务占用和释放追踪。
5. 库存流水提供库存变化全链路追溯。
6. 库存异常提供库存风险和系统异常处理入口。

第一版原型先完成库存汇总、库存明细和库存流水，再补充批次效期、库存锁定和库存异常。

# WMS角色-页面映射表

## 1. 文档说明

本文基于 `01~06` 最新口径，将页面统一映射到 3 大类角色：`系统管理类 / 仓内作业类 / 货主查询类`，用于后续权限评审、菜单裁剪和原型回写。

## 2. 映射规则

| 角色类型 | 映射原则 |
| ---- | ---- |
| 系统管理类 | 主要覆盖开放平台、登录、上下文、消息、异常排查和全局巡检页面 |
| 仓内作业类 | 主要覆盖仓内执行、仓内管理、库存、入库、出库、履约、物流、售后、调拨等业务页面 |
| 货主查询类 | 主要覆盖货主可查看的店铺、库存、入库、出库、发货和物流结果查询页面 |

## 3. 页面数量汇总

| 角色类型 | 终端 | 页面数量 | 覆盖模块 |
| ---- | ---- | ---- | ---- |
| 系统管理类 | WEB | 3 | 开放平台 |
| 仓内作业类 | WEB | 32 | 基础资料、入库中心、库存中心、出库中心、履约中心、物流协同、售后中心、调拨中心、仓内作业中心、异常中心、结算中心 |
| 货主查询类 | WEB | 16 | 基础资料、入库中心、库存中心、出库中心、履约中心、物流协同 |

| 货主查询类 | APP | 0 | 无 |

## 6. 当前结论

| 结论项 | 说明 |
| ---- | ---- |
| 系统管理类 | 当前主要落在 `WEB` 开放平台页，以及 `APP` 登录、上下文、消息、异常与巡检辅助页 |
| 仓内作业类 | 是当前页面覆盖最完整的一类，贯穿 `WEB` 管理页和 `APP` 执行页 |
| 货主查询类 | 当前仅在 `WEB` 端承接货主查询页面，`APP` 端暂不开放 |
| 后续如需细化 | 可在本表基础上继续拆为“角色-页面-按钮”三级映射 |

# 仓储管理后台原型设计（自营版大框架）

## 1. 设计目标

仓储管理后台原型面向自营WMS业务，围绕仓库、货位、容量规则、上下架规则和状态监控组织页面。

本阶段定义页面结构、导航入口、主视图和模块关系，不展开字段级和交互细节。

## 2. 角色与使用场景

| 角色 | 使用目标 | 核心关注点 |
| --- | --- | --- |
| 仓库管理员 | 维护仓储基础资料 | 仓库、货位是否完整可用 |
| 仓内主管 | 查看现场结构和状态 | 库位占用、锁定、容量、作业规则 |
| 仓内作业人员 | 在作业中定位库位 | 上架、拣货、移库、盘点的库位可用性 |
| 系统管理员 | 处理基础资料异常 | 编码重复、状态冲突、任务占用、删除阻断 |

| 来源页面 | 触发点 | 目标页面 |

## 7. 权限与展示差异

| 能力 | 仓库管理员 | 仓内主管 | 仓内作业人员 | 系统管理员 |
| --- | --- | --- | --- | --- |
| 查看仓库/货位 | 支持 | 支持 | 支持作业关联范围 | 支持 |
| 新增/编辑仓库 | 支持 | 不支持 | 不支持 | 支持 |
| 新增/编辑货位 | 支持 | 按授权支持 | 不支持 | 支持 |

| 查看状态监控 | 支持 | 支持 | 支持作业关联范围 | 支持 |

## 8. 原型第一版页面优先级

### 8.1 第一优先级

| 页面 | 目标 |
| --- | --- |
| 仓库管理 | 建立自营仓储节点维护入口 |
| 货位管理 | 建立最小存放单位维护入口 |

### 8.2 第二优先级

| 页面 | 目标 |
| --- | --- |
| 货位规则 | 支持容量、品类、商品、批次和临期规则维护 |
| 仓储状态监控 | 支持货位占用、锁定和状态异常查看 |

## 9. 大框架结论

仓储管理后台原型按“仓库结构 + 货位规则 + 状态监控”设计：

1. 仓库管理维护自营仓储节点。
2. 货位管理维护最小存放单位、容量和使用状态。
3. 货位规则维护容量、品类、商品、批次和临期限制。
4. 仓储状态监控查看货位占用、锁定、容量预警和异常状态。

第一版原型先完成仓库管理和货位管理，再补充货位规则和仓储状态监控。

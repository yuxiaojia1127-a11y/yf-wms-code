# 货位管理简易需求

## 1. 基本信息

- 功能名称：货位管理
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-W03`
- 所属模块：仓储管理
- 当前口径来源：`00原型方案/02WEB端HTML版/01WMS_WEB端高保真原型.html`

## 2. 业务目标

维护库区下的货位主数据，支持货位查询、查看、新建、编辑、启停及容量与上下架规则配置，作为上架、拣选、补货、盘点、移库等业务的最小存放单位。

## 3. 功能范围

- 列表查询
- 列表展示与分页
- 新建货位
- 编辑货位
- 查看货位详情
- 启用/停用货位
- 删除货位
- 查看货位操作日志
- 导出

不包含：批量导入、批量启停、货位可视化拓扑图、自动生成货位编码规则配置、三方实时同步校验。

## 4. 查询条件

| 字段名称 | 字段类型  | 查询方式 | 说明                          |

## 8. 关键规则

- 列表默认按"所属仓库顺序 + 所属库区排序值倒序 + 货位排序值倒序"展示，分页区展示总条数、页码、上一页、下一页。
- 翻页后保留当前查询条件。
- 当前筛选结果为空时，展示空态提示。
- 抽屉中"所属仓库"切换后联动可选"所属库区"范围。
- 同一库区下"货位编码"不可重复。
- 上下架规则中"禁止批次混放""禁止生产年限货""货主限定"可独立勾选/选择。
- 容量字段（重量/数量/体积/尺寸）允许为空，但填写后必须为大于 0 的数字。
- 点击抽屉右上角关闭、取消、遮罩空白处时关闭抽屉；点击抽屉内部非关闭区域不应误关闭。
- 点击"保存"时校验必填字段与数值合法性，保存成功后关闭抽屉并刷新列表。
- 点击"启用/停用"时弹出居中确认框；当货位"使用状态"为"占用"时，不允许停用，需先完成下架/移库。
- 点击"删除"时弹出居中确认框；当货位"使用状态"为"占用"或"锁定"时，不允许删除，需先解除占用或锁定。
- 抽屉底部展示该货位的操作日志（时间、操作类型、内容），仅查看模式下显示完整列表。

## 9. 状态规则

### 9.1 货位状态（管理状态）

| 状态 | 含义        | 规则                            |
| -- | --------- | ----------------------------- |
| 启用 | 货位可参与业务   | 可在上架、拣选、补货、盘点等业务中被引用          |
| 停用 | 货位不可参与新业务 | 默认不出现在新增可选范围内，历史库存保留，使用状态需为"空"方可停用 |

### 9.2 货位使用状态

| 状态 | 含义        | 触发                          |
| -- | --------- | --------------------------- |
| 空  | 当前无库存、无任务 | 库存为 0 且无在途任务时自动置为"空"        |
| 占用 | 当前有库存或有任务 | 货位上有库存或有未完成的上架/拣选任务时自动置为"占用" |
| 锁定 | 临时锁定，禁止动作 | 盘点、维修等场景人工锁定，期间不参与上架/拣选     |

## 10. 验收要点

- 能按所属仓库、库区、货位类型、货位编码、使用状态完成查询
- 能打开新建、查看、编辑抽屉，仓库/库区字段联动正确
- 能正常关闭抽屉，不出现误关闭
- 同库区下货位编码唯一
- 列表展示货品ABC分类，且位置在状态前
- 容量与定位字段支持空值，填写后做大于 0 校验
- 上下架规则中各勾选项可独立保存
- 占用状态下不允许停用，给出提示
- 占用或锁定状态下不允许删除，给出提示
- 点击保存后抽屉关闭并刷新列表
- 点击启用/停用后弹出确认框
- 点击删除后弹出确认框
- 分页区展示总条数、勾选数、页码切换
- 查看抽屉中可查看该货位的操作日志

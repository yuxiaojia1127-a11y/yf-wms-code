# WMS-WEB 库存明细列表简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 库存明细列表 |
| 所属模块 | 库存中心 |
| 页面定位 | 以仓库、库区、货位为主视角的库存明细查询页 |
| 页面编码 | `WMS-WEB-013` |
| 适用端 | WMS-WEB 管理端 |

## 2. 业务说明

库存明细列表用于承接库存中心中按库位明细查看库存的需求，帮助仓库管理员、仓内主管和运营人员快速确认某个 SKU 当前具体存放在哪个仓库、哪个库区、哪个货位，以及对应批次、库存状态和实物数量。

该页面与“库存查询”形成分层关系：

- `库存查询` 负责 SKU + 仓库维度的库存汇总查看。
- `库存明细列表` 负责 仓库 + 库区 + 货位 + SKU + 批次 + 库存状态 的明细查看。

当前版本聚焦货位维度库存查询与下钻，不在本页面直接承载库存调整、冻结/解冻等控制动作；如需进一步处理，进入关联详情或后续控制页面。

## 3. 使用角色

| 角色类型 | 角色 | 操作权限 | 数据权限 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 管理角色 | 仓库管理员 | 查询、导出、查看详情 | 所属权限仓库 | 页面核心使用角色 |
| 管理角色 | 仓内主管 | 查询、导出、查看详情 | 所属仓库 | 用于查看货位分布、批次状态和异常库存 |
| 业务角色 | 运营人员 | 查询、导出 | 授权商品与仓库范围 | 重点查看商品实际所在货位及可用情况 |
| 协同角色 | 客服 / 售后人员 | 查询 | 授权仓库范围 | 用于辅助答复库存去向，不支持控制动作 |
| 作业角色 | 上架 / 拣货人员 | 可按授权查看 | 所属作业仓库 | 用于确认目标货位库存情况 |

## 4. 功能描述

- 支持在库存中心进入“库存明细列表”页面。
- 支持按仓库、库区、货位、SKU 编码、商品名称、条码、批次号、库存状态进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持以明细列表方式展示货位维度库存数据。
- 支持查看单条库存明细详情。
- 支持从 `库存查询` 页面点击“查看明细”下钻进入，并自动带入 `仓库 + SKU` 等上下文条件。
- 支持从驾驶舱 `库存风险 Top` 等入口跳转进入，并自动带入 `仓库 + SKU + 批次 / 风险类型` 等筛选条件。

## 7. 排序与展示规则

- 列表默认按最近变更时间倒序展示。
- 页面主维度优先展示 `仓库 + 库区 + 货位`，其后展示商品信息与库存数量。
- 同一 SKU 在不同库位下必须分行展示，不在当前页面做合并汇总。
- 同一货位下同一 SKU 如存在不同批次或不同库存状态，按明细拆行展示。
- 冻结、报损、待检等非正常状态库存需通过标签进行明显区分。
- 当前筛选条件下无数据时，保留查询条件并展示空态。
- 默认每页展示 10 条。

## 8. 查看详情

- 点击“查看详情”后，进入库存详情页或打开右侧详情抽屉。
- 详情至少展示：商品信息、仓库、库区、货位、批次、库存状态、实物 / 锁定 / 冻结 / 可用数量、最近库存流水摘要、关联锁定摘要。
- 当前页面仅做查询与下钻，不直接在列表区进行冻结、解冻或库存调整。

## 9. 关键规则

- 库存明细唯一性口径为：同一 `SKU + 仓库 + 库区 + 货位 + 批次 + 库存状态` 形成一条库存明细。
- 无批次管理商品可使用默认批次占位规则展示。
- 开启效期管理的商品，需展示生产日期、到期日期和效期状态。
- 冻结库存不参与可用数量计算。
- 页面数据口径为货位维度明细，不等同于 `库存查询` 的仓库汇总口径。
- 从其他页面跳入时，应自动保留来源页面带入的 `仓库 / SKU / 批次 / 风险类型` 等上下文。
- 导出范围为当前筛选结果。

## 10. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在库存明细数据 | 展示查询区、列表、分页与查看详情能力 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无库存中心权限 | 展示无权限提示，不显示列表 |
| 数据延迟 | 明细数据尚未完成同步 | 页面顶部展示更新时间说明 |

## 11. 菜单与入口

| 入口位置 | 入口说明 | 跳转结果 |
| ---- | ---- | ---- |
| 库存中心 > 库存明细列表 | 菜单常驻入口 | 进入库存明细列表页面 |
| 库存查询 > 查看明细 | 从 SKU 汇总结果下钻 | 跳转库存明细列表，并自动带入仓库与 SKU |
| 驾驶舱 > 库存风险 Top | 风险 SKU 下钻入口 | 跳转库存明细列表，并自动带入仓库、SKU、批次等条件 |

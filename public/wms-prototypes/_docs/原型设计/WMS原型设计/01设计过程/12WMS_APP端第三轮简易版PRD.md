# WMS_APP端第三轮简易版PRD

## 1. 文档说明

本文为 `WMS原型设计` 中 `WMS_APP端` 的第三轮简易版 PRD，承接前两轮已完成的 `通用基础能力 + 工作台与任务中心 + 入库/出库执行主链路` 与 `物流协同 + 调拨作业`，继续补齐 APP 端的售后作业、仓内作业和异常扩展能力。

本轮重点覆盖：

- 售后作业
- 仓内作业
- 异常扩展

本轮特别说明：

- 本轮能力以现场执行和问题反馈为主，不替代 Web 端的后台跟踪、异常工单和结算处理。
- 退货、加工、库内转移等均属于非首批高频链路，因此本轮以任务处理和结果回传为主，不提前扩展复杂审批流。
- 异常扩展重点解决“现场发生异常时怎么报、怎么留痕、怎么回流后台”，不在 APP 端完成完整闭环。

本轮不展开以下范围：

- 消息中心
- 我的
- 面单协同扩展
- 异常工单闭环

状态口径说明：本文中的任务状态、执行节点状态、交接状态、质检状态和异常状态统一引用 [16WMS_APP端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/16WMS_APP端状态口径总表.md)；若本文件局部示例与状态口径总表存在差异，以状态口径总表为准。

## 2. 功能目标

本轮简易版 PRD 的目标是补齐 APP 端中剩余的低频但必要能力，让仓内执行端在退货处理、仓内加工、库内转移和现场异常反馈方面形成完整补充。

具体目标如下：

1. 建立退货收货与质检执行能力，支持退货商品收货、质检、回库或报损处理。
2. 建立加工任务执行能力，支持加工任务接单、执行和结果提交。
3. 建立库内转移任务执行能力，支持扫码确认和转移结果提交。
4. 建立统一异常上报能力，支持对收货、上架、备货、发运、退货和物流交接异常进行现场反馈。
5. 明确售后作业、仓内作业和异常扩展与 Web 端售后中心、仓内作业中心、异常中心之间的依赖关系。

## 7. 核心流程

### 7.1 退货处理主链路

1. 作业员或主管在任务中心进入退货收货与质检页。
2. 确认退货商品和应收数量后执行收货。
3. 对商品进行质检，形成可回库、报损或部分异常的结论。
4. 提交质检结果后，结果回流到 Web 端售后中心。

### 7.2 加工任务主链路

1. 作业员在任务中心进入加工任务页。
2. 接单后开始加工执行。
3. 完成加工后提交结果，如加工数量、完成情况和备注。
4. 结果回流到 Web 端仓内作业中心。

### 7.3 库内转移主链路

1. 作业员在任务中心进入库内转移任务页。
2. 扫码确认原货位、目标货位和商品信息。
3. 提交转移结果后，库存位置同步更新。
4. 结果回流到库存中心和仓内作业中心。

### 7.4 异常上报主链路

1. 用户在任务执行过程中或单独从异常中心入口进入异常上报页。
2. 选择异常类型，如破损、少收、码不匹配、物流交接异常等。
3. 填写异常说明并提交。
4. 异常记录回流到 Web 端异常中心或相关业务模块继续处理。

## 8. 状态流转

本章节不再定义独立的 APP 端状态体系，统一引用 [16WMS_APP端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/16WMS_APP端状态口径总表.md)；以下内容仅用于说明本轮涉及任务或结果对象的状态使用范围、页面展示位置和理解方式。

### 8.1 退货处理任务状态

| 状态 | 说明 |
| ---- | ---- |
| 待接单 | 待领取退货处理任务 |
| 待收货 | 已接单，待执行收货 |
| 待质检 | 收货完成，待形成质检结论 |
| 已完成 | 质检和处理结果已提交 |
| 异常 | 收货或质检过程中存在异常 |

### 8.2 仓内作业任务状态

| 状态 | 说明 |
| ---- | ---- |
| 待接单 | 待领取任务 |
| 处理中 | 已开始执行 |
| 已完成 | 结果已提交 |
| 异常 | 执行中存在异常 |

### 8.3 异常上报状态

| 状态 | 说明 |
| ---- | ---- |
| 待提交 | 异常信息尚未提交 |
| 已提交 | 异常已上报成功 |
| 提交失败 | 异常上报失败，可重试 |

### 8.4 质检结果状态

| 状态 | 说明 |
| ---- | ---- |
| 可回库 | 商品可重新回库 |
| 报损 | 商品不可回库，需报损 |
| 部分异常 | 部分商品或数量存在异常 |

## 12. 关键操作

| 模块 | 关键操作 | 说明 |
| ---- | ---- | ---- |
| 售后作业 | 收货 | 确认退货商品到仓 |

| 仓内作业 | 接单 | 锁定加工或转移任务归属 |

| 异常扩展 | 选择异常类型 | 明确异常分类 |
| 异常扩展 | 填写异常说明 | 记录现场问题 |
| 异常扩展 | 提交异常 | 回流后台异常中心 |

## 13. 异常处理

| 场景 | 处理要求 |
| ---- | ---- |
| 退货实收与应收不一致 | 必须登记差异或异常说明 |
| 质检结论缺失 | 不允许直接提交完成 |
| 加工结果提交失败 | 保留现场录入内容并支持重试 |
| 库内转移扫码不匹配 | 显示扫码失败原因并阻止提交 |
| 异常上报失败 | 展示失败原因并支持在线重试 |
| 任务状态失效 | 提示当前任务已不可继续处理 |

## 15. 模块依赖与协作

| 模块 | 依赖对象 | 依赖说明 |
| ---- | ---- | ---- |
| 售后作业 | Web 端售后中心 | 退货结果需回流售后中心查看和跟踪 |
| 售后作业 | 库存中心 | 回库或报损结果影响库存状态 |
| 仓内作业 | Web 端仓内作业中心 | 加工和转移结果需回流后台管理端 |

| 异常扩展 | Web 端异常中心 | 现场异常需回流后台统一处理 |
| 异常扩展 | 相关业务模块 | 异常来源可能挂到入库、出库、物流、退货等上下文 |

## 16. 待确认项

| 编号 | 待确认项 | 说明 |
| ---- | ---- | ---- |

| 2 | 加工任务是否需要区分不同加工类型模板 | 当前统一按加工任务处理 |

## 17. 测试关注点

| 类别 | 测试点 |
| ---- | ---- |
| 售后作业 | 收货、质检、回库/报损结果是否正确回流 |
| 仓内作业 | 加工任务和库内转移任务状态流转是否正确 |
| 扫码校验 | 库内转移扫码是否正确拦截不匹配场景 |
| 异常上报 | 各类异常类型是否能正确提交并回流后台 |
| 权限 | 作业员、主管、管理员对退货质检和仓内任务的权限是否正确 |
| 弱网 | 结果提交失败时是否能正确在线重试 |

## 1. 文档说明

本文用于统一 `WMS_APP端` 当前信息架构、页面清单、页面原型说明和三轮简易版 PRD 中涉及的状态口径，作为后续页面细化、联调、测试和跨端协同回写的统一参考。

- 任务状态、执行状态、页面反馈状态混用
- 入库、出库、调拨、退货等链路中的节点名称不统一
- 物流交接和异常提报在不同页面中的表达不一致

## 2. 使用原则

| 原则 | 说明 |
| ---- | ---- |
| 先区分任务状态和页面状态 | 任务状态用于业务流转，页面状态用于加载与反馈 |
| 任务状态面向列表可筛选 | 列表中显示的状态应可枚举、可统计 |
| 执行节点状态单独表达 | 接单、备货、收货、上架、交接、质检等节点状态不直接替代任务主状态 |
| 异常结果单独留痕 | 异常提报作为结果对象，不直接替代所有任务主状态 |
| 与 Web 协同保持映射 | APP 的执行状态应能映射到 Web 后台可识别的结果状态 |

## 3. 页面通用状态

| 状态分类 | 标准口径 | 说明 | 适用范围 |
| ---- | ---- | ---- | ---- |
| 页面状态 | 默认 | 当前上下文下正常展示页面数据 | 全部页面 |
| 页面状态 | 加载中 | 数据请求中，支持骨架屏 | 全部页面 |
| 页面状态 | 空数据 | 当前筛选下无任务或无记录 | 列表页 |
| 页面状态 | 无权限 | 当前角色或仓库无权限 | 全部页面 |
| 页面状态 | 网络异常 | 在线请求失败，需要重试 | 全部页面 |
| 操作反馈 | 操作成功 | 接单、提交、复核、交接等动作成功 | 全部页面 |
| 操作反馈 | 操作失败 | 状态冲突、扫码不匹配、任务失效、接口失败 | 全部页面 |

## 4. 任务中心主状态

| 状态 | 说明 | 适用对象 |
| ---- | ---- | ---- |
| 待处理 | 任务已进入当前用户可处理范围，但尚未实际开始 | 我的任务、任务中心 |
| 处理中 | 已开始执行，尚未完成 | 我的任务、任务中心 |
| 待交接 | 已完成出库结果，待物流交接或后续确认 | 出库相关任务 |
| 已完成 | 任务闭环完成 | 全部任务 |
| 已取消 | 后台取消或任务失效，不再继续处理 | 全部任务 |
| 异常 | 任务执行中断或存在异常待回流 | 全部任务 |

说明：

- `全部任务列表` 可以展示更广义的状态集合。
- `我的任务列表` 建议优先用 `待处理 / 处理中 / 待交接 / 已完成` 这一套口径。

| 已接单 | 任务已锁定到当前执行人 |

### 5.2 执行进度状态

| 状态 | 说明 |

| 执行中 | 正在执行当前动作 |
| 已完成 | 当前动作完成 |
| 失败 | 当前动作执行失败 |

## 6. 出库作业状态

### 6.1 发货履约任务主状态

| 状态 | 说明 |
| ---- | ---- |
| 待处理 | 已进入当前仓内执行范围，待接单或待开始 |
| 处理中 | 已接单并开始备货、复核、出库中的任一环节 |
| 待交接 | 出库结果已确认，待执行物流交接 |
| 已完成 | 交接完成或任务在 APP 侧已闭环 |
| 异常 | 备货、复核、出库过程中存在异常 |

### 6.2 备货扫码状态

| 状态 | 说明 |
| ---- | ---- |
| 待扫码 | 尚未开始扫描 |
| 扫码中 | 正在执行扫码核销 |
| 已核销 | 本次核销通过并提交成功 |
| 核销失败 | 扫码不匹配、数量不符或提交失败 |

### 6.3 复核与出库确认状态

| 状态 | 说明 |
| ---- | ---- |
| 待复核 | 备货完成，待复核 |
| 复核中 | 正在复核商品行和数量 |
| 复核完成 | 复核通过 |
| 已出库 | 出库确认成功 |
| 出库失败 | 出库确认未成功 |

## 12. 异常扩展状态

### 12.1 异常提报状态

| 状态 | 说明 |
| ---- | ---- |
| 待提交 | 已填写异常信息，尚未提交 |
| 已提交 | 已成功回流后台异常中心 |
| 提交失败 | 异常提报未成功 |

### 12.2 异常类型建议口径

| 类型 | 说明 |
| ---- | ---- |
| 破损 | 商品或包材破损 |
| 少收 | 收货数量不足 |
| 码不匹配 | 扫码结果与任务不一致 |
| 物流交接异常 | 出库后交接失败或信息不一致 |
| 执行失败 | 当前动作提交失败 |

## 13. Web/App 状态映射建议

| APP 状态 | 对应 Web 侧理解 | 说明 |
| ---- | ---- | ---- |
| 待处理 | 待受理 / 待处理 | APP 可开始处理，Web 侧可能尚在待受理 |
| 处理中 | 处理中 / 备货中 / 出库中 | 根据对象不同映射到 Web 不同节点 |
| 待交接 | 已出库待物流协同 | 主要用于履约和调拨出库场景 |
| 已完成 | 已完成 / 已发运 / 已入库 | 需按业务对象具体映射 |
| 异常 | 异常 / 异常单 | 统一作为跨端风险状态 |

## 14. 当前建议统一替换项

| 当前可能混用表述 | 建议统一为 | 说明 |
| ---- | ---- | ---- |
| 揽货 | 备货 | APP 全端统一术语 |
| 待发货 | 待交接 | 在 APP 端更贴近出库后的实际动作 |
| 已发货 | 已完成或待交接 | APP 不直接复用 Web 履约状态命名 |
| 任务异常 / 异常任务 | 异常 | 任务主状态统一用词 |

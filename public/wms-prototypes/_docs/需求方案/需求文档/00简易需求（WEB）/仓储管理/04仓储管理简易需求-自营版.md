# 仓储管理简易需求（自营版）

## 1. 基本信息

- 功能名称：仓储管理
- 所属系统：WMS_WEB端
- 页面范围：仓库管理、库区管理、货位管理
- 所属模块：仓储管理
- 文档定位：自营业务版
- 适用范围：自营仓库、库区、货位、容量、作业属性、上下架规则和状态管理

## 2. 核心结论

### 2.1 WMS管理对象

| 对象 | 主键/编码 | 管理口径 | 作用 |
| --- | --- | --- | --- |
| 仓库 | 仓库编码 | 自营仓储节点 | 承接采购入库、销售出库、调拨、盘点、退货和库存管理 |
| 库区 | 仓库 + 库区编码 | 仓内功能区域 | 承接暂存、存储、拣货、备货、次品、退货、报损等作业分区 |
| 货位 | 仓库 + 库区 + 货位编码 | 最小存放单位 | 承接上架、拣货、补货、移库、盘点和库位库存 |
| 通道/排列层 | 库区 + 通道/排/列/层 | 库内定位结构 | 支撑货位定位、动线规划和作业路径 |
| 容量规则 | 货位编码 | 货位容量控制 | 控制重量、体积、件数、商品种类数 |
| 上下架规则 | 货位编码 | 作业控制口径 | 控制商品类别、批次混放、临期限制和库位用途 |

### 2.2 核心规则

1. 仓储结构按 `仓库 -> 库区 -> 货位` 三级管理。
2. 仓库作为库存归属和作业组织的实体节点。
3. 库区用于表达仓库内不同作业功能和库存状态承载范围。
4. 货位作为库存落位、拣货、补货、移库和盘点的最小物理位置。
5. 库存台账按SKU、仓库、库区、货位、批次和库存状态落账。
6. 仓库、库区、货位启用后参与业务；停用后保留历史库存、单据和操作记录。
7. 货位容量和上下架规则用于控制上架、移库、补货和拣货校验。
8. 货位使用状态由库存和任务自动驱动，包括空、占用和锁定。

## 3. 业务目标

仓储管理用于维护自营WMS的仓库、库区和货位基础资料，支撑采购入库、销售出库、调拨、盘点、移库、补货、退货、报损和库存查询。

系统通过仓库、库区、货位三级结构，为库存落账、仓内作业、任务分派、库位容量控制、库存追溯和现场管理提供统一空间基础资料。

## 4. 功能范围

- 仓库列表查询与分页
- 新建、编辑、查看、启用、停用仓库
- 库区列表查询与分页
- 新建、编辑、查看、启用、停用库区
- 货位列表查询与分页
- 新建、编辑、查看、启用、停用、删除货位
- 通道、排、列、层结构维护
- 货位容量规则维护
- 货位上下架规则维护
- 货位使用状态查看
- 仓储基础资料导出
- 仓储操作日志查看

## 5. 仓库管理

### 5.1 仓库类型

| 仓库类型 | 说明 | 典型业务 |
| --- | --- | --- |
| 中心仓 | 自营主仓或区域主仓 | 采购入库、批量存储、销售出库、调拨出库 |
| 前置仓 | 靠近履约区域的小型仓 | 快速履约、区域补货、即时配送 |
| 退货仓 | 集中处理退货和质检 | 退货入库、质检、返架、报损 |
| 门店仓 | 自营门店或门店后仓 | 门店库存、门店发货、门店盘点 |

### 5.3 仓库规则

- 仓库编码全局唯一。
- 仓库启用后可被入库、出库、调拨、盘点和库存查询引用。
- 仓库停用后不参与新业务创建，历史库存、历史单据和库存流水保留。
- 停用仓库前校验是否存在进行中的入库、出库、调拨、盘点任务。

| 库区类型 | 说明 | 典型业务 |

| 存储区 | 正常库存长期或中期存放区域 | 上架、存储、补货 |

| 备货区 | 出库前暂存和集货区域 | 复核、打包、交接 |
| 次品区 | 不良品或待处理商品区域 | 质检不良、退货不良 |

| 报损区 | 报损待处理商品区域 | 报损出库 |
| 中转区 | 临时周转区域 | 调拨、越库、暂存 |

### 6.3 库区规则

- 同一仓库下库区名称唯一。
- 库区启用后可被货位、上架、拣货、盘点等业务引用。
- 库区停用后不参与新业务选择，历史库存和历史任务保留。
- 停用库区前校验是否存在进行中的上架、拣货、移库、盘点任务。

### 7.3 货位规则

- 同一库区下货位编码唯一。
- 货位启用后可参与上架、拣货、补货、移库和盘点。
- 货位停用前校验使用状态为空。
- 货位删除前校验无库存、无进行中任务、无锁定状态。
- 容量字段填写后必须为大于0的数字。
- 上架、移库时校验货位容量、品类限制、商品限制、批次混放和临期限制。
- 货位使用状态由库存和任务自动更新。

## 10. 状态规则

### 10.1 管理状态

| 状态 | 含义 | 规则 |
| --- | --- | --- |
| 启用 | 可参与业务 | 可被入库、出库、库存、盘点、调拨等业务引用 |
| 停用 | 停止参与新业务 | 历史库存、单据、任务和日志保留 |

### 10.2 货位使用状态

| 状态 | 含义 | 触发 |
| --- | --- | --- |
| 空 | 当前无库存、无任务 | 库存为0且无未完成任务 |
| 占用 | 当前有库存或任务 | 货位存在库存或未完成上架、拣货、移库、盘点任务 |
| 锁定 | 临时禁止作业 | 盘点、维修、异常处理等场景人工或系统锁定 |

## 11. 异常场景处理

| 异常场景 | 系统处理 |
| --- | --- |
| 仓库编码重复 | 阻断保存并提示重复仓库 |
| 库区编码重复 | 阻断保存并提示重复库区 |
| 货位编码重复 | 阻断保存并提示重复货位 |
| 停用仓库存在进行中任务 | 阻断停用并提示任务数量 |
| 停用库区存在进行中任务 | 阻断停用并提示任务数量 |
| 停用货位使用状态非空 | 阻断停用并提示库存或任务占用 |
| 删除货位存在库存或任务 | 阻断删除并提示占用原因 |
| 上架超出货位容量 | 阻断上架并提示容量限制 |
| 上架不符合货位规则 | 阻断上架并提示规则冲突 |

## 12. 验收要点

- 能维护仓库、库区、货位三级结构。
- 能按仓库类型、仓库状态、仓库编码、仓库名称查询仓库。
- 能按仓库、库区类型、库区状态、库区编码/名称查询库区。
- 能按仓库、库区、货位类型、使用状态、货位编码、SKU编码查询货位。
- 仓库、库区、货位编码唯一性校验正确。
- 仓库类型支持中心仓、前置仓、退货仓、门店仓。
- 库区类型支持收货暂存区、存储区、拣货区、备货区、次品区、退货区、报损区、中转区。
- 货位类型支持收货暂存货位、存储货位、拣货货位、备货货位、次品货位、报损货位。
- 货位容量字段可保存并在上架、移库时校验。
- 货位上下架规则可保存并在上架、移库时校验。
- 货位使用状态可根据库存和任务自动更新为空、占用、锁定。
- 占用或锁定货位停用、删除时能正确阻断并提示原因。
- 仓储基础资料变更能记录操作日志。

# WMS_WEB端第一轮简易版PRD

## 1. 文档说明

本文为 `WMS原型设计` 第一轮简易版 PRD，作为后续页面原型说明和可交互原型的输入基线。

本轮只覆盖以下范围：

- 开放平台
- 主数据
- 入库主链路
- 库存主链路
- 出库主链路

本轮不展开以下范围：

- 物流中心
- 物流协同
- 售后中心
- 调拨中心
- 仓内作业中心
- 异常中心
- 结算中心

状态口径说明：本文中的业务对象状态、执行结果状态、异常状态统一引用 [15WMS_WEB端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/15WMS_WEB端状态口径总表.md)；若本文件局部示例与状态口径总表存在差异，以状态口径总表为准。

## 2. 功能目标

本轮简易版 PRD 的目标是先建立 WMS_WEB 端最核心的后台管理骨架，支撑第三方电商系统接入后的基础运维、主数据承接、入库处理、库存查询和出库管理。

具体目标如下：

1. 建立开放平台基础运维入口，支持回调配置、回调测试和回调日志排查。
2. 建立主数据查询入口，统一承接货主、店铺、仓库、商品、条码、批次规则等基础信息。
3. 建立入库单管理闭环，支撑采购入库、调拨入库、退货入库的受理、查询、改约和详情查看。
4. 建立库存查询闭环，支撑汇总库存、明细库存、批次库存、冻结记录和预警排查。
5. 建立出库单管理闭环，支撑普通出库、调拨出库、其他出库、采购退货出库的统一查询与处理跟踪。

## 7. 核心流程

### 7.1 开放平台运维流程

1. 运维人员进入开放平台概览页查看当前接入状态。
2. 在回调配置页维护回调地址、启停状态和测试配置。
3. 通过回调测试验证联通性和报文投递结果。
4. 当测试失败或线上回调失败时，进入回调日志页查看失败原因和报文。
5. 对失败事件执行人工重推，并记录结果。

### 7.2 主数据承接流程

1. 第三方电商系统通过 OpenAPI 同步或查询货主、店铺、仓库和商品相关基础数据。
2. WMS_WEB 端在授权范围页统一展示货主、店铺、仓库及服务能力关系。
3. 管理人员通过 SKU 资料列表和详情页核对商品、条码、包装规格、批次与效期规则。
4. 当业务涉及组合商品或唯一码时，通过扩展关系页面查看关联关系。

### 7.3 入库主链路

1. 第三方电商系统创建入库单。
2. WMS 受理入库单并进入入库列表可查状态。
3. 管理人员在入库单详情页查看来源单号、预约时间、商品明细和差异信息。
4. 如预约时间需调整，则通过改约入口提交新的预约时间。
5. 入库完成后，库存台账和批次数据同步更新。

### 7.4 库存查询主链路

1. 管理人员从库存汇总列表查看 SKU 维度库存资产。
2. 如需追溯库存分布，则进入库存明细列表查看仓库、货位、批次和库存状态。
3. 如需查看效期和批次风险，则进入批次库存列表。
4. 如需排查冻结或预警风险，则进入冻结记录与预警页查看冻结记录、低库存、临期、过期等信息。

### 7.5 出库主链路

1. 第三方电商系统创建出库单。
2. WMS 受理出库单并在出库列表中展示不同类型单据和处理状态。
3. 管理人员在出库单详情页查看商品行、来源单号、执行进度和异常记录。
4. 出库完成后，库存扣减结果应可在库存中心查询到。
5. 若出库出现异常，则在详情页保留异常记录，供下一轮异常中心承接闭环处理。

## 8. 状态流转

本章节不再定义独立的 Web 端状态体系，统一引用 [15WMS_WEB端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/15WMS_WEB端状态口径总表.md)；以下内容仅用于说明本轮涉及对象的状态使用范围、页面展示位置和理解方式。

### 8.1 回调配置状态

| 对象 | 状态/结果 | 说明 |
| ---- | ---- | ---- |
| 回调配置 | 启用 / 停用 | 控制是否对外投递事件 |
| 回调测试 | 成功 / 失败 | 记录最近一次测试结果 |

| 待改约 | 预约时间待调整或待确认 |
| 已完成 | 入库处理完成 |
| 已取消 | 入库单被取消 |

### 8.3 库存状态

| 对象 | 状态 | 说明 |
| ---- | ---- | ---- |
| 库存 | 实物库存 / 可用库存 / 冻结库存 | 核心库存口径 |
| 批次 | 正常 / 临期 / 过期 | 效期风险口径 |
| 预警 | 正常 / 低库存 / 临期 / 过期 | 风险提示口径 |

### 8.4 出库单状态

| 状态 | 说明 |
| ---- | ---- |
| 待受理 | 已创建，待 WMS 受理 |
| 处理中 | 已进入出库处理过程 |
| 已完成 | 出库完成 |
| 已取消 | 出库单被取消 |
| 异常单 | 存在执行异常，需人工排查 |

## 13. 异常处理

| 场景 | 处理要求 |
| ---- | ---- |
| 回调测试失败 | 展示失败原因、支持再次测试、保留最近结果 |
| 回调投递失败 | 回调日志可查询失败记录并支持人工重推 |
| 主数据查询为空 | 展示空态提示，不自动推断缺失关系 |
| 入库单状态异常 | 详情页显式展示当前状态与处理记录，避免误操作 |
| 入库改约失败 | 返回失败原因，不改变原预约时间 |
| 库存查询无结果 | 保留查询条件并展示空数据页 |
| 批次临期/过期 | 使用风险标签突出展示 |
| 出库单异常 | 在详情页沉淀异常记录，后续对接异常中心闭环处理 |

## 16. 待确认项

| 编号 | 待确认项 | 说明 |

## 17. 测试关注点

| 类别 | 测试点 |
| ---- | ---- |

# 仓库人员管理简易需求（自营版）

## 1. 基本信息

- 功能名称：仓库人员管理
- 所属系统：WMS_WEB端、WMS_APP端
- 页面范围：仓库人员列表、人员档案、账号开通与绑定、作业仓库权限、人员角色权限、APP作业权限、作业组管理
- 所属模块：仓储管理
- 文档定位：自营业务版
- 适用范围：仓库管理人员、仓库作业人员、仓库作业组、作业仓库授权、APP作业授权

## 2. 核心结论

### 2.1 功能定位

仓库人员管理用于维护仓库管理人员和仓库作业人员的业务身份、作业仓库、人员角色、APP作业权限和任务可见范围。

原有用户管理负责统一账号、登录认证、后台菜单和系统级角色；仓库人员管理负责仓库作业身份、仓库范围和仓内作业权限。

### 2.2 管理对象

| 对象 | 管理口径 | 作用 |
| --- | --- | --- |
| 统一账号 | 登录账号 | 支撑后台或APP登录认证 |
| 仓库人员档案 | 人员工号/手机号 | 记录仓库人员基础信息和在职状态 |
| 作业仓库权限 | 人员 + 仓库 | 控制人员可操作的仓库范围 |
| 人员角色权限 | 人员 + 角色 | 控制人员可执行的仓内作业类型 |
| APP作业权限 | 人员 + APP功能 | 控制作业人员在APP端可使用的功能 |
| 作业组 | 仓库 + 作业组 | 支撑人员分组、任务池、手动派单和后续自动派单 |

### 2.3 核心规则

1. 仓库人员必须关联统一账号后才可登录后台或APP。
2. 新增仓库人员时，系统支持直接创建账号；账号已存在时直接绑定已有账号。
3. 同一个统一账号只能绑定一个仓库人员档案。
4. 仓库人员可授权一个或多个作业仓库。
5. 仓库人员只能查看和操作授权仓库范围内的数据与任务。
6. 仓库作业人员在APP端按作业仓库、人员角色和任务可见范围加载功能。
7. 仓库管理人员在后台按授权仓库执行人员管理、任务分配、异常处理和作业监控。
8. 仓库人员离职或停用后，系统停止其仓库作业权限，并保留历史作业记录。

## 3. 业务目标

仓库人员管理用于解决自营WMS中仓库人员身份、账号开通、仓库授权、角色授权和APP作业权限的统一维护问题。

系统通过仓库人员管理，将“能否登录系统”和“能在哪个仓库做什么作业”分开管理，支撑仓库现场多人作业、手动接单、手动派单、作业追踪、异常处理和后续自动派单。

## 4. 与用户管理的关系

| 模块 | 管理重点 | 典型对象 | 说明 |
| --- | --- | --- | --- |
| 用户管理 | 账号、登录、系统角色、后台菜单 | 系统管理员、运营人员、后台用户 | 控制账号是否可登录系统，以及后台可访问的菜单和功能 |
| 仓库人员管理 | 仓库作业身份、作业仓库、人员角色、APP权限 | 仓库管理人员、仓库作业人员 | 控制人员进入仓库业务后可查看哪些仓、接哪些任务、执行哪些作业 |

仓库人员管理使用统一账号体系，不单独维护登录认证。人员新增时可在仓库人员管理中完成账号创建、账号绑定、人员档案创建和仓库作业授权。

## 6. 账号开通与绑定

### 6.1 账号处理方式

| 场景 | 系统处理 | 结果 |
| --- | --- | --- |
| 账号已存在 | 选择已有账号并绑定仓库人员档案 | 使用原账号登录，加载仓库作业权限 |
| 账号不存在 | 在仓库人员管理中创建账号并生成仓库人员档案 | 新账号可登录后台或APP |
| 人员已有档案 | 回显人员档案和已绑定账号 | 支持继续维护仓库权限和角色权限 |

### 6.2 账号识别规则

- 手机号作为账号优先识别字段。
- 工号可作为仓库内部人员识别字段。
- 用户名可作为后台账号登录名。
- 新增人员时按手机号、工号、用户名校验是否已存在账号或人员档案。
- 账号绑定后，仓库人员档案记录账号ID、账号名称、手机号和绑定时间。

### 6.3 账号状态规则

- 账号启用且仓库人员启用时，人员可登录授权端并执行授权作业。
- 账号停用时，人员不可登录后台和APP。
- 仓库人员停用时，人员不可执行仓库作业。
- 人员离职时，系统停止仓库作业权限；账号是否停用按统一用户体系规则处理。

| 仓库作业人员 | 负责仓内现场作业执行 | APP接单、扫码、作业提交、异常上报 |

| 基础信息 | 人员姓名 | 单行输入框 | 是 | 人员真实姓名 |

| 角色信息 | 人员角色 | 多选下拉 | 是 | 仓库主管、仓库作业员、收货员、揽货员、打包复核员、发货员 |

### 7.3 人员规则

- 人员工号全局唯一。
- 登录手机号全局唯一。
- 同一个账号只能绑定一个仓库人员档案。
- 默认仓库必须在所属仓库范围内。
- 人员角色必须匹配已授权仓库支持的作业能力。
- 人员启用后可参与任务接单、派单和作业执行。
- 人员停用后不可接收新任务，不可执行未完成任务。
- 停用人员前校验是否存在进行中的作业任务。

## 8. 作业仓库权限

### 8.1 授权内容

| 权限项 | 说明 |
| --- | --- |
| 可作业仓库 | 控制人员可进入和操作的仓库 |
| 默认仓库 | 控制APP登录后的默认作业仓库 |
| 仓库内人员角色 | 控制人员在不同仓库可执行的作业类型 |
| 仓库内任务范围 | 控制人员在不同仓库可见的任务池 |

### 8.2 授权规则

- 仓库人员至少授权一个启用状态仓库。
- 仓库作业人员APP端只能切换到已授权仓库。
- 仓库管理人员后台只能查看和管理授权仓库范围内的人员、任务和异常。
- 不同仓库可配置不同人员角色。
- 移除仓库授权前校验该人员在该仓库是否存在未完成任务。

## 9. 人员角色权限

### 9.1 角色权限清单

| 人员角色 | 可授权动作 | 使用端 |
| --- | --- | --- |
| 仓库主管 | 人员维护、账号开通与绑定、仓库授权、角色授权、APP权限配置、作业组维护、任务派单、任务改派、异常处理、日志查看 | WMS_WEB端 |
| 仓库作业员 | 查看任务、接单、上架、移库、补货、盘点、异常上报 | WMS_APP端 |
| 收货员 | 查看收货任务、接单、收货、清点、差异上报、移交上架 | WMS_APP端 |
| 揽货员 | 查看揽货任务、揽货接单、扫描揽货、缺货上报、移交打包复核 | WMS_APP端 |
| 打包复核员 | 查看复核/打包任务、扫描复核、合单复核、差异上报、打包、称重、面单处理、包裹确认 | WMS_APP端 |
| 发货员 | 查看发货任务、扫描包裹、物流交接、交接确认 | WMS_APP端 |

### 9.2 角色规则

- 仓库人员可授权一个或多个人员角色。
- 仓库主管为管理类角色，主要使用后台执行人员、权限、任务和异常管理。
- 仓库作业员为通用作业角色，用于承接上架、移库、补货、盘点等通用仓内作业。
- 揽货接单权限独立控制，授权后可从待接单任务池领取任务。
- 打包复核员合并承接复核、合单复核、打包和包裹确认。
- 异常处理、任务派单、任务改派默认由仓库主管承接。

## 10. APP作业权限

### 10.1 APP功能范围

| APP功能 | 权限说明 | 典型用户 |
| --- | --- | --- |
| 我的任务 | 查看分配给自己的作业任务 | 仓库作业人员 |
| 待接单任务池 | 查看本仓可领取的任务 | 仓库作业员、收货员、揽货员、打包复核员、发货员 |
| 扫码作业 | 扫描商品、库位、容器、包裹、物流单号 | 仓库作业人员 |
| 揽货接单 | 手动领取揽货任务 | 揽货员 |
| 收货作业 | 执行收货、清点和差异上报 | 收货员 |
| 上架作业 | 执行扫描货位和确认上架 | 仓库作业员 |
| 揽货作业 | 执行商品揽货、缺货上报和移交打包复核 | 揽货员 |
| 打包复核 | 执行商品复核、合单复核、打包、称重和包裹确认 | 打包复核员 |
| 发货交接 | 执行包裹扫描和物流交接 | 发货员 |
| 盘点作业 | 执行初盘、复盘和盘点异常上报 | 仓库作业员 |
| 异常上报 | 上报数量差异、商品不符、库位不符、破损、无货、条码异常 | 仓库作业人员 |
| 库存查询 | 查询授权仓库范围内的必要库存信息 | 授权人员 |

### 10.2 APP权限规则

- APP登录后根据绑定的仓库人员档案加载作业仓库和APP功能。
- APP首页仅展示人员已授权的作业入口。
- APP任务列表仅展示授权仓库、授权角色和任务可见范围内的任务。
- 普通作业人员可上报异常，异常处理结果由授权管理人员确认。
- APP库存查询展示作业必要信息，不开放库存调整和库存冻结操作。
- APP作业提交记录操作人员、操作时间、作业仓库、任务编号和扫描结果。

## 11. 任务可见范围

| 可见范围 | 说明 | 适用场景 |
| --- | --- | --- |
| 仅本人任务 | 只展示已分配给当前人员的任务 | 管理人员派单或系统自动派单 |
| 本组任务 | 展示当前人员所属作业组的任务 | 作业组协同处理 |
| 本仓可接任务 | 展示授权仓库下可领取的待接单任务 | 手动接单模式 |

### 11.1 接单规则

- 人员只能领取授权仓库范围内的任务。
- 人员只能领取授权角色匹配的任务。
- 人员领取任务后，任务归属更新为当前人员。
- 任务领取后从其他人员的可接任务池中移除。
- 管理人员可对未完成任务进行改派。
- 人员存在未完成任务时，系统可按业务规则限制继续接单数量。

## 12. 作业组管理

### 12.1 作业组类型

| 作业组类型 | 说明 |
| --- | --- |
| 收货组 | 承接入库收货和清点任务 |
| 仓库作业组 | 承接上架、移库、补货、盘点等通用仓内作业 |
| 揽货组 | 承接出库揽货和缺货上报任务 |
| 打包复核组 | 承接复核、合单复核、打包、称重、面单处理和包裹确认任务 |
| 发货组 | 承接发货扫描和物流交接任务 |

### 12.2 作业组字段

| 字段名称 | 字段类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 所属仓库 | 下拉单选 | 是 | 作业组归属仓库 |
| 作业组编码 | 文本/系统生成 | 否 | 新建时系统生成 |
| 作业组名称 | 单行输入框 | 是 | 作业组名称 |
| 作业组类型 | 下拉单选 | 是 | 收货组 / 仓库作业组 / 揽货组 / 打包复核组 / 发货组 |
| 组长 | 下拉单选 | 否 | 选择已授权该仓库的人员 |
| 组员 | 下拉多选 | 否 | 选择已授权该仓库的人员 |
| 状态 | 下拉单选 | 是 | 启用 / 停用 |
| 备注 | 多行输入框 | 否 | 补充说明 |

### 12.3 作业组规则

- 同一仓库下作业组名称唯一。
- 组员必须具备所属仓库权限。
- 组员人员角色应匹配作业组类型。
- 作业组启用后可用于任务可见范围、手动派单和后续自动派单。
- 停用作业组前校验是否存在未完成任务。

## 15. 异常场景处理

| 异常场景 | 系统处理 |
| --- | --- |
| 手机号已存在账号 | 提示选择已有账号并绑定人员档案 |
| 工号已存在 | 阻止保存并提示更换工号 |
| 账号已绑定其他人员 | 阻止重复绑定 |
| 默认仓库未授权 | 阻止保存并提示先授权仓库 |
| 人员角色与仓库能力不匹配 | 阻止保存或提示调整授权 |
| 人员存在未完成任务 | 限制停用、离职或移除仓库权限 |
| APP登录无仓库权限 | 提示暂无可作业仓库 |
| APP登录无作业权限 | 提示暂无可用作业功能 |

## 16. 操作日志

系统记录仓库人员管理相关操作日志，包括：

- 人员新增、编辑、启用、停用、离职
- 账号创建、账号绑定、账号解绑
- 作业仓库授权变更
- 人员角色权限变更
- APP作业权限变更
- 任务可见范围变更
- 作业组新增、编辑、启停
- 人员加入或移出作业组

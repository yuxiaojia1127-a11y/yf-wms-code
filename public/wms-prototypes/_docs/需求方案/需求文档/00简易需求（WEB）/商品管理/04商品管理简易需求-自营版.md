# 商品管理简易需求（自营版）

## 1. 基本信息

- 功能名称：商品管理
- 所属系统：WMS_WEB端
- 页面编号：`WMS-WEB-006`
- 关联页面：`WMS-WEB-007`
- 所属模块：商品管理
- 文档定位：自营业务版
- 适用范围：自营业务商品、SKU、条码、单位、仓储规则、商品同步与异常处理

## 2. 核心结论

### 2.1 WMS管理对象

| 对象 | 主键/编码 | 管理口径 | 作用 |
| --- | --- | --- | --- |
| 商品档案 | 商品编码 / SPU编码 | 自营商品基础资料 | 承接商品名称、品牌、分类、商品类型等基础信息 |
| SKU档案 | SKU编码 | 库存和作业最小单元 | 作为入库、库存、出库、盘点、调拨、履约和对账的业务主数据 |
| WMS商品编码 | 系统生成 | WMS内部商品主键 | 承接单据、接口、库存流水和历史追溯 |
| 条码档案 | 条码 | SKU识别码 | 支持收货、上架、拣货、复核、盘点扫码识别 |
| 单位规则 | 基础单位 + 辅助单位 + 换算比例 | 计量换算口径 | 支持件、箱、瓶、包等单位转换 |
| 仓储规则 | SKU编码 | 仓内作业控制口径 | 控制批次、效期、SN、易碎、危险品、液体等作业规则 |

### 2.2 核心规则

1. WMS以SKU作为库存和作业最小单元。
2. 库存台账按 `SKU + 仓库 + 库区 + 库位 + 批次 + 库存状态` 管理。
3. WMS商品编码由系统生成并长期稳定，用于单据、库存流水、接口流转和历史追溯。
4. 商品档案承接SPU级基础信息，SKU档案承接库存作业级信息。
5. 一个SKU支持维护一个主条码和多个辅助条码。
6. SKU按仓储规则参与收货、上架、拣货、复核、出库、盘点和可售计算。
7. 批次、效期、SN规则按SKU维护，并在仓内作业中强制校验。
8. 商品同步面向上游商品系统、ERP、OMS、电商系统或下游仓储接口，系统记录同步状态和失败原因。

## 3. 业务目标

商品管理用于维护自营业务的商品档案、SKU档案、条码、单位、规格、尺寸重量和仓储规则，为采购入库、销售出库、库存管理、盘点、调拨、退货入库、可售计算和商品同步提供基础资料。

## 4. 功能范围

- 商品列表查询与分页
- 新建商品
- 编辑商品
- 查看商品详情
- 启用/停用商品

- 条码维护

- 商品数据导出

## 5. 关键流程

### 5.1 商品建档流程

1. 商品运营新建商品档案，维护商品名称、品牌、分类、商品类型等基础信息。
2. 商品运营在商品档案下维护SKU，录入SKU编码、SKU名称、规格、基础单位、条码、尺寸、重量和箱规。
3. 系统保存后生成WMS商品编码。
4. 商品运营维护批次、效期、SN、易碎、危险品、液体等仓储规则。
5. 商品启用后参与采购入库、库存、销售出库、盘点、调拨和可售计算。

### 5.2 商品同步流程

1. 上游系统通过接口同步商品资料，或运营在WMS后台手工维护商品资料。
2. 系统按SKU编码、外部商品ID或WMS商品编码进行幂等处理。
3. 系统校验必填字段、条码、单位、仓储规则和状态。
4. 校验通过后保存商品资料并更新同步状态。
5. 同步失败时记录失败原因、失败时间和原始报文摘要。
6. 商品运营或系统管理员修正数据后发起重试同步。

### 5.3 仓内使用流程

1. 入库收货时，系统按SKU、条码和仓储规则校验商品。
2. 上架时，系统按SKU属性和仓储规则推荐或校验库区、库位。
3. 拣货时，系统按SKU、批次、效期、SN规则生成拣货要求。
4. 复核出库时，系统通过条码、SKU、批次和SN校验实物。
5. 盘点时，系统按SKU、库位、批次和库存状态生成盘点任务。

## 8. 规则要求

### 8.1 商品与SKU规则

- 商品编码在自营业务范围内唯一。
- SKU编码在自营业务范围内唯一。
- WMS商品编码保存后生成并长期稳定。
- SKU作为库存、单据、作业和库存流水的最小业务对象。
- 商品停用后保留历史库存、历史单据和库存流水。

### 8.2 条码规则

- 一个SKU支持维护一个主条码和多个辅助条码。
- 条码保存时自动去重。
- 同一个启用SKU的主条码唯一。
- 辅助条码用于收货、拣货、复核、盘点时辅助识别。
- 商品换包装、新旧条码并行等场景可通过辅助条码维护。

### 8.3 单位规则

- SKU必须维护基础单位。
- 库存台账以基础单位记录。
- 辅助单位通过换算比例换算为基础单位。
- 入库、出库、盘点允许展示业务单位，系统落账时统一换算为基础单位。

### 8.4 仓储规则

- 开启效期管理时，保质期天数必填。
- 禁收天数、禁售天数、临期预警天数不得大于保质期天数。
- 开启批次管理时，入库、库存、出库、盘点记录批次。
- 开启效期管理时，入库、库存、出库、盘点记录生产日期或到期日期。
- 开启SN管理时，入库、出库、盘点按序列号逐件校验。
- 易碎、危险品、液体属性用于仓储提示、库区限制、包装要求和运输限制。

### 8.5 同步规则

- 接口同步按外部系统商品ID、外部系统SKU ID或SKU编码进行幂等处理。
- 手工维护商品可发起对外同步。
- 同步成功后记录下游商品ID、同步时间和返回结果。
- 同步失败后记录失败原因、失败时间和报文摘要。
- 修正商品资料后支持重新同步。

## 9. 状态规则

### 9.1 商品状态

| 状态 | 含义 | 规则 |
| --- | --- | --- |
| 启用 | 商品可参与业务 | 可用于入库、库存、出库、可售、调拨、盘点和同步 |
| 停用 | 商品停止参与新业务 | 历史数据保留，历史单据可继续查询 |

### 9.2 同步状态

| 状态 | 含义 | 触发 |
| --- | --- | --- |
| 未同步 | 商品已建立，未发起对外同步 | 新建后初始状态 |
| 同步中 | 已发起同步请求，等待返回结果 | 点击同步或系统自动同步 |
| 同步成功 | 下游接收成功 | 返回成功并记录下游商品ID |
| 同步失败 | 下游接收失败 | 返回失败码、失败信息或接口超时 |

## 10. 异常场景处理

| 异常场景 | 系统处理 |
| --- | --- |
| 商品编码重复 | 阻断保存并提示重复商品 |
| SKU编码重复 | 阻断保存并提示重复SKU |
| 主条码重复 | 阻断保存并提示冲突SKU |
| 效期规则缺少必填字段 | 阻断保存并提示补全仓储规则 |
| 单位换算比例缺失 | 阻断保存并提示补全单位规则 |
| 同步失败 | 记录失败原因并支持重试 |
| 商品已被历史单据引用 | 保留历史引用关系，记录变更日志 |

## 11. 验收要点

- 能按商品状态、同步状态、商品类型、商品分类、SKU编码、WMS商品编码、商品编码、商品名称、条码完成查询。
- 能新建、查看、编辑、启用、停用商品。
- 能维护商品档案、SKU档案、条码、基础单位、规格、尺寸、重量和箱规。
- 能维护批次、效期、SN、易碎、危险品、液体等仓储规则。
- 保存商品后自动生成WMS商品编码。
- 能校验商品编码唯一、SKU编码唯一、主条码唯一。
- 条码支持主条码和辅助条码维护。
- 开启效期管理时能正确校验保质期、禁收、禁售和临期预警字段。
- 商品同步后能展示同步状态、最近同步时间和失败原因。
- 商品变更后能记录操作日志并保留历史单据追溯。

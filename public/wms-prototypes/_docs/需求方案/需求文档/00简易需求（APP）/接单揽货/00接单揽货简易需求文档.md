# 仓库APP-接单揽货简易需求文档

> 版本范围说明：本文档仅覆盖「查看揽货任务指令、接单」两个环节；接单后的揽货作业（拣货、扫码、核销等）另行输出独立需求文档。

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 接单揽货 |
| 所属模块 | 仓库APP > 揽货 |
| 页面定位 | 仓库揽货人员查看 WMS 下发的揽货任务指令并完成接单的作业入口页 |
| 页面编码 | `WMS-APP-001` |
| 适用端 | 仓库APP（揽货配送端） |
| 适用角色 | 仓库揽货人员 |

## 2. 业务说明

电商系统完成支付后，WMS 系统根据销售渠道绑定的库房进行 SKU 履约匹配并下达揽货任务指令。库房分为**即采即销仓库**和**前置仓**两种类型。

订单可能因履约库房有多个而拆分成多张揽货指令。当履约库房包含即采即销仓库时，需等待即采即销仓完成整单揽货后，前置仓才继续开始接单揽货，避免即采即销仓因库存不足发生退换货而导致消费者取消订单、造成整单退款。

WMS 下达揽货任务指令后，仓库揽货人员在 APP【接单揽货】页的【待接单】列表查看任务，点击【接单】完成接单；接单后的任务进入【我的任务】列表，等待后续揽货作业。

## 3. 功能描述

- 支持在仓库APP进入「接单揽货」页面，查看本人所属库房的揽货任务指令。
- 支持按订单号 / 联系人搜索任务。
- 支持「待接单」「我的任务」两个页签切换。
- 支持按配送类型筛选：全部 / 即时配送 / 物流发货。
- 支持按时间排序（升序 / 倒序切换）。
- 支持点击任务卡片区域或「揽货详情」按钮查看揽货详情。
- 支持在任务列表卡片点击「接单」完成接单。
- 支持在揽货详情页底部点击「确认接单」完成接单。
- 接单成功后任务从「待接单」列表移入「我的任务」列表，状态变为「已接单」，操作按钮变为「去揽货」（去揽货后续流程不在本文档范围）。

## 4. 页面结构

### 4.1 接单揽货列表页

| 区域 | 内容说明 |

## 5. 任务状态与流转

| 状态名称 | 触发条件 | 页面表现 |
| ---- | ---- | ---- |
| 待接单 | WMS 下达揽货任务指令且满足下发条件 | 展示在「待接单」列表，操作：揽货详情 + 接单 |
| 已接单 | 揽货人员点击「接单 / 确认接单」成功 | 移入「我的任务」列表，操作：揽货详情 + 去揽货 |

状态流转：`WMS下达指令` → `待接单` → （接单） → `已接单` → 后续揽货作业（不在本文档范围）。

## 6. 关键业务规则

1. **任务下发与库房匹配**：WMS 按销售渠道绑定库房做 SKU 履约匹配后下达揽货任务；揽货人员仅可见本人所属库房的任务。
2. **订单拆单**：一张订单可因履约库房多个拆分为多张揽货指令，每张指令独立接单；详情页以「揽货#N ｜ 第N/共N张揽货单」标识。
3. **即采即销仓优先**：履约库房包含即采即销仓库时，前置仓的揽货任务**暂不下发/不可接单**，须等待即采即销仓完成整单揽货后，前置仓任务方进入「待接单」列表。目的：避免即采即销仓缺货退换导致消费者取消订单、整单退款。
4. **接单互斥**：同一任务仅可被一名揽货人员接单；接单成功后其他人员列表中该任务移除。若任务已被他人接单，点击「接单」提示「任务已被接单」并刷新列表。
5. **两个接单入口等效**：列表卡片「接单」与详情页「确认接单」效果一致，接单成功均回到列表并切换至「我的任务」或给予成功提示。
6. **缺货处理与备注前置展示**：详情页强提示「商品缺货时」处理方式与「订单备注」，供揽货人员接单前判断。

## 7. 交互说明

- 搜索：输入订单号或联系人关键字，点击「搜索」按钮发起查询；支持模糊匹配。
- 筛选：配送类型标签单选，默认「全部」，切换后即时刷新列表。
- 排序：默认按下单时间倒序；点击「时间」可切换升序 / 倒序。
- 接单确认：点击「接单 / 确认接单」后建议二次确认弹窗（确认后执行接单），接单成功 toast 提示。
- 复制：详情页任务ID、订单号支持一键复制。
- 拨号：点击电话图标唤起系统拨号。
- 收货详情：默认收起，点击「收货详情」展开完整地址、楼层/门牌号、Wechat、WhatsApp。

## 8. 异常与空态

| 场景 | 页面表现 |
| ---- | ---- |
| 列表无任务 | 展示空态插图与文案「暂无揽货任务」 |
| 搜索无结果 | 保留搜索条件，展示空态文案 |
| 任务已被他人接单 | toast 提示「任务已被接单」，并刷新列表 |
| 网络异常 | 提示加载失败，支持重试 |
| 任务被 WMS 取消（如订单取消） | 任务从列表移除；若停留在详情页操作接单，提示「任务已取消」并返回列表 |

- 配送 / 物流发货环节。
- WMS 后台揽货任务指令的生成与拆单规则配置页面。

# WMS_APP端页面清单

## 1. 页面优先级说明

| 优先级 | 定义 |
| ---- | ---- |
| P0 | 第一批必须进入原型，覆盖登录、任务中心、收货、备货、复核、出库主链路 |
| P1 | 第二批进入原型，补齐物流交接、上架、调拨、异常处理 |
| P2 | 第三批进入原型，补齐退货质检、消息与个人中心 |
| P3 | 后续增强能力，补齐加工、库内转移等低频任务 |

## 4. 页面状态要求

每个任务型页面至少覆盖以下状态：

| 状态 | 说明 |
| ---- | ---- |
| 默认 | 展示当前货主/仓库上下文内任务 |
| 加载中 | 数据请求中，支持骨架屏 |
| 空数据 | 当前筛选下无任务 |
| 无权限 | 角色无菜单或无仓库权限 |
| 网络异常 | 仅支持在线重试，不支持离线缓存 |
| 操作成功 | 接单、收货、核销、复核、出库、交接成功 |
| 操作失败 | 状态冲突、扫码不匹配、任务失效、接口失败 |

# WMS功能清单

> 说明：
>
> - 本清单依据 `WMS-API接口清单.md` 重新整理，仅保留 WMS 自身系统范围。
> - 第三方电商系统自身功能、页面和运营需求不纳入本清单。
> - 功能按 `WMS_WEB端`、`WMS_WEB_物流系统`、`WMS_APP端`、`WMS_APP_物流系统` 四部分归类，物流需求在需求文档侧保持独立拆分，原型阶段再按端内模块合并呈现。
> - 状态说明：`调整` 表示基于原有梳理重新归类或重构，`新增` 表示本轮新增能力，`规划` 表示在 API 清单中已体现但建议放在后续阶段建设。
> - `已稳定页面口径` 仅记录已经在页面清单、页面原型说明和简易版 PRD 中完成收口的页面；仅有页面占位但尚未进入主 PRD 回写范围的，统一标记为 `待后续补充`。

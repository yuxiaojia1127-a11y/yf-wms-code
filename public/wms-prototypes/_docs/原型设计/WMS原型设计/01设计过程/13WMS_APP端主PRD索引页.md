## 1. 文档说明

本文用于汇总 `WMS_APP端` 已拆分完成的三轮简易版 PRD，作为 APP 端需求查阅、原型回写、评审对齐和后续迭代补充的总入口。

本文不替代各轮简易版 PRD 的详细内容，主要负责：

- 说明 APP 端主范围与边界
- 汇总三轮简易版 PRD 的覆盖模块
- 串联页面范围、轮次优先级和依赖关系
- 提供建议阅读顺序和后续回写入口
- 将状态口径统一挂接到 `16WMS_APP端状态口径总表.md`

状态引用说明：

- 如索引页、简易版 PRD、页面原型说明中的局部状态示例与状态口径总表存在差异，以状态口径总表为准。

## 2. APP端定位

`WMS_APP端` 是仓内一线执行端，面向仓内作业员、仓内主管和仓库管理员，承担任务接单、收货、上架、备货、扫码核销、复核、物流交接、调拨执行、退货质检、仓内作业和现场异常提报。

系统边界如下：

- 承接 WMS 后台下发的任务和状态流转，不承接第三方电商系统侧页面能力。
- 强调“现场执行”和“即时回传”，不在 APP 端承接后台管理、异常工单闭环或复杂配置。
- `WMS_APP_物流系统` 在需求文档侧独立拆分，但在原型和 APP 端简易版 PRD 中并入 `WMS_APP端` 的 `物流协同` 模块体现。

## 8. 依赖关系总览

| APP模块 | 主要依赖 | 说明 |
| ---- | ---- | ---- |
| 通用基础能力 | 账号权限、仓库授权 | 决定用户可见任务范围和可操作仓库 |
| 工作台与任务中心 | Web 端任务生成与状态回流 | APP 端任务展示依赖后台任务分发 |
| 入库作业 | 入库中心、库存中心 | 收货和上架结果回流后台并影响库存 |
| 出库作业 | 出库中心、物流中心 | 备货、复核和出库确认影响履约状态 |
| 物流协同 | WMS_APP_物流系统、Web 端物流协同 | 交接和运单状态需与后台统一 |
| 调拨作业 | 调拨中心、入库中心、出库中心、库存中心 | 调拨结果影响两端库存和后台跟踪 |
| 售后作业 | 售后中心、库存中心 | 退货质检结果影响回库或报损 |
| 仓内作业 | 仓内作业中心、库存中心 | 加工和转移结果需同步后台和库存位置 |
| 异常扩展 | 异常中心、各业务模块 | 现场异常只负责提报，闭环由后台承接 |

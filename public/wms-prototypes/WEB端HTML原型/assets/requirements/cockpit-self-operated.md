# 驾驶舱简易需求-自营版

## 1. 基本信息

- 功能名称：驾驶舱111222
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-036`
- 所属模块：驾驶舱
- 当前口径来源：当前 `public/prototype/web/index.html` 原型实现
- 文档定位：根据当前高保真原型回写的简易需求文档，用于原型、前端、接口和测试统一口径

## 2. 业务目标

面向自营仓储管理角色提供一屏总览能力，集中展示库存风险、仓内作业、履约链路、异常待办和关键指标，帮助仓内管理者在当前屏快速识别风险与堵点，并进入对应业务页面继续处理。

当前页面默认需要快速回答以下 4 个问题：

1. 当前库存是否存在必须优先处理的风险。
2. 仓内作业当前卡在哪个节点。
3. 履约链路当前卡在哪个节点。
4. 哪些超时 / 紧急待办需要立刻处理。

## 3. 角色权限

| 角色类型 | 角色           | 操作权限       | 数据权限             | 说明                  |
| ---- | ------------ | ---------- | ---------------- | ------------------- |
| 管理角色 | 系统管理员 / 系统运营 | 查询、查看、下钻查看 | 可查看全量授权范围内的驾驶舱数据 | 用于全局业务健康与异常监控       |
| 管理角色 | 仓内管理员        | 查询、查看、下钻查看 | 可查看所属权限仓库范围内的数据  | 当前页面核心使用角色          |
| 管理角色 | 仓内主管         | 查询、查看、下钻查看 | 可查看所属仓库或班次范围内的数据 | 重点关注当日作业进度和超时待办     |
| 作业角色 | 仓内作业员        | 无页面权限      | 不开放 Web 驾驶舱      | 继续在 APP / 作业端处理具体任务 |

## 6. 核心指标卡需求

### 6.1 展示要求

- 顶部固定展示 5 项总览型核心指标，不支持用户自定义排序。
- 每张指标卡展示：指标名称、指标值、指标说明、状态标签。
- 指标卡支持点击下钻，进入对应业务页面。
- 顶部指标卡只展示结果型指标，不与作业漏斗节点重复。
- 当前原型指标说明口径已收敛为更短文案，避免首屏信息过载。

### 6.2 指标明细

| 指标名称  | 统计口径                                          | 当前说明文案要求                                | 状态标签示例            | 下钻页面       |
| ----- | --------------------------------------------- | --------------------------------------- | ----------------- | ---------- |
| 可用库存  | 当前筛选范围内 available 库存总量汇总                      | 展示简短库存补充说明，如冻结库存或库存充足说明                 | 较昨日 +3.8% / 稳定    | 库存查询       |
| 履约及时率 | SLA 内完成履约单数 / 应完成履约单数                         | 展示分子 / 分母明细，如 `428 / 452`               | 较昨日 +1.2% / 略低于目标 | 履约链路跟踪明细列表 |
| 库存预警  | 当前筛选范围内未关闭库存预警总数，低于安全库存值、高预警库存值的则预警           | 当前驾驶舱统一展示为低库存 SKU 数，如 `低库存SKU12`        | 5条高预警 / 以低库存为主    | 库存风险列表     |
| 锁定占比  | `locked / physical，锁定占比值高于60%的为高锁定，高于80%严重锁定` | 当前驾驶舱统一展示为高锁定 SKU 数，如 `高锁定SKU 4 个`      | 1条高预警 / 需关注 / 正常  | 库存风险列表     |
| 异常待处理 | 当前筛选范围内未关闭异常数量                                | 展示履约 / 入库 / 出库拆分，如 `履约 3 · 入库 2 · 出库 2` | `2条已等待超60分钟`      | 超时/紧急列表    |

### 6.3 指标状态规则

| 指标    | 正常          | 预警                | 严重                |
| ----- | ----------- | ----------------- | ----------------- |
| 可用库存  | 库存满足当前作业需求  | 关键 SKU 可用库存逼近安全阈值 | 关键 SKU 已影响履约或作业执行 |
| 履约及时率 | 达到目标值       | 低于目标值但未严重偏离       | 明显低于目标值           |
| 库存预警  | 无高风险预警或数量较低 | 存在需关注的低库存 SKU     | 高预警数量较多，需优先处理     |
| 锁定占比  | 占比处于安全范围    | 高于关注阈值            | 高于严重阈值并影响可用库存     |
| 异常待处理 | 无超时异常       | 存在已等待超 30 分钟异常    | 存在已等待超 60 分钟异常    |

#### 9.3.4 进度条规则

- 当前原型不再使用单一健康度条，改为三段式进度条。
- 红色：当前节点超时处理单量。
- 黄色：当前节点待处理单量。
- 灰色：当前分组待处理总量底座。
- 履约链路中仅 `待接单`、`重新派单`、`已取货`、`配送中` 计入待处理总量。
- `当日已送达` 不计入待处理总量，改为单独绿色进度条展示。
- 问号提示浮层需明确上述口径，不再在模块底部单独占用说明区域。

### 9.4 库存风险 Top

该模块为完整需求模块，不是单一字段。

| 字段名称   | 字段类型 | 必填 | 说明                           |
| ------ | ---- | -- | ---------------------------- |
| 风险对象   | 文本   | 是  | 展示商品名称、SKU 或规格               |
| 风险标签   | 标签   | 是  | 当前驾驶舱使用 `低库存`、`高锁定占比` 两类主要标签 |
| 辅助说明   | 文本   | 是  | 展示库存、可售、锁定、仓库、阈值说明           |
| 查看库存预警 | 按钮   | 是  | 进入库存风险列表                     |
| 分页区    | 分页组件 | 是  | 默认展示 10 条，支持翻页               |

排序与展示规则：

- 默认按风险优先级和影响程度降序展示。
- 高风险低库存优先于一般风险。
- 高锁定占比按锁定影响程度排序。
- 当前 1.0 口径不展示临期、冻结、复核差异等旧版口径。
- 点击单条风险对象，跳转库存查询或库存明细并带入上下文。

该模块为完整需求模块，不是单一字段。

| 字段名称   | 字段类型 | 必填 | 说明                      |
| ------ | ---- | -- | ----------------------- |
| 待办单号   | 文本   | 是  | 展示待处理单据编号               |
| 待办类型   | 标签   | 是  | 如入库待收货、履约待拣货、待发运、库存异常   |
| 辅助说明   | 文本   | 是  | 展示仓库、渠道、等待时长；入库待收货不展示渠道 |
| 处理人    | 文本   | 否  | 展示当前处理人                 |
| 查看超时列表 | 按钮   | 是  | 进入超时/紧急列表               |
| 分页区    | 分页组件 | 是  | 默认展示 10 条，支持翻页          |

排序与展示规则：

- 先过滤 `待复核`、`异常待关闭`、`工单待关闭` 三类待办，不在驾驶舱中展示。
- 剩余待办按等待时长倒序排序。
- 等待时长大于 60 分钟的卡片使用红色预警样式。
- 超过30分钟但未超过 60 分钟的卡片保留普通 / 黄色状态，不全部标红。
- 点击待办单号进入对应业务列表页或详情页。

## 10. 关键规则

- 驾驶舱默认展示当前权限范围内的数据，不得越权展示其他仓库数据。
- 页面为纯查看页，不提供新建、编辑、删除能力。
- 顶部核心指标卡只展示总览型结果指标，不展示与作业漏斗重复的流程节点指标。
- 作业漏斗按 `仓内作业跟踪` 与 `履约链路跟踪` 两个分组展示。
- 仓内作业跟踪与履约链路跟踪均支持点击节点进入各自明细列表。
- 作业漏斗卡片、库存风险卡片、待办卡片当前统一压缩为约 `100px` 高度，优先保证首屏信息密度。
- 作业漏斗进度条统一按当前三段口径展示，不表示流程完成率。
- `当日已送达` 单独使用绿色进度条展示，不计入履约待处理总量。
- 库存风险 Top 和超时 / 紧急待办是完整模块需求，包含列表、分页、排序、下钻和空态规则。
- 超时 / 紧急待办中超过 60 分钟的记录需红色预警。
- 简易需求文档通过生产可访问的静态 md 资源读取，不依赖本地 docs 路径。

## 11. 状态规则

| ---- | -------------- | ---------------------- |

## 13. 验收要点

- 能正常进入驾驶舱页面并看到 5 项核心指标卡、作业漏斗、库存风险 Top、超时 / 紧急待办 4 个核心区块。
- 顶部 5 个指标卡均展示名称、指标值、说明文案、状态标签，并支持点击下钻。
- 作业漏斗模块标题为 `作业漏斗`，右上角存在 `仓内作业跟踪`、`履约链路跟踪` 两个跳转按钮。
- 作业漏斗内部需展示两个文字分组标题：`仓内作业跟踪`、`履约链路跟踪`。
- 仓内作业跟踪展示 5 个节点：待入库、待接单揽货、待揽货、待打包复核、待发货。
- 履约链路跟踪展示 5 个节点：待接单、重新派单、已取货、配送中、当日已送达。
- 作业漏斗除 `当日已送达` 外，其余节点进度条均按红 / 黄 / 灰三段展示。
- `当日已送达` 使用绿色进度条，文案展示 `N单配送异常`。
- 库存风险 Top 不再出现临期、冻结、复核差异等当前版本不做的口径。
- 超时 / 紧急待办按等待时长倒序展示，并过滤 `待复核`、`异常待关闭`、`工单待关闭`。
- 超过 60 分钟的待办卡片使用红色预警样式，未超过 60 分钟保留普通 / 黄色状态。
- 点击 `简易需求文档` 后，原型内能直接读取并展示生产可访问的 md 文档内容。

# 商品接口上下架简易需求

## 1. 基本信息

| 属性     | 内容                   |
| ------ | -------------------- |
| 功能名称   | 商品接口上下架              |
| 所属系统   | WMS\_WEB端            |
| 所属模块   | 商品管理                 |
| 关联模块   | 入库管理 / 出库管理 / 库存中心  |
| 文档版本   | v1.0                 |
| 文档日期   | 2026-06-09           |

---

## 2. 背景与目标

WMS 系统需在可售库存发生关键变化时，自动调用电商系统的商品上下架状态接口，保证线上门店商品的销售状态与实际库存同步，避免超卖或虚假下架。

**核心规则：**

- 可售库存 = 0 时 → 自动调用接口，将商品状态置为**已下架**
- 可售库存由 0 变为 > 0 时（入库类事件触发）→ 自动调用接口，将商品状态置为**已上架**

---

## 3. 触发场景

| 触发场景 | 库存变化方向     | 上下架动作 |
| ---- | ---------- | ----- |
| 采购入库 | 可售库存 0 → N | 上架    |
| 退货入库 | 可售库存 0 → N | 上架    |
| 调拨入库 | 可售库存 0 → N | 上架    |
| 其他入库 | 可售库存 0 → N | 上架    |
| 销售出库 | 可售库存 N → 0 | 下架    |
| 调拨出库 | 可售库存 N → 0 | 下架    |
| 报损出库 | 可售库存 N → 0 | 下架    |
| 其他出库 | 可售库存 N → 0 | 下架    |

> 注：仅在可售库存**跨越 0 值临界点**时触发接口调用，非每次库存变动都调用。

---

## 4. 接口调用逻辑

```
库存变动事件发生
  ↓
计算该 SKU 最新可售库存
  ↓
可售库存 == 0？
  ├── 是 → 调用电商接口：下架（SKU）
  └── 否 → 上次可售库存是否为 0？
              ├── 是 → 调用电商接口：上架（SKU）
              └── 否 → 不触发接口（无需变更状态）
  ↓
记录接口调用日志（无论成功/失败）
```

---

## 5. 日志查询功能

### 5.1 功能定位

提供**商品接口上下架日志**查询页面，供运营/仓管人员追溯每一次接口调用的来源、结果及SKU上下架明细。

### 5.2 统计概览

页面顶部展示 4 张指标卡，数值均基于**当前查询结果**实时统计：

| 指标卡   | 说明                                  |
| ----- | ----------------------------------- |
| 触发次数  | 当前查询结果共触发接口调用的总条数                   |
| 成功次数  | 当前查询结果中接口调用成功的条数                    |
| 失败次数  | 当前查询结果中接口调用失败的条数                    |
| 失败待关注 | 与失败次数一致，数字红色标注；点击可快速带入「调用结果=失败」条件查询 |

### 5.3 查询条件

| 字段名称  | 字段类型      | 说明                                                           |
| ----- | --------- | ------------------------------------------------------------ |
| 所属分类  | 三级级联下拉    | 支持关键词搜索，最多三级分类，逐级展开；可选任意层级                                   |
| SKU编码 | 输入框       | 模糊搜索                                                         |
| 上下架动作 | 下拉单选      | 全部 / 上架 / 下架                                                 |
| 触发事件  | 下拉单选      | 全部 / 采购入库 / 退货入库 / 调拨入库 / 其他入库 / 销售出库 / 调拨出库 / 报损出库 / 其他出库 |
| 调用结果  | 下拉单选      | 全部 / 成功 / 失败                                                 |
| 关联渠道  | 多选下拉 + 搜索 | 支持关键词模糊搜索，可多选；当前渠道：吉隆坡门店 / 槟城门店                              |
| 触发时间  | 日期范围选择    | 默认近7天                                                        |

### 5.4 列表字段

| 列名      | 说明                                           |
| ------- | -------------------------------------------- |
| 触发时间    | 接口调用触发的时间，精确到秒，默认倒序排列                        |
| 商品信息    | 商品名称（加粗）+ SKU编码（等宽字体，次行展示）合并为一列              |
| 条码      | 商品条形码                                        |
| 所属分类    | 多级路径展示，最多三级（如：日化 > 洗护 > 洗衣液）                |
| 上下架动作   | 标签：上架=绿色 / 下架=橙色                             |
| 触发事件    | 采购入库 / 退货入库 / 调拨入库 / 其他入库 / 销售出库 / 调拨出库 / 报损出库 / 其他出库 |
| 关联渠道    | 触发上下架的目标门店（吉隆坡门店 / 槟城门店）                     |
| 触发时可售库存 | 接口调用触发时的可售库存快照（跨越 0 值临界点时的库存数量）              |
| 调用结果    | 标签：成功=绿色 / 失败=红色；失败行整行浅红背景高亮                 |
| 失败原因    | 常驻展示：成功时显示 --，失败时展示错误信息；超长截断，hover 显示完整内容    |
| 操作      | 【查看详情】                                       |

点击【查看详情】居中弹出，背景半透明遮罩，宽度 680px，超长内容弹窗内部滚动。

**基本信息区**（两列布局，共 11 个字段）：

| 字段      | 说明                          |
| ------- | --------------------------- |
| 商品名称    |                             |
| SKU编码   |                             |
| 条码      | 商品条形码                       |
| 所属分类    | 多级路径（如：日化 > 洗护 > 洗衣液）       |
| 上下架动作   | 标签展示                        |
| 触发事件    |                             |
| 关联渠道    | 触发上下架的目标门店                  |
| 触发时可售库存 | 触发时的库存快照                    |
| 调用结果    | 标签展示                        |
| 触发时间    |                             |
| 失败原因    | 常驻展示：成功时显示 --，失败时红色加粗显示错误信息 |

**报文区（Tab 切换）：**

- 请求报文：请求时间、请求地址、请求参数（JSON，支持复制）
- 响应报文：响应状态码、响应耗时、响应内容（JSON，支持复制）、重试次数（失败时展示）

## 6. 异常处理

| 场景           | 处理策略                            |
| ------------ | ------------------------------- |
| 接口调用失败       | 记录失败日志，触发重试（建议最多重试3次，间隔递增）      |
| 重试仍失败        | 日志标记为最终失败，触发告警通知（钉钉/邮件，具体方式待定） |
| 短时间内同一SKU频繁触发 | 合并同向操作，避免重复调用（如1分钟内多次归零仅调用1次下架） |
| 电商系统无此SKU    | 忽略该次调用，日志记录"SKU不存在于电商系统"         |

## 8. 非功能需求

- 接口调用超时时间：建议 ≤ 5秒，超时视为失败进入重试
- 日志保留周期：≥ 180天
- 日志支持导出（Excel）

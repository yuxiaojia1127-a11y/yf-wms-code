# WMS WEB 模板生成器（基于“我的商品”）

## 何时调用

- 需要新增/改造任意 WMS WEB 原型页面，使其与“我的商品”一致的框架与视觉语言（含侧边栏、顶栏、查询区、列表区、抽屉等）
- 需要把多个页面统一成同一套响应式断点与布局策略（桌面优先：1360 / 920 / 720）
- 需要复用页面内交互模板：右侧抽屉（需求文档/详情）、数据总览区域（可收起/展开）

## 产物范围

- 仅生成/改造 docs 下的原型 HTML 页面（非真实工程组件）。

## 基准模板

- 以该文件作为“主模板”进行复制与按需裁剪（样式、布局、交互保持一致，内容按新页面替换）：
  - docs/原型设计/WMS原型设计/00原型方案/02WEB端HTML版/01WMS_WEB端原型框架预览-A1我的商品微调.html

## 输入信息（你需要向用户确认）

- 页面名称（标题 + 面包屑 + 左侧菜单激活项）
- 查询区字段清单（字段类型：input/select/date/range/…；是否占 2 列 keyword）
- 统计区是否保留；统计卡数量（默认 4）；默认是否收起
- 工具栏按钮（左侧主动作 + 右侧搜索/图标）
- 表格列定义（列名、是否需要左/右 sticky、操作列按钮组）
- 是否需要右侧抽屉（需求文档/详情/编辑等），抽屉触发入口在哪里

## 输出规则（必须遵守）

- 保持整体结构：`.shell`（sidebar + main）→ `.header` → `.workspace` → `.main-surface` → `.filter-wrap`/`.list-panel`
- 复用 `:root` 变量体系与现有类名；除非必要，不引入新的全局变量命名风格
- 自适应断点保持与模板一致：
  - `max-width: 1360px`：查询区改 3 列、统计卡 2 列
  - `max-width: 920px`：sidebar 变为上方块；header 变为 1 列；workspace padding 收紧
  - `max-width: 720px`：统计卡 1 列；查询区 1 列；工具栏搜索框满宽
- 表格策略：
  - 默认允许横向滚动（`.table-scroll { overflow:auto }`）
  - 如需要 sticky 列，保持 `col-sticky-left` / `col-sticky-right` 的写法
  - 操作列按钮对齐方式按需求设置（左/右），并保持一致
- 交互策略（原生 JS）：
  - 抽屉：使用 `docDrawer`/`docTrigger`/`docClose` 模式，支持遮罩点击关闭
  - 数据总览：使用“中间区域胶囊按钮（数据总览 + 小箭头）”控制 `statsCollapse` 高度动画；默认收起
- 禁止输出占位图片；如必须展示图片，仅使用项目约定的 text_to_image 接口（通常原型页不需要）

## 生成步骤（执行清单）

1. 复制主模板为新页面文件（建议按命名规则：`01WMS_WEB端原型框架预览-<版本>-<页面名>.html`）
2. 替换以下内容：
   - `<title>`、页面主标题、面包屑、左侧菜单激活项
   - 查询区字段（保持网格/按钮区风格一致）
   - 工具栏按钮组与右侧搜索/图标
   - 表格列与行示例数据（保持样式组件一致，如状态 pill）
3. 如页面无需统计区：
   - 移除 stats 区域，同时保留查询区与列表区的间距一致（不要留下空白块）
4. 如页面需要不同数量统计卡：
   - 保持 `.stats-grid`，根据数量调整 `grid-template-columns` 或在断点处覆盖
5. 校验响应式（至少验证 3 档）：
   - 1360：查询区 3 列、统计卡 2 列
   - 920：sidebar/header/workspace 自适应
   - 720：查询/统计/工具栏不溢出

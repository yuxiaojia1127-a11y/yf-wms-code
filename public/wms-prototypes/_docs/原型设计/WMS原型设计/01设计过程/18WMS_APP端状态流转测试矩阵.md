## 2. 使用原则

| 原则 | 说明 |
| ---- | ---- |
| 先看任务主状态 | 先验证任务能否正确进入待处理、处理中、待交接、已完成、异常等主状态 |
| 再看执行节点状态 | 接单、收货、备货、复核、交接、质检等节点单独验证 |
| 页面和结果同时校验 | 同时检查列表标签、详情头部、步骤区、提交结果是否一致 |
| 跨端映射必须校验 | APP 的执行结果需能正确映射到 Web 后台状态和结果对象 |
| 终态禁止重复提交 | 已完成、已取消、异常终态需校验按钮收敛和重复提交拦截 |

## 3. 页面通用状态测试矩阵

| 场景 | 前置条件 | 触发动作 | 预期状态流转 | 预期页面表现 | 关键校验点 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 默认加载 | 用户有任务权限，接口正常 | 进入页面 | 进入默认页面状态 | 展示当前上下文任务和入口 | 不应误展示空态和失败态 |
| 加载中 | 接口请求未完成 | 打开页面或切换页签 | 默认 -> 加载中 -> 默认 | 展示骨架屏或加载提示 | 加载结束后状态恢复正常 |
| 空数据 | 当前筛选无任务 | 查询列表 | 默认 -> 空数据 | 展示空态和返回筛选入口 | 不应残留旧任务卡 |
| 无权限 | 当前角色无页面权限 | 进入页面 | 默认 -> 无权限 | 展示权限说明，不展示业务数据 | 按钮全部禁用或隐藏 |
| 网络异常 | 请求失败 | 刷新或提交 | 默认 -> 网络异常 | 展示重试入口 | 不应丢失已录入内容 |
| 操作成功 | 前置校验通过 | 执行接单、提交、交接等动作 | 操作反馈 -> 操作成功 | 消息提示成功，状态刷新 | 页面跳转和按钮变化正确 |
| 操作失败 | 状态冲突或校验失败 | 提交操作 | 操作反馈 -> 操作失败 | 展示失败原因并保留现场上下文 | 失败不应写入成功状态 |

## 13. Web/App 映射校验矩阵

| APP 状态 | 预期 Web 侧映射 | 典型场景 | 关键校验点 |
| ---- | ---- | ---- | ---- |
| 待处理 | 待受理 / 待处理 | 入库、出库、调拨任务刚进入 APP | Web 不应误显示已处理中 |
| 处理中 | 处理中 / 备货中 / 出库中 | 备货、收货、调拨执行中 | 映射对象要与业务类型一致 |
| 待交接 | 已出库待物流协同 | 出库完成待交接 | Web 端应出现物流协同入口 |
| 已完成 | 已完成 / 已发运 / 已入库 | 不同业务链路完成 | 需按对象正确映射 |
| 异常 | 异常 / 异常单 | 执行失败、差异、交接异常 | Web 端应可查询异常记录 |

## 14. 关键异常拦截测试

| 场景 | 异常条件 | 预期结果 | 关键校验点 |
| ---- | ---- | ---- | ---- |
| 已完成任务重复提交 | 终态任务再次点击提交 | 阻断操作并提示 | 不应重复写入结果 |
| 未接单直接执行 | 待接单任务直接进入执行页提交 | 阻断操作 | 必须先完成接单 |
| 扫码错误仍允许提交 | 条码或数量不匹配 | 阻断提交 | 核销失败状态必须生效 |
| 交接信息不全 | 缺物流方式、交接人等必填项 | 阻断提交 | 错误提示明确 |
| 跨端状态不同步 | APP 已完成但 Web 未更新 | 提示刷新或记录延迟 | 延迟需可追溯和解释 |

## 15. 回归优先级建议

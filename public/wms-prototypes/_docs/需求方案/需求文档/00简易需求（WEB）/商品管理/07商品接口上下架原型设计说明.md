# 商品接口上下架原型设计说明

## 1. 设计目标

- 基于 [06商品接口上下架简易需求.md](./06商品接口上下架简易需求.md) 输出可直接用于绘制原型的页面设计说明
- 覆盖上下架日志列表页、详情弹窗两个页面
- 帮助运营/仓管人员快速追溯：哪个 SKU、因为什么事件、触发了上架还是下架、接口调用是否成功

---

## 2. 设计范围

### 2.1 本期范围

- 商品接口上下架日志列表页
- 调用详情弹窗

### 2.2 暂不涉及

- 手动触发上下架入口（待业务确认后再补充）
- 失败告警通知配置页（后台系统级配置，不在本模块）

---

## 3. 信息架构

```text
商品管理
└─ 接口上下架日志
   ├─ 日志列表页
   │  ├─ 统计概览区
   │  ├─ 查询筛选区
   │  └─ 日志列表区
   └─ 调用详情弹窗
      ├─ 基本信息区
      └─ 报文区（请求 / 响应）
```

## 4. 页面关系

| 来源页面       | 触发动作         | 目标页面     |
| ---------- | ------------ | -------- |
| 商品管理菜单     | 点击「接口上下架日志」  | 日志列表页    |
| 日志列表页      | 点击【查看详情】     | 调用详情弹窗   |

## 6. 页面级原型设计

### 6.1 接口上下架日志列表页

**页面目标**

供运营/仓管人员按需筛选、追溯每次上下架接口调用的来源、结果及 SKU 明细。

**页面布局**

```text
标题区
├─ 标题：接口上下架日志
└─ 说明文字：记录WMS自动触发的电商商品上下架接口调用明细

统计概览区（4张指标卡，数值均基于当前查询结果统计）
├─ 触发次数（当前查询结果共触发次数）
├─ 成功次数（当前查询结果接口成功条数）
├─ 失败次数（当前查询结果接口失败条数）
└─ 失败待关注（与失败次数一致，点击可快速筛选失败记录）

查询筛选区
├─ 所属分类（下拉单选，商品分类树，支持选择叶子分类或父分类）
├─ SKU编码（输入框，模糊搜索）
├─ 上下架动作（下拉单选：全部 / 上架 / 下架）
├─ 触发事件（下拉单选：全部 / 入库上架 / 退货解冻 / 出库发货 / 库存调整 / 库存冻结）
├─ 调用结果（下拉单选：全部 / 成功 / 失败）
├─ 触发时间（日期范围选择，默认近7天）
└─ 操作按钮：【查询】【重置】【导出】

列表区
├─ 触发时间（精确到秒，默认倒序）
├─ SKU编码
├─ SKU名称
├─ 所属分类
├─ 上下架动作（标签：上架=绿色 / 下架=橙色）
├─ 触发事件（文字标签：入库上架 / 退货解冻 / 出库发货 / 库存调整 / 库存冻结）
├─ 关联单据号（可点击复制）
├─ 触发时可售库存（接口触发时的库存快照）
├─ 调用结果（标签：成功=绿色 / 失败=红色）
├─ 失败原因（失败时展示，超长截断+hover展示全文）
└─ 操作列：【查看详情】

分页器
└─ 默认每页20条，支持切换 20 / 50 / 100
```

**核心交互**

- 「失败待关注」指标卡可点击，点击后自动带入「调用结果=失败」条件并触发查询
- 「上下架动作」列使用颜色标签区分，上架绿色、下架橙色，视觉上快速区分状态
- 「调用结果」列失败行整行可轻度高亮（浅红背景），引起关注
- 「关联单据号」支持点击复制，方便跳转到对应入库/出库/调整单排查
- 「失败原因」列内容超长时截断显示，鼠标 hover 时展示完整内容的 tooltip
- 点击【查看详情】打开调用详情弹窗，不跳页

---

### 6.2 调用详情弹窗

**弹窗目标**

展示该条日志对应的完整接口请求/响应报文，供技术人员排查接口调用失败原因。

**触发方式**

点击日志列表中的【查看详情】按钮，居中弹出，背景半透明遮罩。

**弹窗布局**

```text
弹窗标题
└─ 接口调用详情 + 右上角关闭按钮（×）

基本信息区（两列布局，共10个字段，5行×2列整齐排列）
├─ SKU编码
├─ SKU名称
├─ 所属分类
├─ 上下架动作（标签）
├─ 触发事件
├─ 关联单据号
├─ 触发时可售库存
├─ 调用结果（标签）
├─ 触发时间
└─ 失败原因（常驻展示：成功时显示 --，失败时红色加粗）

分割线

报文区（Tab切换）
├─ Tab：请求报文
│  ├─ 请求时间
│  ├─ 请求地址（URL）
│  └─ 请求参数（代码块，JSON格式，支持复制）
└─ Tab：响应报文
   ├─ 响应状态码
   ├─ 响应时间（毫秒）
   ├─ 响应内容（代码块，JSON格式，支持复制）
   └─ 重试次数（有重试时展示：第N次，共M次）

弹窗底部操作区
└─ 【关闭】按钮
```

**核心交互**

- 弹窗宽度建议 680px，高度自适应，超长内容内部滚动
- 基本信息区 10 个字段两列排列，无空白行
- 「失败原因」字段常驻展示：调用成功时显示 --，失败时红色加粗显示错误信息
- 报文区 JSON 内容采用等宽字体代码块展示，提供【复制】快捷按钮
- 点击遮罩区域或右上角关闭按钮，弹窗关闭

## 7. 状态页设计

### 7.1 列表空态

- 有筛选条件时：展示"未查询到符合条件的日志"，提供【重置筛选】入口
- 无筛选条件时：展示"暂无上下架接口调用记录"

### 7.2 调用结果标签状态

| 状态 | 标签颜色 | 标签文字 |
| -- | ---- | ---- |
| 成功 | 绿色   | 成功   |
| 失败 | 红色   | 失败   |

### 7.3 上下架动作标签状态

| 动作 | 标签颜色 | 标签文字 |
| -- | ---- | ---- |
| 上架 | 绿色   | 上架   |
| 下架 | 橙色   | 下架   |

### 7.4 列表加载态

- 列表数据加载中展示骨架屏，不展示空态插画

---

## 8. 组件规范

### 8.1 查询区

- 查询条件每行最多 4 个字段，等宽排列
- 时间范围选择器占 2 个字段宽度
- 操作按钮（查询/重置/导出）右对齐，紧跟最后一行查询条件

### 8.2 列表区

- 采用标准后台表格，斑马纹或细分割线区分行
- 失败行整行浅红背景（#FFF1F0），无需加粗文字
- 编码类字段（SKU编码、关联单据号）支持点击复制，复制成功后行内提示"已复制"
- 列宽自适应，「失败原因」列最大宽度 200px，超出截断

### 8.3 详情弹窗

- 弹窗宽度：680px
- 弹窗最大高度：80vh，内容超出时弹窗内部纵向滚动
- 报文 JSON 代码块背景色使用浅灰（#F5F5F5），字体 Monospace 12px
- 代码块右上角放置【复制】图标按钮，点击后变为✓并显示"已复制"

### 8.4 统计概览区

- 4 张指标卡横向均分排列
- 每张卡片：上方数字（大号字体）+ 下方标签文字
- 「累计失败待关注」卡片数字用红色标注，强调异常

## 10. 原型输出顺序

**第一阶段**

- 接口上下架日志列表页整体框架（标题区 + 统计区 + 筛选区 + 列表区骨架）

**第二阶段**

- 列表区字段填充 + 状态标签样式
- 调用详情弹窗

**第三阶段**

- 空态 / 加载态
- 失败行高亮 + hover交互细节

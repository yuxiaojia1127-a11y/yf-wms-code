# 商品管理后台原型设计（自营版大框架）

## 1. 设计目标

商品管理后台原型面向自营WMS业务，围绕商品档案、SKU档案、条码单位、仓储规则和商品同步异常组织页面。

本阶段定义页面结构、导航入口、主视图和模块关系，不展开字段级和交互细节。

## 2. 角色与使用场景

| 角色 | 使用目标 | 核心关注点 |
| --- | --- | --- |
| 商品运营 | 维护商品与SKU资料 | 商品是否完整、SKU是否启用、条码和规格是否正确 |
| 仓库管理员 | 查看仓储作业资料 | 批次、效期、SN、单位、箱规、尺寸重量是否适合作业 |
| 系统管理员 | 处理同步和数据异常 | 同步失败、重复条码、必填缺失、规则异常 |
| 仓内作业人员 | 在作业中识别商品 | 扫码识别、单位换算、批次效期和SN校验 |

## 6. 页面关系

| 来源页面 | 触发点 | 目标页面 |
| --- | --- | --- |
| 商品档案 | 点击SKU数量 | SKU档案过滤结果 |
| 商品档案 | 点击同步状态 | 商品同步与异常 |

| SKU档案 | 点击仓储规则 | 仓储规则详情 |
| 条码与单位 | 点击条码冲突 | 商品同步与异常 |
| 仓储规则 | 点击规则异常 | 商品同步与异常 |
| 商品同步与异常 | 点击商品编码/SKU编码 | 商品档案或SKU档案详情 |

## 8. 原型第一版页面优先级

### 8.1 第一优先级

| 页面 | 目标 |
| --- | --- |
| 商品档案 | 建立商品基础资料维护入口 |
| SKU档案 | 建立库存和作业最小单元维护入口 |
| 仓储规则 | 建立批次、效期、SN等作业规则维护入口 |

### 8.2 第二优先级

| 页面 | 目标 |
| --- | --- |
| 条码与单位 | 支持条码维护、辅助条码和单位换算 |
| 商品同步与异常 | 支持同步失败和数据异常处理 |

## 9. 大框架结论

商品管理后台原型按“自营商品主数据 + 仓储作业规则”设计：

1. 商品档案承接SPU级商品基础信息。
2. SKU档案承接库存、单据和仓内作业最小单元。
3. 条码与单位支撑扫码识别和库存计量。
4. 仓储规则支撑批次、效期、SN和特殊属性作业控制。
5. 商品同步与异常支撑接口同步、失败重试和数据质量处理。

第一版原型先完成商品档案、SKU档案、仓储规则三类主页面，再补充条码单位和同步异常处理页面。

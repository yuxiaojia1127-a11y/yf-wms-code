# 库存管理简易需求（自营版）

## 1. 基本信息

- 功能名称：库存管理
- 所属系统：WMS_WEB端
- 页面编号：`WMS-WEB-I01`
- 所属模块：库存管理
- 文档定位：自营业务版
- 适用范围：自营库存查询、库存明细、批次效期、库存锁定、库存流水、库存调整与异常处理

## 2. 核心结论

### 2.1 WMS管理对象

| 对象 | 主键/编码 | 管理口径 | 作用 |
| --- | --- | --- | --- |
| 库存汇总 | SKU + 仓库 | 汇总库存口径 | 查看SKU在各仓的库存总量、可用量、锁定量 |
| 库存明细 | SKU + 仓库 + 库位 + 批次 + 库存状态 | 实物库存口径 | 支撑收货、上架、拣货、盘点、移库和追溯 |
| 批次库存 | SKU + 批次 + 生产日期/到期日期 | 批次效期口径 | 支撑食品类商品先进先出、效期预警和禁售控制 |
| 库位库存 | SKU + 库位 + 批次 + 状态 | 仓内作业口径 | 支撑上架、拣货、移库、补货和盘点 |
| 库存锁定 | 单据 + SKU + 批次/库位 | 业务占用口径 | 支撑订单预占、出库锁定、盘点锁定和异常锁定 |
| 库存流水 | 业务单据 + 库存动作 | 库存变更口径 | 记录每一次库存增加、减少、锁定、释放和调整 |

### 2.2 核心规则

1. 自营库存按SKU统一管理。
2. 库存台账粒度为 `SKU + 仓库 + 库位 + 批次 + 库存状态`。
3. 库存数量分为实物库存、锁定库存、可用库存、冻结库存和在途库存。
4. 可用库存按 `实物库存 - 锁定库存 - 冻结库存` 计算。
5. 批次、效期、SN规则来源于SKU仓储规则。
6. 所有库存变更必须生成库存流水。
7. 销售出库、调拨出库、报损出库扣减库存；采购入库、退货入库、调拨入库增加库存。
8. 库存调整、冻结、解冻、移库、盘点差异处理均保留操作记录和业务原因。

## 3. 业务目标

库存管理用于查看和管理自营业务在各仓库、库位、批次和库存状态下的库存情况，支撑采购入库、销售出库、调拨、盘点、移库、补货、退货和库存异常处理。

系统通过库存汇总、库存明细、批次效期、锁定记录和库存流水，为仓内作业、运营查询、库存追溯和财务对账提供统一库存口径。

## 4. 功能范围

- 库存汇总查询
- 库存明细查询
- 批次效期库存查询
- 库位库存查询
- 库存锁定记录查询
- 库存流水查询
- 库存冻结/解冻
- 库存调整
- 库存移库记录查看
- 库存异常处理
- 库存数据导出

## 5. 库存对象与计算口径

### 5.1 库存数量类型

| 库存类型 | 含义 | 来源 |
| --- | --- | --- |
| 实物库存 | 已入库并在仓内可追溯的实际库存 | 收货上架、退货入库、调拨入库、库存调整 |
| 锁定库存 | 已被订单、任务或业务动作占用的库存 | 出库预占、拣货任务、盘点任务、异常处理 |
| 冻结库存 | 暂停参与出库和可用计算的库存 | 质量异常、效期异常、人工冻结、系统冻结 |
| 可用库存 | 当前可用于新业务的库存 | 实物库存 - 锁定库存 - 冻结库存 |
| 在途库存 | 已生成入库预期但尚未完成上架的库存 | 采购在途、调拨在途、退货在途 |

### 5.2 库存状态

| 状态 | 含义 | 使用场景 |
| --- | --- | --- |
| 正品 | 可正常销售和出库 | 标准库存 |
| 次品 | 质检不良或退货不良库存 | 退货、质检、异常处理 |
| 待检 | 已收货待质检库存 | 收货暂存、质检流程 |
| 冻结 | 被质量、效期、盘点或人工原因冻结 | 异常处理 |
| 报损 | 已确认报损待出库或已报损记录 | 报损处理 |

### 5.3 库存计算规则

```text
可用库存 = 实物库存 - 锁定库存 - 冻结库存
```

库存汇总按SKU和仓库聚合展示，库存明细按SKU、仓库、库位、批次和库存状态展示。

批次/效期商品按SKU仓储规则记录批次号、生产日期、到期日期和效期状态。

## 6. 关键流程

### 6.1 入库增加库存

1. 采购、退货或调拨入库任务完成收货。
2. 系统按SKU、批次、效期、SN和库位生成库存明细。
3. 上架完成后增加实物库存。
4. 系统生成入库库存流水。
5. 库存汇总、批次库存、库位库存同步更新。

### 6.2 出库扣减库存

1. 销售、调拨或报损出库单生成出库任务。
2. 系统按SKU、仓库、批次、效期和库位锁定库存。
3. 拣货、复核完成后扣减实物库存和锁定库存。
4. 系统生成出库库存流水。
5. 库存汇总、批次库存、库位库存同步更新。

### 6.3 库存锁定与释放

1. 订单预占、出库任务、盘点任务或异常处理触发库存锁定。
2. 系统记录锁定单据、锁定SKU、锁定数量、锁定库位和锁定原因。
3. 业务完成时扣减锁定库存或释放锁定库存。
4. 系统生成锁定、释放或扣减流水。

### 6.4 库存冻结与解冻

1. 质量异常、效期异常、盘点异常或人工操作触发库存冻结。
2. 冻结库存不参与可用库存计算。
3. 异常处理完成后执行解冻、报损或调整。
4. 系统记录冻结原因、操作人、冻结时间和处理结果。

### 6.5 库存调整

1. 仓库管理员提交库存调整申请或直接执行授权调整。
2. 系统校验SKU、仓库、库位、批次和库存状态。
3. 系统按调整方向增加或减少实物库存。
4. 系统生成库存调整流水。
5. 调整记录保留业务原因、附件和操作日志。

### 6.6 库存盘点差异处理

1. 盘点任务完成后生成账实差异。
2. 系统按SKU、库位、批次和库存状态展示差异。
3. 复核确认后生成盘盈或盘亏调整。
4. 系统生成盘点差异库存流水。

## 9. 规则要求

### 9.1 库存唯一性规则

- 同一SKU、仓库、库位、批次、库存状态下形成一条库存明细。
- 无批次管理SKU使用系统默认批次占位口径保存库存明细。
- 开启SN管理的SKU按序列号记录实物明细。

### 9.2 库存扣减规则

- 出库扣减前必须完成库存锁定。
- 扣减库存时校验锁定记录、SKU、批次、库位和数量。
- 库存扣减后不得出现负库存。
- 出库完成后同步减少实物库存和锁定库存。

### 9.3 批次效期规则

- 开启批次管理的SKU入库时必须记录批次号。
- 开启效期管理的SKU入库时必须记录生产日期或到期日期。
- 达到禁售天数的库存不参与销售出库可用计算。
- 过期库存进入效期异常处理。

### 9.4 冻结与调整规则

- 冻结库存不参与可用库存计算。
- 解冻后库存恢复可用计算。
- 库存调整必须记录调整原因。
- 调整减少库存时校验可用数量。
- 已被出库任务锁定的库存不可直接调整减少。

### 9.5 库存流水规则

- 入库、出库、锁定、释放、冻结、解冻、调整、盘点差异处理均生成库存流水。
- 库存流水记录变化前数量、变化数量和变化后数量。
- 库存流水不可删除。
- 库存流水用于库存追溯和对账。

## 10. 异常场景处理

| 异常场景 | 系统处理 |
| --- | --- |
| 可用库存不足 | 阻断锁定或出库并提示库存不足 |
| 扣减后出现负库存 | 阻断提交并记录异常日志 |
| 批次缺失 | 阻断入库或库存调整并提示补全批次 |
| 效期缺失 | 阻断入库或库存调整并提示补全效期 |
| 库位停用 | 阻断上架、移入和库存调整增加 |
| 库位锁定 | 阻断上架、拣选和调整 |
| 库存被任务占用 | 阻断直接调整减少 |
| 库存流水生成失败 | 回滚本次库存动作并进入系统异常队列 |

## 11. 状态规则

### 11.1 效期状态

| 状态 | 含义 | 规则 |
| --- | --- | --- |
| 正常 | 处于可销售效期范围 | 可参与销售出库 |
| 临期 | 距到期天数小于等于临期预警天数 | 可参与业务并触发预警 |
| 禁售 | 距到期天数小于等于禁售天数 | 不参与销售出库可用计算 |
| 过期 | 已超过到期日期 | 进入效期异常处理 |

### 11.2 锁定状态

| 状态 | 含义 | 规则 |
| --- | --- | --- |
| 已锁定 | 库存已被业务占用 | 不参与新业务可用计算 |
| 已释放 | 锁定已释放 | 库存恢复可用计算 |
| 已扣减 | 锁定库存已完成出库扣减 | 记录最终扣减结果 |

## 12. 验收要点

- 能按仓库、库位、SKU编码、商品名称、条码、批次号、库存状态、效期状态完成查询。
- 能查看SKU维度库存汇总。
- 能查看SKU、仓库、库位、批次、库存状态维度库存明细。
- 能正确计算实物库存、锁定库存、冻结库存和可用库存。
- 能查看批次号、生产日期、到期日期和效期状态。
- 能查看库存锁定记录和释放记录。
- 能查看库存流水，且流水包含业务单号、业务类型、库存动作、变化前数量、变化数量和变化后数量。
- 库存冻结后不参与可用库存计算。
- 库存解冻后恢复可用库存计算。
- 库存调整能记录调整原因和操作日志。
- 出库扣减库存时不允许出现负库存。
- 库存数据支持导出。

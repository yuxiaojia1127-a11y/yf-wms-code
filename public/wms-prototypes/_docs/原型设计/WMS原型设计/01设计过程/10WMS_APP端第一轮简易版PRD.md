# WMS_APP端第一轮简易版PRD

## 1. 文档说明

本文为 `WMS原型设计` 中 `WMS_APP端` 的第一轮简易版 PRD，作为后续 APP 端页面原型说明和可交互原型的输入基线。

本轮重点覆盖：

- 通用基础能力
- 工作台与任务中心
- 入库执行主链路
- 出库执行主链路

本轮特别说明：

- APP 端是仓内一线执行端，聚焦任务驱动和现场操作，不承接第三方电商系统侧页面需求。
- APP 端第一轮先解决“登录进入系统、选择上下文、接单执行、扫码核销、收货上架、复核出库”的高频主链路。
- 物流协同、调拨、退货、仓内作业和异常扩展能力暂不在本轮展开完整简易版 PRD，留到下一轮继续补充。

本轮不展开以下范围：

- 物流协同
- 调拨作业
- 售后作业
- 仓内作业
- 消息中心
- 我的
- 异常中心扩展能力

状态口径说明：本文中的任务状态、执行节点状态、交接状态、质检状态和异常状态统一引用 [16WMS_APP端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/16WMS_APP端状态口径总表.md)；若本文件局部示例与状态口径总表存在差异，以状态口径总表为准。

## 2. 功能目标

本轮简易版 PRD 的目标是建立 WMS_APP 端的高频执行主链路，让一线作业员能够从登录进入、选择仓库上下文开始，完成收货、上架、备货、扫码核销、复核和出库确认等关键任务。

具体目标如下：

1. 建立 APP 登录与上下文切换能力，确保任务数据按货主和仓库范围正确隔离。
2. 建立工作台和任务中心，统一展示待收货、待上架、待备货、待复核、待出库等任务入口。
3. 建立入库执行主链路，承接收货任务详情、收货录入、上架确认。
4. 建立出库执行主链路，承接发货履约任务详情、备货扫码与核销、复核与出库确认。
5. 建立在线重试等基础系统能力，保证弱网和提交失败场景下的一线可操作性。

## 7. 核心流程

### 7.1 登录与上下文进入流程

1. 作业员打开 APP 进入登录页。
2. 登录成功后，系统加载角色和可操作仓库范围。
3. 用户进入货主/仓库选择页，确认当前上下文。
4. 上下文确认后进入工作台或任务中心开始执行任务。

### 7.2 入库执行主链路

1. 作业员在工作台或任务中心进入收货任务详情。
2. 接单后，任务锁定到当前作业人。
3. 进入收货录入页执行扫码收货、录入批次、生产日期、有效期和货位信息。
4. 如存在少收、多收、破损等情况，在现场完成差异登记。
5. 收货提交成功后进入上架确认页，完成货位确认和结果提交。
6. 完成入库后，WMS 更新入库状态和库存结果。

### 7.3 出库执行主链路

1. 作业员在任务中心进入发货履约任务详情。
2. 接单后，任务锁定到当前作业人。
3. 点击开始备货进入扫码与核销页。
4. 按推荐货位、批次和数量进行扫码核销，系统实时校验。
5. 核销成功后进入复核与出库确认页。
6. 完成复核和出库确认后，WMS 更新出库结果与履约状态。

### 7.4 弱网与失败处理流程

1. 登录、扫码、收货提交、核销提交、出库确认均为在线动作。
2. 如网络异常或提交失败，系统弹出在线重试提示层。
3. 用户可查看失败原因并发起重试，不支持离线缓存补传。

## 8. 状态流转

本章节不再定义独立的 APP 端状态体系，统一引用 [16WMS_APP端状态口径总表.md](file:///Users/yuxiaojia/Documents/项目/YF/YF-wms-web/YF-wms-web-code/docs/原型设计/WMS原型设计/16WMS_APP端状态口径总表.md)；以下内容仅用于说明本轮涉及任务或结果对象的状态使用范围、页面展示位置和理解方式。

### 8.1 通用任务状态

| 状态 | 说明 |
| ---- | ---- |
| 待接单 | 任务已生成，待作业员领取 |
| 处理中 | 任务已由作业员接单并进入执行过程 |
| 已完成 | 当前任务处理完成 |
| 失效 | 任务已被取消、转派或状态变更不可继续执行 |
| 异常 | 任务执行中出现异常，需人工确认 |

### 8.2 入库任务状态

| 状态 | 说明 |
| ---- | ---- |
| 待接单 | 待领取收货任务 |
| 待收货 | 已接单，待录入收货结果 |
| 待上架 | 收货完成，待确认货位并提交上架结果 |
| 已完成 | 入库执行完成 |

### 8.3 出库任务状态

| 状态 | 说明 |
| ---- | ---- |
| 待接单 | 待领取发货履约任务 |
| 待备货 | 已接单，待执行扫码备货 |
| 待复核 | 备货完成，待复核 |
| 待出库 | 复核完成，待确认出库 |
| 已完成 | 出库结果提交成功 |

### 8.4 扫码与提交结果状态

| 对象 | 状态 | 说明 |
| ---- | ---- | ---- |
| 扫码结果 | 成功 / 失败 | 成功更新明细，失败展示原因 |
| 提交结果 | 成功 / 失败 | 成功流转任务状态，失败允许在线重试 |
| 差异结果 | 正常 / 少收 / 多收 / 破损 / 码不匹配 | 现场差异登记口径 |

## 13. 异常处理

| 场景 | 处理要求 |
| ---- | ---- |
| 登录失败 | 展示账号错误、权限不足或网络失败原因 |
| 上下文无权限 | 提示当前账号无可操作仓库 |
| 任务已被他人接单 | 提示任务已锁定，不允许重复处理 |
| 任务状态失效 | 提示当前状态不可继续操作 |
| 扫码失败 | 展示码不匹配、重复扫码、数量不符等原因 |
| 收货差异 | 支持登记少收、多收、破损和备注 |
| 出库差异 | 支持在核销或复核阶段记录异常 |
| 网络异常 | 弹出在线重试提示层，不缓存离线数据 |

# 商品管理简易需求

## 1. 基本信息

- 功能名称：商品管理
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-006`
- 关联页面：`WMS-WEB-007`
- 所属模块：商品管理
- 文档定位：结论版

## 2. 核心结论

### 2.1 WMS管理对象

| 对象        | 主键/编码             | 管理口径     | 作用                           |
| --------- | ----------------- | -------- | ---------------------------- |
| 货主商品      | `货主 + 货主SKU编码`    | 货主独立维护   | 作为订单、库存、入库、出库、盘点、调拨、结算的业务主数据 |
| WMS商品编码   | 系统生成              | 一物一编码    | 作为WMS内部商品主键，承接单据、接口、历史追溯     |
| WMS商品识别档案 | 识别商品ID            | 系统自动生成   | 归集不同货主同品候选、承接供给关系、支撑跨货主履约匹配  |
| 跨货主供给关系   | 需求货主SKU + 供给货主SKU | 平台维护生效关系 | 定义谁可以给谁供货、在哪个仓供货、按什么优先级供货    |

### 2.2 核心规则

1. WMS 以 `货主SKU` 作为库存和作业主数据。
2. 库存台账按 `货主 + SKU + 仓库 + 仓位 + 批次 + 状态` 隔离管理。
3. 系统基于 `主条码 + 基础单位 + 规格关键字段` 自动生成 WMS 商品识别档案（识别商品ID）。
4. 商品名称、SPU、SKU 文案统一归一化后参与辅助校验。
5. 批次、效期、SN 采用“是否管理”口径参与规则兼容性校验，不比较具体值。
6. 系统基于已生效的跨货主供给关系执行自动供货与履约。
7. 需求货主库存不足时，系统自动匹配供给货主库存，并生成履约来源、采购、销售、货权/结算记录(后续再迭代)。
8. 对外订单、发货单、物流结果始终以需求货主口径输出。

## 3. 业务目标

维护多货主商品/SKU主数据、商品识别档案和跨货主供给关系，支撑商品同步、库存管理、仓内作业和跨货主自动履约。

## 4. 功能范围

- 商品列表查询与分页
- 商品新建、编辑、查看、启停
- 商品同步与同步日志查看
- WMS商品识别档案生成与查看
- 跨货主供给关系维护与生效控制
- 跨货主自动履约来源记录
- 商品数据导出

## 5. 关键流程

### 5.1 商品建档与识别流程

1. 货主维护自己的商品和 SKU。
2. 系统生成 WMS 商品编码，并保存主条码、基础单位、规格关键字段、仓储规则。
3. 系统自动生成或归并 WMS 商品识别档案。
4. 系统回显识别商品ID、识别状态和识别摘要。
5. 平台维护跨货主供给关系并控制生效状态。

### 5.2 跨货主自动履约流程（后续再迭代，1.0暂不涉及）

1. 订单进入 WMS，订单行使用需求货主 SKU。
2. 系统优先扣减需求货主自有库存。
3. 自有库存不足时，系统查询已生效供给关系。
4. 系统按仓库范围、可用库存、规则兼容性、优先级完成供给匹配。
5. 命中后锁定供给货主库存，并生成履约来源明细。
6. 系统自动生成采购单、销售单、货权转移单或结算记录。
7. 仓内按实际库存货主的商品、批次、库位执行作业。
8. 对外回传需求货主订单、发货单、包裹和物流状态。

## 8. 规则要求

### 8.1 商品与库存规则

- `货主 + 货主SKU编码` 作为业务唯一键。
- WMS商品编码保存后生成并长期稳定，用于单据、接口和历史追溯。
- 同一货主下货主SKU编码不可重复。
- 条码支持多值录入，保存时自动去重。
- 一个 SKU 可维护 1 个主条码 + 多个辅助条码，列表默认展示主条码，详情中展示完整条码清单。
- 当商品因加工、换包装、新旧规格替换等场景出现新条码时，允许在不变更 SKU 的前提下补充辅助条码。
- 商品状态为启用时参与业务；停用后保留历史数据。

### 8.2 WMS商品识别档案规则

- 系统按主条码、基础单位、规格关键字段自动生成或归并识别商品档案。
- 商品名称、SPU、SKU、品牌等文字字段在比对前自动做大小写、空格、全半角归一化。
- 文字字段参与辅助校验，不单独决定识别结果。
- 批次、效期、SN 采用“是否管理”口径参与仓储规则兼容性校验。
- 主条码、基础单位、规格关键字段一致时，货主商品归入同一识别商品ID。
- 主条码相同但单位、规格、仓储规则冲突时，系统生成独立识别商品ID并进入冲突待处理状态。
- 货主商品资料修正后，系统自动重新执行识别匹配并更新识别结果。

### 8.3 跨货主供给关系规则（后续迭代）

- 供给关系至少包含：需求货主、需求SKU、供给货主、供给SKU、仓库范围、优先级、状态。
- 系统仅使用已审核、已生效且规则兼容的供给关系参与自动履约。
- 供给关系可挂在识别商品ID下，也可挂在需求SKU/供给SKU组合下。

### 8.4 自动履约规则

- 订单进入 WMS 后，订单行保持需求货主 SKU 口径。
- 系统优先匹配需求货主自有库存。
- 自有库存不足时，系统按供给关系、仓库范围、库存、时效、规则兼容性完成供给匹配。
- 命中供给后，系统生成履约来源明细，记录需求货主SKU、供给货主SKU、仓库、批次、数量、结算价。
- 系统自动生成采购单、销售单、货权转移单或结算记录。
- 仓内按实际库存货主商品执行拣货、复核、出库。
- 对外仅回传需求货主订单、发货单、包裹和物流状态。

### 8.5 异常场景处理

- 供给关系未生效时，系统不执行跨货主供给，订单进入异常处理。
- 单位、规格或仓储规则不兼容时，系统不执行跨货主供给，订单进入异常处理。
- 结算价缺失时，系统不生成自动采购/销售结算，订单进入异常处理。
- 供给货主库存不足时，系统按缺货处理并输出异常结果。
- 识别状态为冲突待处理时，相关商品不参与自动供给匹配。

## 9. 状态规则

### 9.1 商品状态

| 状态 | 含义        | 规则                  |
| -- | --------- | ------------------- |
| 启用 | 商品可参与业务   | 可用于入库、库存、出库、可售与同步处理 |
| 停用 | 商品不可参与新业务 | 历史数据保留              |

### 9.2 同步状态

| 状态   | 含义            | 触发            |
| ---- | ------------- | ------------- |
| 未同步  | 商品已建立，未发起对外同步 | 新建后初始状态       |
| 同步中  | 已发起同步请求       | 点击同步或自动重试后进入  |
| 同步成功 | 下游接收成功        | 返回成功并记录下游商品ID |
| 同步失败 | 下游接收失败        | 返回失败码、失败信息    |

### 9.3 识别状态

| 状态    | 含义              | 触发              |
| ----- | --------------- | --------------- |
| 候选中   | 系统已完成识别并可参与候选归集 | 商品保存后生成识别结果     |
| 已生效   | 已用于供给匹配和履约来源承接  | 识别结果稳定可用        |
| 冲突待处理 | 主字段冲突，待修正后重新识别  | 条码相同但单位/规格/规则冲突 |

## 10. 验收要点

- 能按货主、商品状态、同步状态、识别状态、货主SKU编码、WMS商品编码、识别商品ID、商品名称、条码完成查询
- 商品保存后自动生成 WMS 商品编码和识别商品ID
- 条码、单位、规格一致时，多个货主商品可归入同一识别商品ID
- 识别主字段冲突时，系统生成独立识别商品ID并进入冲突待处理状态
- 需求货主库存不足时，系统可按生效供给关系匹配供给货主库存
- 自动履约完成后可生成履约来源、采购、销售、货权或结算记录
- 供给关系未生效、规则不兼容、结算价缺失时，系统按异常场景处理
- 点击同步后能看到同步状态变化和失败原因

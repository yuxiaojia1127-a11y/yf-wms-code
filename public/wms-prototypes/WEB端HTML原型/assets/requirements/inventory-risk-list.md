# WMS-WEB 库存风险列表简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 库存风险列表 |
| 所属模块 | 库存中心 |
| 页面定位 | 承接驾驶舱“库存风险 Top”模块的下钻查看与处理入口 |
| 页面编码 | `WMS-WEB-015A` |
| 适用端 | WMS-WEB 管理端 |

## 2. 业务说明

库存风险列表用于集中承接驾驶舱“库存风险 Top”模块中的风险商品明细，帮助仓内管理角色从卡片式风险浏览切换到列表式风险处理模式。

页面数据口径与驾驶舱当前模块保持一致，不新增额外业务口径。当前版本重点承接以下风险类型：

- 高预警库存
- 安全库存预警
- 高锁定占比
- 严重高锁定

用户进入页面后，可按仓库、风险类型、风险等级、商品关键词等条件快速筛选风险记录，支持导出当前筛选结果，并支持通过页面顶部按钮关闭当前筛选结果中的风险预警，便于管理者快速完成风险收口。

## 3. 使用角色

| 角色类型 | 角色 | 操作权限 | 数据权限 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 管理角色 | 系统管理员 / 系统运营 | 查询、导出、关闭预警 | 全部授权范围 | 用于查看整体库存风险分布 |
| 管理角色 | 仓内管理员 | 查询、导出、关闭预警 | 所属权限仓库 | 页面核心使用角色 |
| 管理角色 | 仓内主管 | 查询、关闭预警 | 所属仓库或库区 | 重点关注高预警库存与高锁定风险 |
| 作业角色 | 仓内作业员 | 无页面权限 | 不开放 | 不直接使用该页面 |

## 4. 功能描述

- 支持从驾驶舱“库存风险 Top”模块点击进入库存风险列表页面。
- 支持在库存中心菜单下新增“库存风险列表”入口。
- 支持列表展示与驾驶舱当前模块一致的库存风险数据。
- 支持按仓库、风险类型、风险等级、处理状态、关键词进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持通过页面顶部按钮关闭当前筛选结果中的风险预警。
- 支持按风险类型、仓库、可售库存、锁定占比、更新时间点击表头排序。

## 5. 查询条件

| 字段名称 | 字段类型 | 查询方式 | 暗字提示 |
| ---- | ---- | ---- | ---- |
| 仓库 | 下拉单选 | 精确筛选 | 默认全部授权仓库 |
| 风险类型 | 下拉单选 | 精确筛选 | 高预警库存 / 安全库存预警 / 高锁定 / 严重高锁定 |
| 风险等级 | 下拉单选 | 精确筛选 | 全部 / 红色严重 / 橙色预警 |
| 处理状态 | 下拉单选 | 精确筛选 | 全部 / 待处理 / 跟进中 / 已忽略 |
| 关键词 | 输入框 | 模糊查询 | 支持 SKU 编码 / 商品名称 / 条码 |

## 6. 列表字段

| 字段名称 | 字段类型 | 是否必填 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 商品信息 | 文本 | 是 | 鸡蛋 30 枚装 / EGG-30 | 展示商品名称、SKU 编码、规格 |
| 风险类型 | 标签 | 是 | 高预警库存 | 展示当前风险分类 |
| 仓库 | 文本 | 是 | 2号仓库 | 展示当前风险所属仓库 |
| 可售库存 | 数值 | 是 | 6 箱 | 展示当前 available 数值 |
| 高预警库存阈值 | 数值 | 否 | 10 箱 | 高预警库存类风险展示 |
| 安全库存阈值 | 数值 | 否 | 20 箱 | 安全库存类风险展示 |
| 锁定占比 | 百分比 | 否 | 83% | 锁定类风险展示 |
| 风险说明 | 文本 | 是 | 可售库存低于高预警库存（10箱） | 与驾驶舱风险文案保持一致 |
| 更新时间 | 时间 | 是 | 2026-06-04 10:30 | 最近一次同步时间，支持表头排序 |

## 7. 排序与展示规则

- 默认按风险严重程度排序，红色严重优先。
- 支持按风险类型、仓库、可售库存、锁定占比、更新时间点击表头排序。
- 同级排序规则与驾驶舱保持一致：
  - 高预警库存
  - 高锁定
  - 其他预警
- 同一风险类型下，按更新时间倒序展示。
- 默认每页展示 10 条。
- 当前筛选条件下无数据时，列表展示空态并保留查询条件。

## 8. 关闭预警

- 点击页面顶部“关闭预警”按钮后，弹出确认提示。
- 确认关闭后，当前筛选结果中的风险预警从列表中移除。
- 取消关闭后，页面维持当前状态不变。

## 9. 关键规则

- 页面数据口径与驾驶舱“库存风险 Top”模块保持一致。
- 高预警库存文案统一为：`可售库存低于高预警库存（阈值）`。
- 安全库存预警文案统一为：`可售库存低于安全库存（阈值）`。
- 高锁定文案统一为：`仓库名 · 锁定占比 xx%`。
- 当锁定占比 `> 80%` 时，风险等级升级为红色严重。
- 导出范围为当前筛选结果，不导出未命中的记录。
- 驾驶舱入口默认跳转到该页面，不再直接进入库存控制通用页。

## 10. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在风险数据 | 展示查询区、列表、分页与关闭预警能力 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无库存中心权限 | 展示无权限提示，不显示列表 |
| 数据延迟 | 数据刷新存在延迟 | 页面顶部展示更新时间说明 |

## 11. 菜单与入口

| 入口位置 | 入口说明 | 跳转结果 |
| ---- | ---- | ---- |
| 驾驶舱 > 库存风险 Top > 查看库存预警 | 驾驶舱风险模块下钻入口 | 跳转库存风险列表 |
| 库存中心 > 库存风险列表 | 菜单常驻入口 | 进入库存风险列表 |

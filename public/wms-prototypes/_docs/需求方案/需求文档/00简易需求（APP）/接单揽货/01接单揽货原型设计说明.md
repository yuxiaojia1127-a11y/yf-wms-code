# 仓库APP-接单揽货原型设计说明

> 依据文档：
>
> - 需求：[00接单揽货简易需求文档.md](./00接单揽货简易需求文档.md)
> - UI 规范：[2606改仓配端APP UI规范.md](../../../UI规范/2606改仓配端APP UI规范.md)
> - 设计稿：CoDesign `2606改仓配端` 分组（接单揽货、揽货详情、揽货详情-展开画板）
>
> 本说明仅覆盖「查看揽货任务、接单」环节；接单后的揽货作业设计另行输出。

## 1. 设计目标

- 基于简易需求文档输出可直接用于绘制/还原原型的页面设计说明。
- 覆盖接单揽货列表页、揽货详情页（默认态 + 收货详情展开态）两个页面。
- 帮助仓库揽货人员在现场快速完成：扫一眼任务关键信息 → 判断 → 接单，主路径触达不超过 2 步。

## 2. 设计范围

### 2.1 本期范围

- 接单揽货列表页（搜索区 + 页签区 + 筛选区 + 任务卡片列表）
- 揽货详情页默认态（任务摘要 + 订单信息 + 收货人 + 商品清单 + 金额 + 日志 + 底部接单）
- 揽货详情页收货详情展开态（灰底补充信息块）

### 2.2 暂不涉及

- 去揽货后的商品级作业操作（可操作商品卡、扫码、缺货登记、换货退货等多态，对应 UI 规范 8.5.2 / 8.5.3 的 actionable / exception 态）
- 「我的任务」中已接单任务的后续状态流转展示
- 工作台入口卡片设计（由工作台页面统一约束）

## 3. 信息架构

```text
仓库APP
└─ 接单揽货（WMS-APP-001）
   ├─ 任务列表页
   │  ├─ 顶部导航（返回 + 标题）
   │  ├─ 搜索区（订单号/联系人 + 搜索按钮）
   │  ├─ 页签区（待接单 / 我的任务 + 时间排序）
   │  ├─ 筛选区（全部 / 即时配送 / 物流发货）
   │  └─ 任务卡片列表（下拉刷新 / 上拉加载）
   └─ 揽货详情页（WMS-APP-001-D）
      ├─ 任务摘要区（状态 + 任务ID + 订单号 + 配送信息）
      ├─ 订单信息卡（库房 / 预约送达 / 缺货处理 / 备注 / 收货人）
      │  └─ 收货详情展开块（地址 / 收货点 / 门牌号 / Wechat / WhatsApp）
      ├─ 揽货商品清单（批次标识 + 商品行）
      ├─ 金额汇总（支付金额 / 总成本价）
      ├─ 订单日志（下单节点）
      └─ 底部操作栏（确认接单）
```

## 4. 页面关系

| 来源页面 | 触发动作 | 目标页面 | 带入参数 |
| ---- | ---- | ---- | ---- |
| 工作台 > 揽单 | 点击模块卡片 | 任务列表页（默认「待接单」页签） | 当前库房 |
| 任务列表页 | 点击卡片区域 /「揽货详情」 | 揽货详情页 | 任务ID |
| 任务列表页 | 点击「接单」 | 留在列表，弹确认弹窗 → 接单成功 | 任务ID |
| 揽货详情页 | 点击「确认接单」 | 接单成功，返回列表 | 任务ID |
| 揽货详情页 | 点击「收货详情」 | 页内展开/收起补充信息块 | — |
| 揽货详情页 | 点击返回 | 返回任务列表页 | 保留页签与筛选状态 |

## 5. 页面设计

### 5.1 任务列表页

整体遵循 UI 规范 7.1 标准移动页结构，页面背景 `--app-bg #F5F7F8`，左右安全边距 `12px`。

**顶部导航**（规范 7.2）：高度 `44px`，左侧返回图标，居中标题「接单揽货」16px / 600，可叠加顶部浅青渐变 `#DDF8F2` 起色。

**搜索区**（规范 8.3）：浅灰胶囊输入框（`--app-bg-soft`，圆角 16-18px），左侧搜索图标，placeholder「请输入订单号/联系人」使用 `--app-text-muted`；右侧「搜索」为主色胶囊按钮。

**页签区**：「待接单」「我的任务」横向 Tab，当前项 16px 加粗 + 主色 `#43B8A8` 下划线，未选中项 `--app-text-secondary`；右侧「时间 ⇅」排序切换，文字 12px + 上下箭头图标，激活方向使用主色。

**筛选区**：胶囊按钮组「全部 / 即时配送 / 物流发货」，单选；选中项深色底（`#1F2329`）白字，未选中白底深字，圆角胶囊，高度约 32px。

**任务卡片**（规范 8.4）：

| 元素 | 设计规格 |
| ---- | ---- |
| 卡片容器 | 白底 `#FFFFFF`，圆角 `8px`，卡片间距 `8-10px`，内边距 `10-12px`，阴影 `--app-shadow-card` |
| 卡片标题 | 左上角联系人（如 linzhaobin），14px / 500，`--app-text` |
| 状态标签 | 右上角小圆点 + 状态文字：待接单 `#68B92E`、已接单 `#2AA7C9`，11-12px |
| 字段区 | 左右对齐两列：字段名左侧 `--app-text-secondary` 12px，字段值右侧 `--app-text` 12px；依次为任务ID、库房、配送方式（时效 ｜ 距离）、送达时间选择、商品数量（N (共N件)）、下单时间 |
| 分隔线 | 字段区与按钮区之间使用虚线分隔，颜色 `--app-border #EEF0F2` |
| 操作按钮 | 卡片底部右对齐：次按钮「揽货详情」浅灰底（`--app-bg-soft`）深字；主按钮「接单」（待接单）/「去揽货」（已接单）主色 `#43B8A8` 白字；圆角 6-8px，高度约 36px |

列表交互：下拉刷新、上拉加载更多、滚动保留页签/筛选吸顶（搜索区随页面滚动收起可选）。

### 5.2 揽货详情页（默认态）

对应 UI 规范 8.5.1，页面骨架从上到下固定：

1. **返回区**：顶部左侧返回图标，无标题文字，状态直接作为正文大标题。
2. **任务摘要**：状态标题「待接单」20px / 600；任务ID、订单号（SM2025002140190351）各一行，旁置「复制」浅蓝小标签（`--app-info` 弱底）；配送信息行「即时配送 ｜ 2小时内送达 ｜ XXXkm」13px。
3. **订单信息卡**（白卡，圆角 8px）：
   - 库房（右对齐值，如：吉隆坡前置仓）、预约送达时间——常规字段，值 `--app-text`。
   - 商品缺货时、订单备注——值使用橙色强调 `--app-warning #D99A19`，与常规字段间用虚线分隔。
   - 收货人行：人形图标（主色）+ 姓名 ｜ 电话 + 右侧主色描边圆形拨号按钮。
   - 邮编行 + 「收货详情 ˅」展开入口（`--app-info` 链接色，带展开箭头）。
4. **揽货商品清单**：
   - 区块标题「揽货商品: N（共N件）」14px / 600，数字部分可红橙强调。
   - 批次卡片标题「揽货#N ｜ 第N/共N张揽货单」，「第N」使用主色（规范 8.5.4 批次标题格式）。
   - 商品行（规范 8.6，只读态）：行头为温区+库位标签（货架图标 + 常温区 A01-01-2）与条码（条码图标 + 5748754888），灰底圆角小条；行体为商品图（52-60px，圆角）、商品名最多两行超出省略、规格/重量 11px 弱色、售价红橙 `--app-danger`、成本价深色、右侧数量 `xN`（红橙）。
5. **金额汇总卡**：支付金额 / 总成本价并排两列，金额数字 20px / 600（RM 523.00），字段名 12px 弱色置于下方。
6. **订单日志卡**：时间轴样式，「下单」节点（主色空心圆点 + 竖虚线），内含下单用户、下单时间、付款时间，灰底信息块。
7. **底部操作栏**：固定底部，高 `56px` + 安全区，顶部 `--app-border` 细分割线；单一主按钮「确认接单」，主色胶囊（圆角 20px+），全宽居中。

仅「待接单」状态展示底部「确认接单」；从「我的任务」进入的已接单任务隐藏该按钮（去揽货入口不在本期范围）。

### 5.3 揽货详情页（收货详情展开态）

对应 UI 规范 8.5.2 的补充信息块规则：

- 点击「收货详情」在收货人信息下方展开灰底补充块（`--app-bg-soft #F7F8FA`，圆角 8px，内边距 10-12px）。
- 内容自上而下：地址全称（多行长文本）、虚线分隔、收货点、楼层/门牌号（值橙色强调 `--app-warning`，如 BlockA-21-7）、Wechat、WhatsApp。
- 文字 11-12px，长地址允许多行展示，不截断。
- 再次点击「收货详情 ˄」收起；展开/收起不改变页面其他区块层级与顺序。

## 7. 关键交互设计

- **接单确认**：列表「接单」与详情「确认接单」均弹中置确认弹窗（规范 8.8：遮罩黑 35%-45%，圆角 12-16px，主按钮主色、取消浅灰），确认后调用接单，成功 toast「接单成功」，任务移入「我的任务」。
- **接单冲突**：任务已被他人接单时 toast「任务已被接单」，自动刷新列表移除该任务；详情页则提示后返回列表。
- **复制**：点击「复制」复制任务ID/订单号并 toast「已复制」。
- **拨号**：点击拨号按钮唤起系统电话。
- **排序**：默认下单时间倒序，点击「时间」切换升/倒序，箭头方向同步。
- **状态保持**：从详情返回列表保留页签、筛选、排序与滚动位置。

## 8. 空态与异常态

| 场景 | 设计表现 |
| ---- | ---- |
| 列表为空 | 居中空态插图 + 「暂无揽货任务」（`--app-text-muted`） |
| 搜索无结果 | 保留搜索词，空态文案「未找到相关任务」 |
| 加载失败 | 居中提示 + 「重试」次按钮 |
| 任务已取消 | 详情页操作时 toast「任务已取消」并返回列表 |

## 9. 原型落地规则

- 新页面草稿先放 `public/wms-prototypes/_drafts/`，确认后合并至 `APP端HTML原型/WMS-APP端原型.html`（规范 10）。
- 样式统一引用 UI 规范第 9 节 Design Tokens，不新造颜色、圆角、阴影。
- 中英文兼容：按钮与状态文案预留英文变长宽度（规范 3.6）。
- 详情页骨架为后续「去揽货」作业态复用基础，商品卡需预留 `readonly → actionable` 状态切换能力（规范 8.5.4），本期仅实现 readonly。

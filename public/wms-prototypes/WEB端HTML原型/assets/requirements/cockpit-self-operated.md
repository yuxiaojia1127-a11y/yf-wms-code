# 驾驶舱简易需求-自营版

## 1. 基本信息

- 功能名称：驾驶舱111222
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-036`
- 所属模块：驾驶舱
- 当前口径来源：当前 `public/prototype/web/index.html` 原型实现
- 文档定位：根据当前高保真原型回写的简易需求文档，用于原型、前端、接口和测试统一口径

## 2. 业务目标

面向自营仓储管理角色提供一屏总览能力，集中展示库存风险、仓内作业、履约链路、异常待办和关键指标，帮助仓内管理者在当前屏快速识别风险与堵点，并进入对应业务页面继续处理。

当前页面默认需要快速回答以下 4 个问题：

1. 当前库存是否存在必须优先处理的风险。
2. 仓内作业当前卡在哪个节点。
3. 履约链路当前卡在哪个节点。
4. 哪些超时 / 紧急待办需要立刻处理。

## 5. 核心指标卡需求

### 5.1 展示要求

- 顶部固定展示 5 项总览型核心指标，不支持用户自定义排序。
- 每张指标卡展示：指标名称、指标值、指标说明、状态标签。
- 指标卡支持点击下钻，进入对应业务页面。
- 顶部指标卡只展示结果型指标，不与作业漏斗节点重复。
- 当前原型指标说明口径已收敛为更短文案，避免首屏信息过载。

### 5.2 指标明细

| 指标名称  | 统计口径                                          | 当前说明文案要求                                | 状态标签示例            | 下钻页面       |
| ----- | --------------------------------------------- | --------------------------------------- | ----------------- | ---------- |
| 可用库存  | 当前筛选范围内 available 库存总量汇总                      | 展示简短库存补充说明，如冻结库存或库存充足说明                 | 较昨日 +3.8% / 稳定    | 库存查询       |
| 履约及时率 | SLA 内完成履约单数 / 应完成履约单数                         | 展示分子 / 分母明细，如 `428 / 452`               | 较昨日 +1.2% / 略低于目标 | 物流跟踪明细列表 |
| 库存预警  | 当前筛选范围内未关闭库存预警总数，低于安全库存值、高预警库存值的则预警           | 当前驾驶舱统一展示为低库存 SKU 数，如 `低库存SKU12`        | 5条高预警 / 以低库存为主    | 库存风险列表     |
| 锁定占比  | `locked / physical，锁定占比值高于60%的为高锁定，高于80%严重锁定` | 当前驾驶舱统一展示为高锁定 SKU 数，如 `高锁定SKU 4 个`      | 1条高预警 / 需关注 / 正常  | 库存风险列表     |
| 异常待处理 | 当前筛选范围内未关闭异常数量                                | 展示物流 / 入库 / 出库拆分，如 `物流 3 · 入库 2 · 出库 2` | `2条已等待超60分钟`      | 超时/紧急列表    |

### 5.3 指标状态规则

| 指标    | 正常          | 预警                | 严重                |
| ----- | ----------- | ----------------- | ----------------- |
| 可用库存  | 库存满足当前作业需求  | 关键 SKU 可用库存逼近安全阈值 | 关键 SKU 已影响履约或作业执行 |
| 履约及时率 | 达到目标值       | 低于目标值但未严重偏离       | 明显低于目标值           |
| 库存预警  | 无高风险预警或数量较低 | 存在需关注的低库存 SKU     | 高预警数量较多，需优先处理     |
| 锁定占比  | 占比处于安全范围    | 高于关注阈值            | 高于严重阈值并影响可用库存     |
| 异常待处理 | 无超时异常       | 存在已等待超 30 分钟异常    | 存在已等待超 60 分钟异常    |

### 8.3 作业漏斗

当前原型已由旧版“今日作业漏斗”调整为“作业漏斗”，并拆分为两个分组展示。

#### 9.3.1 模块结构

- 模块标题：`作业漏斗`
- 标题右侧保留问号提示，悬浮展示进度条口径说明
- 模块右上角新增 2 个按钮：`仓内作业跟踪`、`物流跟踪`
- 模块内部保留两个文字分组标题，不使用按钮样式

#### 9.3.2 仓内作业跟踪节点

| 节点    | 统计口径          | 展示要求                | 默认跳转       |
| ----- | ------------- | ------------------- | ---------- |
| 待入库   | 待收货入库单数量      | 展示数量、`N单超时处理`、三段进度条 | 入库单列表      |
| 待接单揽货 | 待领取或待派发履约作业数量 | 展示数量、渠道拆分、三段进度条     | 仓内作业跟踪明细列表 |
| 待揽货   | 待揽货作业数量       | 展示数量、渠道拆分、三段进度条     | 仓内作业跟踪明细列表 |
| 待打包复核 | 已完成拣货待复核数量    | 展示数量、渠道拆分、三段进度条     | 仓内作业跟踪明细列表 |
| 待发货   | 待出库确认或待交接发运数量 | 展示数量、渠道拆分、三段进度条     | 发货履约单列表    |

#### 9.3.3 物流跟踪节点

| 节点      | 统计口径             | 展示要求                     | 默认跳转       |
| ------- | ---------------- | ------------------------ | ---------- |
| 待接单     | 待承运方接单的履约任务数     | 展示数量、渠道拆分、三段进度条          | 物流跟踪明细列表 |
| 重新派单    | 需重新分配运力的履约任务数    | 展示数量、渠道拆分、三段进度条          | 物流跟踪明细列表 |
| 物流异常    | 派送过程中出现异常（如未找到客户）待人工处理的任务数 | 展示数量、渠道拆分、三段进度条          | 物流跟踪明细列表 |
| 已接单     | 骑手/承运商已接单待取货配送的履约任务数 | 展示数量、渠道拆分、三段进度条          | 物流跟踪明细列表 |
| 配送中     | 已出仓配送中的履约任务数     | 展示数量、渠道拆分、三段进度条          | 物流跟踪明细列表 |
| 当日已送达 | 当日已送达完成量         | 展示数量、渠道拆分、`N单配送异常`、绿色进度条 | 物流跟踪明细列表 |

#### 9.3.4 进度条规则

- 当前原型不再使用单一健康度条，改为三段式进度条。
- 红色：当前节点超时处理单量。
- 黄色：当前节点待处理单量。
- 灰色：当前分组待处理总量底座。
- 物流跟踪中仅 `待接单`、`重新派单`、`物流异常`、`已接单`、`配送中` 计入待处理总量。
- `当日已送达` 不计入待处理总量，改为单独绿色进度条展示。
- 问号提示浮层需明确上述口径，不再在模块底部单独占用说明区域。

### 8.4 库存风险 Top

该模块为完整需求模块，不是单一字段。

| 字段名称   | 字段类型 | 必填 | 说明                           |
| ------ | ---- | -- | ---------------------------- |
| 风险对象   | 文本   | 是  | 展示商品名称、SKU 或规格               |
| 风险标签   | 标签   | 是  | 当前驾驶舱使用 `低库存`、`高锁定占比` 两类主要标签 |
| 辅助说明   | 文本   | 是  | 展示库存、可售、锁定、仓库、阈值说明           |
| 查看库存预警 | 按钮   | 是  | 进入库存风险列表                     |
| 分页区    | 分页组件 | 是  | 默认展示 10 条，支持翻页               |

排序与展示规则：

- 默认按风险优先级和影响程度降序展示。
- 高风险低库存优先于一般风险。
- 高锁定占比按锁定影响程度排序。
- 当前 1.0 口径不展示临期、冻结、复核差异等旧版口径。
- 点击单条风险对象，跳转库存查询或库存明细并带入上下文。

### 8.5 超时 / 紧急待办

该模块为完整需求模块，不是单一字段。

| 字段名称   | 字段类型 | 必填 | 说明                      |
| ------ | ---- | -- | ----------------------- |
| 待办单号   | 文本   | 是  | 展示待处理单据编号               |
| 待办类型   | 标签   | 是  | 如待入库、待接单揽货、待揽货、待打包复核、待发货、待接单、重新派单 |
| 辅助说明   | 文本   | 是  | 展示仓库、渠道、等待时长；待入库不展示渠道 |
| 处理人    | 文本   | 否  | 展示当前处理人                 |
| 查看超时列表 | 按钮   | 是  | 进入超时/紧急列表               |
| 分页区    | 分页组件 | 是  | 默认展示 10 条，支持翻页          |

排序与展示规则：

- 待办类型与作业漏斗节点状态保持一致，仅展示：待入库、待接单揽货、待揽货、待打包复核、待发货、待接单、重新派单。
- 待办按等待时长倒序排序。
- 等待时长大于 60 分钟的卡片使用红色预警样式。
- 超过30分钟但未超过 60 分钟的卡片保留普通 / 黄色状态，不全部标红。
- 点击待办单号进入对应业务列表页或详情页。

## 9. 关键规则

- 驾驶舱默认展示当前权限范围内的数据，不得越权展示其他仓库数据。
- 页面为纯查看页，不提供新建、编辑、删除能力。
- 顶部核心指标卡只展示总览型结果指标，不展示与作业漏斗重复的流程节点指标。
- 作业漏斗按 `仓内作业跟踪` 与 `物流跟踪` 两个分组展示。
- 仓内作业跟踪与物流跟踪均支持点击节点进入各自明细列表。
- 作业漏斗卡片、库存风险卡片、待办卡片当前统一压缩为约 `100px` 高度，优先保证首屏信息密度。
- 作业漏斗进度条统一按当前三段口径展示，不表示流程完成率。
- `当日已送达` 单独使用绿色进度条展示，不计入履约待处理总量。
- 库存风险 Top 和超时 / 紧急待办是完整模块需求，包含列表、分页、排序、下钻和空态规则。
- 超时 / 紧急待办中超过 60 分钟的记录需红色预警。
- 简易需求文档通过生产可访问的静态 md 资源读取，不依赖本地 docs 路径。

## 10. 状态规则

| 状态   | 含义             | 规则                     |
| ---- | -------------- | ---------------------- |
| 正常   | 当前指标或模块处于可控状态  | 使用默认或绿色样式展示            |
| 预警   | 当前存在需关注问题      | 使用橙色标签或预警样式            |
| 严重   | 当前存在需优先处理问题    | 使用红色标签或严重样式            |
| 超时预警 | 待办等待时长超过 60 分钟 | 待办卡片边框、辅助说明、状态标签使用红色预警 |
| 空数据  | 当前筛选条件下无数据     | 模块展示空态                 |

## 12. 验收要点

- 能正常进入驾驶舱页面并看到 5 项核心指标卡、作业漏斗、库存风险 Top、超时 / 紧急待办 4 个核心区块。
- 顶部 5 个指标卡均展示名称、指标值、说明文案、状态标签，并支持点击下钻。
- 作业漏斗模块标题为 `作业漏斗`，右上角存在 `仓内作业跟踪`、`物流跟踪` 两个跳转按钮。
- 作业漏斗内部需展示两个文字分组标题：`仓内作业跟踪`、`物流跟踪`。
- 仓内作业跟踪展示 5 个节点：待入库、待接单揽货、待揽货、待打包复核、待发货。
- 物流跟踪展示 6 个节点：待接单、重新派单、物流异常、已接单、配送中、当日已送达。其中「物流异常」指物流在派送过程中因异常原因（如未找到客户）无法正常推进、需人工介入处理的状态。
- 作业漏斗除 `当日已送达` 外，其余节点进度条均按红 / 黄 / 灰三段展示。
- `当日已送达` 使用绿色进度条，文案展示 `N单配送异常`。
- 库存风险 Top 不再出现临期、冻结、复核差异等当前版本不做的口径。
- 超时 / 紧急待办按等待时长倒序展示，待办类型仅包含作业漏斗节点状态（待入库、待接单揽货、待揽货、待打包复核、待发货、待接单、重新派单）。
- 超过 60 分钟的待办卡片使用红色预警样式，未超过 60 分钟保留普通 / 黄色状态。
- 点击 `简易需求文档` 后，原型内能直接读取并展示生产可访问的 md 文档内容。

## 13. 前端 UI 规范

以下规范根据当前驾驶舱高保真原型（`WMS-WEB-036`）回写，用于前端实现与测试验收统一口径。

### 13.1 页面导航方式

| 操作 | 打开方式 |
| --- | --- |
| 点击核心指标卡 | 整页跳转到对应下钻页（库存查询 / 物流跟踪明细 / 库存风险列表 / 超时紧急列表） |
| 点击作业漏斗节点 | 整页跳转对应跟踪明细列表（仓内作业跟踪 / 物流跟踪），并带入当前节点类型作为默认筛选 |
| 模块级按钮（仓内作业跟踪 / 物流跟踪 / 查看超时列表 / 查看库存预警） | 整页跳转对应明细列表页 |
| 超时/紧急列表点击「查看详情」 | 右侧滑入抽屉（宽 `min(760px, 100vw)`），左侧列表保持可见（非全屏） |
| 切换仓库 / 渠道 | 顶栏全局下拉，切换后当前页数据即时重渲染 |
| 页面切换机制 | SPA 内容区重渲染，同时通过 `history.replaceState` 将地址同步为独立页 URL（`./{页面key}.html`），刷新后可直达 |

### 13.2 页面布局

- 顶部为驾驶舱总览区：5 个核心指标卡横向等分排列。
- 总览区下方为三列等分网格（列间距 14px）：作业漏斗、超时 / 紧急待办、库存风险 Top 三个面板。
- 每个面板最小高度 540px，内部按「面板头 / 列表区 / 分页条」三段布局；列表区在面板内部滚动，分页条固定于面板底部。
- 作业漏斗面板内分两个文字分组：仓内作业跟踪（5 节点）、物流跟踪（5 节点）。
- 漏斗节点卡、风险卡、待办卡统一压缩为约 100px 高度，保证首屏信息密度。

### 13.3 组件行为

- 核心指标卡：可下钻卡片悬停时上浮并加深阴影；卡片顶部以渐变色条标识状态（绿 / 橙 / 红）。
- 作业漏斗节点：整卡可点击（鼠标手型）；进度条悬停显示原生提示「超时 N 单 / 待处理 N 单 / 分组总量 N 单」。
- 作业漏斗标题右侧 `?` 图标：悬停或键盘聚焦时显示健康度说明气泡，移出后消失。
- 进度条为三段式：红色段（超时单量）压在黄色段（待处理单量）之上，灰色为分组总量底座；`已送达（当日）` 节点单独使用绿色进度条。
- 待办卡：等待时长超过 60 分钟时整卡切换红色预警样式；状态标签展示待办类型（与作业漏斗节点状态一致）。
- 超时/紧急列表：选中行使用浅橙色高亮，详情抽屉打开期间保持；查询 / 重置会先关闭已打开的抽屉再刷新列表。
- 详情抽屉：深色半透明遮罩 + 8px 背景模糊；点击遮罩空白处或右上角圆形关闭按钮关闭；底部「进入对应页面」按钮整页跳转到责任页面。
- 分页条：展示总条数、当前页码与页码切换按钮。

### 13.4 状态颜色

| 用途 | 颜色 |
| --- | --- |
| 主题色 / 成功 / 正常 | `#00ab95`，标签浅底 `rgba(0,171,149,0.12)` |
| 预警（橙） | `#c77c11`，标签浅底 `rgba(199,124,17,0.12)` |
| 严重 / 超时（红） | `#d92d20`，标签浅底 `rgba(217,45,32,0.12)` |
| 进度条-超时段 | 红色渐变 `#ff6b6b → #ff9f9f` |
| 进度条-待处理段 | 黄色渐变 `#f0b44c → #ffd48a` |
| 进度条-总量底座 | 灰色 `rgba(29,29,31,0.10)` |
| 进度条-已送达（绿） | 渐变 `#00ab95 → #4bcebe` |
| 超时待办卡 / 严重风险卡 | 边框 `rgba(217,45,32,0.16)`、背景 `rgba(217,45,32,0.04)`，辅助说明文字红色 |
| 页面基础色 | 文字 `#1d1d1f`、背景 `#f5f5f7`、白色卡片浅投影 |

状态标签（status-pill）统一为胶囊形（圆角 999px）、浅色底 + 同色系深色文字，不使用实底色块。

### 13.5 操作反馈

- 可下钻指标卡与按钮悬停均有即时视觉反馈：卡片上浮加深阴影、幽灵按钮背景变纯白。
- 抽屉关闭按钮悬停上浮并加深阴影，点击后抽屉立即关闭、列表选中态清除。
- 查询 / 重置：即时重渲染列表；重置同时清空选中行与筛选条件。
- 切换仓库 / 渠道后所有模块数据同步刷新，无需手动刷新页面。
- 列表空态：展示「当前筛选条件下暂无超时/紧急待办」文案，保留查询条件，不展示异常样式。
- 导出列表在当前原型中为占位操作，无实际下载；接入接口后需补充导出成功 / 失败 Toast 反馈。
- 当前原型不使用 alert / 阻断式弹窗，所有反馈均为页面内样式变化。

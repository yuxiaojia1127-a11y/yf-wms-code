# 商品接口上下架简易需求

## 1. 基本信息

| 属性     | 内容                   |
| ------ | -------------------- |
| 功能名称   | 商品接口上下架              |
| 所属系统   | WMS\_WEB端            |
| 所属模块   | 商品管理                 |
| 关联模块   | 入库管理 / 出库管理 / 库存中心  |
| 文档版本   | v1.0                 |
| 文档日期   | 2026-06-09           |

---

## 2. 背景与目标

WMS 系统需在可售库存发生关键变化时，自动调用电商系统的商品上下架状态接口，保证线上商品的销售状态与实际库存同步，避免超卖或虚假下架。

**核心规则：**

- 可售库存 = 0 时 → 自动调用接口，将商品状态置为**已下架**
- 可售库存由 0 变为 > 0 时（入库上架 / 退货解冻）→ 自动调用接口，将商品状态置为**已上架**

---

## 3. 触发场景

| 触发场景         | 库存变化方向     | 上下架动作 |
| ------------ | ---------- | ----- |
| 入库上架（收货入库）   | 可售库存 0 → N | 上架    |
| 客户退货解冻库存     | 可售库存 0 → N | 上架    |
| 出库发货（可售库存耗尽） | 可售库存 N → 0 | 下架    |
| 库存调整（可售库存归零） | 可售库存 N → 0 | 下架    |
| 库存冻结（可售库存归零） | 可售库存 N → 0 | 下架    |

> 注：仅在可售库存**跨越 0 值临界点**时触发接口调用，非每次库存变动都调用。

---

## 4. 接口调用逻辑

```
库存变动事件发生
  ↓
计算该 SKU 最新可售库存
  ↓
可售库存 == 0？
  ├── 是 → 调用电商接口：下架（SKU）
  └── 否 → 上次可售库存是否为 0？
              ├── 是 → 调用电商接口：上架（SKU）
              └── 否 → 不触发接口（无需变更状态）
  ↓
记录接口调用日志（无论成功/失败）
```

---

## 5. 日志查询功能

### 5.1 功能定位

提供**商品接口上下架日志**查询页面，供运营/仓管人员追溯每一次接口调用的来源、结果及SKU上下架明细。

### 5.2 查询条件

| 字段名称  | 字段类型   | 说明                                    |
| ----- | ------ | ------------------------------------- |
| 所属分类  | 下拉单选   | 商品分类树，支持选择叶子分类或父分类                    |
| SKU编码 | 输入框    | 精确或模糊搜索                               |
| 上下架动作 | 下拉单选   | 全部 / 上架 / 下架                          |
| 触发事件  | 下拉单选   | 入库上架 / 退货解冻 / 出库发货 / 库存调整 / 库存冻结 |
| 调用结果  | 下拉单选   | 全部 / 成功 / 失败                          |
| 触发时间  | 日期范围选择 | 默认近7天                                 |

### 5.3 列表字段

| 列名      | 说明                              |
| ------- | ------------------------------- |
| 触发时间    | 接口调用触发的时间，精确到秒                   |
| SKU编码   | 触发上下架的 SKU 编码                   |
| SKU名称   | 商品名称                            |
| 所属分类    | 商品所属分类名称                         |
| 上下架动作   | 上架 / 下架                         |
| 触发事件    | 导致上下架的业务事件（如：退货解冻、出库发货等）         |
| 关联单据号   | 触发事件对应的业务单据号（入库单号/出库单号/调整单号）     |
| 触发前可售库存 | 接口调用前的可售库存数量                     |
| 触发后可售库存 | 接口调用后的可售库存数量                     |
| 调用结果    | 成功 / 失败                         |
| 失败原因    | 调用失败时展示返回的错误信息                   |
| 操作      | 【查看详情】                          |

### 5.4 详情弹窗

点击【查看详情】展示完整调用报文，字段包括：

- SKU编码、SKU名称、所属分类
- 请求时间、请求地址
- 请求参数（JSON）
- 响应状态码、响应内容（JSON）
- 重试次数（如有重试机制）

---

## 6. 异常处理

| 场景           | 处理策略                            |
| ------------ | ------------------------------- |
| 接口调用失败       | 记录失败日志，触发重试（建议最多重试3次，间隔递增）      |
| 重试仍失败        | 日志标记为最终失败，触发告警通知（钉钉/邮件，具体方式待定） |
| 短时间内同一SKU频繁触发 | 合并同向操作，避免重复调用（如1分钟内多次归零仅调用1次下架） |
| 电商系统无此SKU    | 忽略该次调用，日志记录"SKU不存在于电商系统"         |

## 7. 权限

| 角色  | 权限         |
| --- | ---------- |
| 管理员 | 可查全部日志     |
| 仓管员 | 只读，可查日志    |

---

## 8. 非功能需求

- 接口调用超时时间：建议 ≤ 5秒，超时视为失败进入重试
- 日志保留周期：≥ 180天
- 日志支持导出（Excel）

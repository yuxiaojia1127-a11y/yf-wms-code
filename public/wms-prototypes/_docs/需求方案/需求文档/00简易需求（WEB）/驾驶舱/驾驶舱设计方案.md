## 2. 方案结论

WMS 1.0 只做自营版，本次驾驶舱只做最重要的管理总览能力。

驾驶舱定位为：

```text
面向自营仓储管理角色的一屏作业总览、库存风险预警与异常待办入口。
```

本版只做一个 `总览驾驶舱` 页面，不拆多个专题驾驶舱，不承接复杂经营 BI，不做大屏化展示；核心目标是让仓库管理者打开首页后，快速判断今天仓库是否正常、风险在哪里、堵点在哪里、该先处理什么。

## 3. 设计目标

默认页面需在 10 秒内回答以下 4 个问题：

1. 今天仓库整体是否正常。
2. 当前库存是否存在必须处理的风险。
3. 入库、出库、履约链路卡在哪个环节。
4. 哪些异常和待办需要立即处理。

## 4. 适用范围

### 4.1 本次纳入

| 业务域  | 1.0 驾驶舱承接内容               |
| ---- | ------------------------- |
| 库存中心 | 库存预警、可用库存、锁定库存、临期/过期、冻结风险 |
| 入库中心 | 待收货、待上架、入库异常、预约/处理超时      |
| 出库中心 | 待拣货、待复核、待出库、出库异常          |
| 履约中心 | 待拣货、待复核、待发运、履约超时          |
| 异常中心 | 待处理异常、超时异常、待关闭工单          |
| 仓储基础 | 仓库、库区、货位、商品资料作为筛选和下钻依据    |

### 4.2 本次不纳入

| 不纳入项              | 说明                 |
| ----------------- | ------------------ |
| 多主体经营分析           | 1.0 只做自营版          |
| 多专题驾驶舱            | 首版只保留一个总览页         |
| 复杂 BI 自定义报表       | 不属于管理端高频需求         |
| 大屏电视化展示           | 与当前 Web 管理端产品形态不符  |
| 调拨、售后、加工、库内转移专题看板 | 非 1.0 核心监控项        |
| 物流全链路分析           | 首版只保留发运异常摘要，深度轨迹后置 |
| 结算与费用分析           | 不属于首版核心仓内问题        |
| 自动补货预测、人效排行、排班排产  | 属于后续增强能力           |

## 5. 信息架构

### 5.1 导航建议

建议将现有 `工作台` 重命名或升级为一级导航 `驾驶舱`。

| 页面ID        | 页面名称  | 页面目标                     | 使用角色        | 优先级 |
| ----------- | ----- | ------------------------ | ----------- | --- |
| WMS-WEB-036 | 总览驾驶舱 | 汇总库存风险、入库进度、出库/履约进度、异常待办 | 系统管理类、仓内管理类 | P0  |

1.0 不新增 `库存驾驶舱`、`作业驾驶舱`、`异常驾驶舱` 等独立页面。

### 5.2 页面结构

总览驾驶舱从上到下分为 5 层：

| 层级 | 内容           | 目的                 |
| -- | ------------ | ------------------ |
| 1  | 标题、更新时间、手动刷新 | 明确数据时效             |
| 2  | 筛选栏          | 统一仓库、店铺/渠道、时间和履约模式 |
| 3  | 核心指标卡        | 快速判断今天是否异常         |
| 4  | 作业漏斗与风险区     | 定位入库、出库、履约堵点和库存风险  |
| 5  | 异常待办与快捷下钻    | 将看板转化为处理动作         |

建议布局如下：

```text
驾驶舱标题 / 更新时间 / 刷新
筛选：仓库、店铺/渠道、履约模式、时间范围、异常等级

核心指标卡：库存预警、可用库存、锁定占比、待收货、待上架、待拣货、待复核、待发运、履约及时率、异常待处理

左：今日作业漏斗
右：库存风险 Top 10 / 超时任务 Top 10

底部：异常待办列表 / 快捷入口
```

## 6. 指标体系设计

### 6.1 指标分层

| 层级   | 用途              | 示例                     |
| ---- | --------------- | ---------------------- |
| 核心指标 | 首页默认展示，快速判断是否正常 | 库存预警、待收货、待拣货、待复核、异常待处理 |
| 诊断指标 | 解释核心指标为什么异常     | 临期批次、冻结超时、入库超时、履约超时    |
| 下钻指标 | 支撑进入业务列表处理      | 风险 SKU、超时入库单、超时履约单、异常单 |

### 6.2 核心指标卡

| 指标     | 口径                    | 默认维度       | 下钻页面                   |
| ------ | --------------------- | ---------- | ---------------------- |
| 库存预警数  | 低库存、临期、过期、冻结等未关闭预警数   | 仓库、SKU     | `WMS-WEB-015` 冻结记录与预警页 |
| 可用库存总量 | `available` 汇总        | 仓库         | `WMS-WEB-012` 库存汇总列表   |
| 锁定库存占比 | `locked / physical`   | 仓库         | `WMS-WEB-013` 库存明细列表   |
| 待收货入库单 | 入库单处于待受理、处理中，且收货节点未完成 | 仓库、入库类型    | `WMS-WEB-010` 入库单列表    |
| 待上架任务数 | 已收货但上架节点未完成的任务数       | 仓库         | `WMS-WEB-011` 入库单详情    |
| 待拣货单数  | 履约单或出库单处于待备货/待拣货的数量   | 仓库、履约模式    | `WMS-WEB-020` 履约执行跟踪页  |
| 待复核单数  | 备货完成后待复核的单据数          | 仓库         | `WMS-WEB-020` 履约执行跟踪页  |
| 待发运单数  | 复核通过后待出库确认或待发运交接的单据数  | 仓库、履约模式    | `WMS-WEB-018` 发货履约单列表  |
| 履约及时率  | SLA 内完成的履约单 / 应完成履约单  | 仓库、履约模式、时间 | `WMS-WEB-018` 发货履约单列表  |
| 异常待处理数 | 未关闭的仓内、履约、库存异常数       | 仓库、异常类型    | `WMS-WEB-032` 异常列表     |

### 6.3 库存风险指标

| 指标            | 口径                        | 展示方式         |
| ------------- | ------------------------- | ------------ |
| 临期批次数         | 距到期日小于配置阈值的批次数            | 风险卡 + Top 列表 |
| 过期批次数         | 当前日期大于到期日的批次数             | 红色严重         |
| 低库存 SKU 数     | available 低于安全库存阈值的 SKU 数 | 橙色预警         |
| 冻结超时数         | 冻结时长超过处理 SLA 的记录数         | 红色严重         |
| 高锁定 SKU 数     | 锁定占比超过阈值的 SKU 数           | 橙色预警         |
| 风险 SKU Top 10 | 按临期、过期、低库存、冻结数量排序         | 列表下钻         |

### 6.4 作业履约指标

| 链路 | 指标                  | 口径             |
| -- | ------------------- | -------------- |
| 入库 | 待收货、收货中、待上架、入库异常    | 按入库单主状态和执行节点统计 |
| 出库 | 待备货、备货中、待复核、待出库、异常单 | 按出库单主状态和执行节点统计 |
| 履约 | 待受理、备货中、出库中、已发运、异常  | 按发货履约单主状态统计    |

建议用一条作业漏斗展示：

```text
待收货 -> 待上架 -> 待拣货 -> 待复核 -> 待发运 -> 已发运
```

### 6.5 异常待办指标

| 指标     | 口径                    | 下钻页面                  |
| ------ | --------------------- | --------------------- |
| 待处理异常数 | 异常状态未关闭的数量            | `WMS-WEB-032` 异常列表    |
| 超时异常数  | 超过处理 SLA 仍未关闭的异常数     | `WMS-WEB-032` 异常列表    |
| 入库异常数  | 入库存在差异或处理异常的单据数       | `WMS-WEB-010` 入库单列表   |
| 出库异常数  | 出库过程中发生缺货、批次不符等问题的单据数 | `WMS-WEB-016` 出库单列表   |
| 履约异常数  | 履约过程中发生拦截、失败或中断的单据数   | `WMS-WEB-018` 发货履约单列表 |
| 接口失败摘要 | 影响入库、出库、履约状态同步的接口失败数量 | 异常中心或回调日志             |

## 7. 筛选与交互设计

### 7.1 全局筛选

| 筛选项     | 说明                     | 默认值    |
| ------- | ---------------------- | ------ |
| 仓库      | 库存和作业核心维度              | 全部授权仓库 |
| 店铺 / 渠道 | 自营履约来源筛选，仅影响履约相关指标     | 全部     |
| 履约模式    | 即时配送、快递配送              | 全部     |
| 时间范围    | 今日、昨日、近 7 日、近 30 日、自定义 | 今日     |
| 异常等级    | 普通、预警、严重               | 全部     |

### 7.2 下钻规则

| 触发                | 行为                                           |
| ----------------- | -------------------------------------------- |
| 点击库存预警            | 跳转冻结记录与预警页，并带入预警状态                           |
| 点击可用库存            | 跳转库存汇总列表，并带入当前仓库                             |
| 点击风险 SKU          | 跳转库存明细，带入 `warehouse_id + sku_id + batch_no` |
| 点击待收货 / 待上架       | 跳转入库单列表或详情，并带入执行节点                           |
| 点击待拣货 / 待复核 / 待发运 | 跳转履约执行跟踪或发货履约单列表                             |
| 点击异常待办            | 跳转异常列表，并带入异常类型和处理状态                          |
| 点击趋势点             | 打开当天明细列表或抽屉                                  |

### 7.3 页面状态

| 状态      | 展示方式                 |
| ------- | -------------------- |
| 加载中     | 骨架屏，保留筛选栏            |
| 无数据     | 当前筛选条件下展示空态，提供重置筛选   |
| 无权限     | 页面或模块级无权限提示          |
| 数据延迟    | 指标卡展示“数据延迟”，保留上次成功时间 |
| 部分指标失败  | 失败模块独立提示，不影响其他模块     |
| 数据口径待配置 | 展示缺少阈值或 SLA 配置提示     |

### 7.4 视觉与组件建议

| 项目   | 建议                       |
| ---- | ------------------------ |
| 页面框架 | 左侧导航 + 顶部上下文 + 主内容区      |
| 视觉风格 | 浅灰背景、白色卡片、青绿色主色          |
| 指标卡  | 卡片化展示，支持状态色、环比、更新时间      |
| 风险表达 | 橙色预警、红色严重、青绿色正常          |
| 图表   | 优先折线、柱状、漏斗、排行，不做装饰性大屏图   |
| 信息密度 | 管理后台密度，避免营销式 hero 和过度视觉化 |

## 8. 数据与接口方案

### 8.1 现有接口复用

| 领域 | 现有接口                                                                     |
| -- | ------------------------------------------------------------------------ |
| 入库 | `/openapi/v1/inbounds`                                                   |
| 库存 | `/openapi/v1/inventory/summary`、`/details`、`/batches`、`/holds`、`/alerts` |
| 出库 | `/openapi/v1/stockouts`                                                  |
| 履约 | `/openapi/v1/shipments`、`/picking-result`、`/shipping-result`             |
| 异常 | `/openapi/v1/exceptions`、`/openapi/v1/tickets`                           |

驾驶舱高频访问时不建议前端并发拉取所有列表再聚合，首版建议新增一个服务端聚合接口。

### 8.2 新增接口

| 接口                                 | 用途                         | 优先级 |
| ---------------------------------- | -------------------------- | --- |
| `GET /openapi/v1/cockpit/overview` | 总览驾驶舱核心指标、作业漏斗、风险 SKU、异常待办 | P0  |

### 8.3 通用请求参数

| 参数                 | 类型        | 说明                                                        |
| ------------------ | --------- | --------------------------------------------------------- |
| `warehouse_ids`    | string\[] | 仓库范围                                                      |
| `store_ids`        | string\[] | 店铺/渠道范围，仅履约相关指标使用                                         |
| `fulfillment_mode` | string    | `INSTANT` / `EXPRESS` / `ALL`                             |
| `time_range`       | string    | `TODAY` / `YESTERDAY` / `LAST_7D` / `LAST_30D` / `CUSTOM` |
| `start_time`       | datetime  | 自定义开始时间                                                   |
| `end_time`         | datetime  | 自定义结束时间                                                   |

### 8.4 通用响应结构

```json
{
  "freshness": {
    "generated_at": "2026-06-03 10:30:00",
    "data_delay_seconds": 30,
    "partial_failed": false
  },
  "scope": {
    "warehouse_ids": ["WH-001"],
    "time_range": "TODAY"
  },
  "cards": [],
  "operation_funnel": [],
  "inventory_risks": [],
  "exception_todos": []
}
```

### 8.5 刷新建议

| 指标类型 | 刷新建议              |
| ---- | ----------------- |
| 作业待办 | 近实时，30 秒到 1 分钟刷新  |
| 库存风险 | 1 到 5 分钟刷新，展示更新时间 |
| 趋势统计 | 5 到 15 分钟刷新，可缓存   |
| 异常待办 | 近实时，异常优先          |

## 9. 权限与安全

| 规则     | 说明                    |
| ------ | --------------------- |
| 继承现有权限 | 驾驶舱不得绕过现有仓库、店铺、模块授权   |
| 仓库隔离   | 仓内角色只能看到授权仓库          |
| 模块裁剪   | 无异常中心权限时，不展示异常下钻      |
| 敏感字段隐藏 | 首版不展示人效排行和责任归因敏感信息    |
| 审计留痕   | 手动刷新、导出、查看敏感异常可进入审计日志 |

## 10. 本期交付范围

### 10.1 首版范围

目标：管理者打开首页即可知道今天仓库是否正常，并能快速处理风险。

范围：

- `WMS-WEB-036 总览驾驶舱`
- 库存风险基础模块
- 入库、出库、履约作业漏斗
- 异常待办和快捷下钻
- `GET /openapi/v1/cockpit/overview` 聚合接口

优先指标：

- 库存预警数
- 可用库存总量
- 锁定库存占比
- 待收货入库单
- 待上架任务数
- 待拣货单数
- 待复核单数
- 待发运单数
- 履约及时率
- 异常待处理数

### 10.2 后续增强

后续版本再考虑：

- 物流轨迹、签收率、面单与承运商异常
- 调拨进度与调拨超期
- 退货质检与售后回库
- 加工、库内转移、盘点专题统计
- 安全库存和补货建议
- 人员或作业组效率
- 成本和账单趋势

## 11. 验收标准

| 类别    | 验收标准                         |
| ----- | ---------------------------- |
| 页面可用  | 默认进入驾驶舱后，核心指标、作业漏斗、风险和待办正常展示 |
| 数据可信  | 每个指标有口径、更新时间、数据范围和异常态        |
| 权限正确  | 不同管理角色看到的数据范围符合仓库和模块权限       |
| 下钻有效  | 核心指标点击后能进入对应页面并带入筛选条件        |
| 异常可控  | 某一指标接口失败时，不影响其他模块展示          |
| 性能可接受 | 首屏加载建议不超过 3 秒                |
| 口径统一  | 状态名称与 `WMS_WEB端状态口径总表` 保持一致  |

## 12. 风险与待确认

| 风险 / 待确认             | 影响          | 建议                           |
| -------------------- | ----------- | ---------------------------- |
| SLA 阈值未定义            | 无法判断超时和及时率  | 先按业务默认阈值配置，后续参数化             |
| 现有接口偏列表查询            | 驾驶舱并发聚合成本高  | 1.0 新增单一 `overview` 聚合接口     |
| 可用库存、锁定库存、可售库存口径容易混淆 | 页面数字容易被误读   | 首版优先展示 WMS 事实库存口径，可售库存后续单独说明 |
| 异常中心页面优先级较后          | 首版下钻可能不足    | 先跳转异常列表占位，后续补齐工单闭环           |
| 旧工作台是否保留             | 导航和用户习惯需要迁移 | 建议旧工作台重定向到总览驾驶舱              |

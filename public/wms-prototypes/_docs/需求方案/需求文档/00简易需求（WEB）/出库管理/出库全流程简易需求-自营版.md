# 出库全流程简易需求（自营版）

## 1. 基本信息

- 功能名称：出库管理
- 所属系统：WMS\_WEB端 / WMS\_APP端
- 页面编号：`WMS-WEB-OUT01`
- 所属模块：出库管理
- 文档定位：自营业务版
- 适用范围：销售出库、调拨出库、报损出库、其他出库、揽货接单、库存锁定、揽货、复核、打包、发货、出库差异与出库流水

## 2. 核心结论

### 2.1 WMS管理对象

| 对象   | 主键/编码       | 管理口径   | 作用                         |
| ---- | ----------- | ------ | -------------------------- |
| 出库单  | 出库单号        | 出库业务主单 | 承接销售、调拨、报损等出库来源            |
| 出库明细 | 出库单号 + SKU  | 出库商品明细 | 记录应出数量、锁定数量、揽货数量、复核数量、发货数量 |
| 揽货接单 | 揽货接单号       | 出库接单作业 | 出库指令下发后由揽货人员接单，并记录接单人和接单时间 |
| 库存锁定 | 锁定单号        | 出库库存占用 | 出库前锁定可用库存，防止重复占用           |
| 揽货任务 | 揽货任务号       | 仓内揽货作业 | 按SKU、库位、批次、效期、SN执行揽货       |
| 复核任务 | 复核任务号       | 出库校验作业 | 校验揽货商品、数量、批次、SN和包裹         |
| 发货任务 | 发货任务号       | 出库交接作业 | 处理打包、称重、面单、交接和发货确认         |
| 出库差异 | 差异单号        | 出库异常记录 | 记录缺货、错揽、破损、复核不符等异常         |
| 出库流水 | 出库单号 + 库存动作 | 库存扣减记录 | 记录库存锁定、释放、扣减和出库完成动作        |

### 2.2 核心规则

1. 自营出库类型包括销售出库、调拨出库、报损出库和其他出库。
2. 出库单是出库业务主对象，揽货接单、库存锁定、揽货、复核、发货围绕出库单执行。
3. 销售出库来源于上游销售订单或发货指令。
4. 调拨出库来源于仓间调拨单。
5. 报损出库来源于库存报损单或异常处理单。
6. 出库指令下发后先进入待接单池，由揽货人员手动接单。
7. 第一阶段采用手动接单模式，未来支持系统自动派单。
8. 出库前必须完成库存锁定。
9. 揽货按SKU、仓库、库位、批次、效期和SN执行。
10. 复核通过后进入打包和发货。
11. 发货完成后扣减实物库存和锁定库存，并生成库存流水。
12. 出库差异必须记录异常类型、异常数量、原因和处理结果。

## 3. 业务目标

出库管理用于处理自营业务商品离开仓库的全流程，包括出库单创建、揽货接单、库存锁定、揽货、复核、打包、发货、库存扣减、差异登记和出库记录追溯。

系统通过出库单、揽货接单、揽货任务、复核任务、发货任务、出库差异和出库流水，保证销售、调拨、报损等出库业务的实物、单据和库存一致。

## 6. 状态流程

### 6.1 出库单状态

| 状态  | 含义               | 规则            |
| --- | ---------------- | ------------- |
| 草稿  | 已创建未确认           | 可编辑、可取消       |
| 待接单 | 出库指令已下发，等待揽货人员接单 | 可由揽货人员手动接单    |
| 已接单 | 揽货人员已接单，等待库存锁定   | 记录接单人和接单时间    |
| 待锁定 | 出库单已接单，等待库存锁定    | 可执行库存锁定       |
| 已锁定 | 库存锁定成功，等待揽货      | 可生成揽货任务       |
| 揽货中 | 正在执行揽货           | 可继续揽货、登记差异    |
| 待复核 | 揽货完成，等待复核        | 可执行复核         |
| 复核中 | 正在执行复核           | 可继续复核、登记差异    |
| 待发货 | 复核完成，等待打包发货      | 可执行打包、称重、发货   |
| 发货中 | 正在交接或发货          | 可继续发货确认       |
| 已完成 | 全部出库并完成库存扣减      | 可查看、导出、追溯     |
| 已取消 | 出库单终止            | 释放锁定库存并保留历史记录 |
| 异常  | 存在差异或阻断问题        | 进入异常处理        |

### 6.2 接单状态

| 状态   | 含义                 |
| ---- | ------------------ |
| 待接单  | 出库指令已下发，尚未有人承接     |
| 已接单  | 揽货人员已承接任务          |
| 揽货中  | 揽货人员已开始处理出库任务      |
| 已揽货  | 揽货人员已完成揽货确认        |
| 已释放  | 原接单关系已释放，可重新接单     |
| 接单异常 | 接单后超时、人员不可用或任务无法继续 |

### 6.3 揽货状态

| 状态   | 含义              |
| ---- | --------------- |
| 未揽货  | 尚未生成或执行揽货       |
| 部分揽货 | 部分明细已揽货         |
| 已揽货  | 全部可揽数量完成揽货      |
| 揽货异常 | 存在缺货、错揽、库位异常等问题 |

### 6.4 复核状态

| 状态   | 含义              |
| ---- | --------------- |
| 未复核  | 尚未执行复核          |
| 复核中  | 正在复核            |
| 复核通过 | 商品、数量、批次、SN校验通过 |
| 复核异常 | 复核结果与揽货或出库明细不一致 |

### 6.5 发货状态

| 状态   | 含义                |
| ---- | ----------------- |
| 未发货  | 尚未进入发货            |
| 待打包  | 复核通过，等待打包         |
| 待交接  | 包裹已完成，等待物流或交接     |
| 已发货  | 完成发货确认并扣减库存       |
| 发货异常 | 包裹、面单、物流交接或库存扣减异常 |

## 7. 关键流程

### 7.1 销售出库流程

1. 上游销售订单或发货指令进入WMS并生成销售出库单。
2. 系统校验SKU、仓库、库存可用量、批次效期和出库数量。
3. 出库指令下发后进入待接单池。
4. 揽货人员手动接单，系统记录接单人和接单时间。
5. 系统按SKU、仓库、库位、批次和效期锁定库存。
6. 锁定成功后生成揽货任务。
7. 揽货人员按任务扫描库位、SKU、批次和SN完成揽货。
8. 复核员扫描商品、批次、SN和包裹执行复核。
9. 发货员完成打包、称重、面单、交接和发货确认。
10. 发货完成后扣减实物库存和锁定库存，并生成出库流水。

### 7.2 调拨出库流程

1. 调拨单确认后生成调拨出库单。
2. 出库任务进入待接单池，由揽货人员手动接单。
3. 系统按调出仓库存锁定SKU、批次和库位。
4. 仓内完成揽货、复核和交接。
5. 发出确认后扣减调出仓库存。
6. 系统生成调拨出库流水，并推动调入仓形成调拨入库预期。

### 7.3 报损出库流程

1. 报损单或异常处理单确认后生成报损出库单。
2. 出库任务进入待接单池，由揽货人员手动接单。
3. 系统锁定报损库存，通常来源于次品、冻结、过期或待处理库存。
4. 仓内按报损任务执行揽货和复核。
5. 报损确认后扣减库存并生成报损出库流水。
6. 系统保留报损原因、审批记录和出库凭证。

### 7.4 揽货接单流程

1. 出库指令下发后，系统生成揽货接单并进入待接单池。
2. 揽货人员在待接单池查看任务，按仓库、优先级、出库类型、SKU数量和时效要求选择接单。
3. 系统校验任务是否仍处于待接单状态，避免多人重复接单。
4. 接单成功后，系统绑定揽货人员、接单时间和任务状态。
5. 接单成功后，出库任务进入待锁定状态。
6. 库存锁定成功后，揽货人员确认开始揽货，系统记录开始时间。
7. 揽货完成后，任务进入复核流转。
8. 仓库管理员可对未完成任务执行释放接单、转派或异常处理。

### 7.5 揽货流程

1. 系统根据锁定库存生成揽货任务。
2. 揽货任务包含SKU、商品名称、批次、效期、库位、应揽数量和特殊提示。
3. 揽货员扫描目标库位和商品条码。
4. 系统校验SKU、批次、效期、SN和数量。
5. 揽货完成后更新揽货状态并流转到复核。

### 7.6 复核与打包流程

1. 复核员扫描出库单、揽货容器、商品条码或包裹。
2. 系统校验SKU、数量、批次、效期、SN和包裹明细。
3. 复核通过后生成或确认包裹。
4. 打包时记录包裹重量、体积、包装材料和面单信息。
5. 包裹完成后进入待交接或待发货状态。

### 7.7 出库差异处理流程

1. 揽货、复核、打包或发货环节发现异常。
2. 系统登记差异类型、差异数量、差异原因、照片或附件。
3. 仓库管理员处理差异，选择补揽、换货位、释放库存、取消明细、关闭差异等处理结果。
4. 差异处理完成后更新出库单状态和库存结果。

## 9. 规则要求

### 9.1 出库单规则

- 出库单号全局唯一。
- 来源单号和出库类型组成幂等校验口径。
- 草稿状态可编辑，已进入揽货后保留原始单据快照。
- 已完成出库单不可编辑业务明细。
- 已取消出库单不参与锁定、揽货、复核和发货。

### 9.2 揽货接单规则

- 出库指令下发后，出库任务进入待接单池。
- 第一阶段采用揽货人员手动接单模式。
- 同一出库任务同一时间只允许一个有效接单人。
- 接单成功后必须记录揽货人员、接单时间、任务来源和操作日志。
- 接单是作业分配动作，不替代库存锁定和库存扣减。
- 接单后未开始或长时间未完成的任务，应支持仓库管理员释放、转派或标记异常。
- 未来支持系统自动派单，可按仓库、人员班次、人员负荷、任务优先级和出库时效自动分配。

### 9.3 库存锁定规则

- 出库前必须先锁定库存。
- 锁定库存时校验SKU、仓库、批次、效期、库存状态、库位和可用数量。
- 锁定成功后减少可用库存，增加锁定库存。
- 取消出库或明细取消时释放锁定库存。
- 锁定库存不得超过可用库存。

### 9.4 揽货规则

- 揽货任务基于锁定库存生成。
- 揽货时必须校验库位、SKU、条码、批次、效期、SN和数量。
- 揽货数量不得超过锁定数量。
- 揽货异常需登记差异。
- 揽货完成后流转到复核。

### 9.5 复核规则

- 复核时必须校验SKU、数量、批次、效期、SN和包裹明细。
- 复核通过数量不得超过揽货数量。
- 复核异常需登记差异。
- 复核通过后进入打包或发货流程。

### 9.6 发货与库存扣减规则

- 发货确认前必须完成复核。
- 发货确认后扣减实物库存和锁定库存。
- 出库扣减后不得出现负库存。
- 发货完成后生成出库流水。
- 销售出库可记录物流单号、承运商和包裹信息。

## 10. 异常场景处理

| 异常场景      | 系统处理                         |
| --------- | ---------------------------- |
| 出库单重复     | 按来源单号和出库类型进行幂等处理             |
| SKU不存在或停用 | 阻断出库确认并提示商品异常                |
| 无人接单      | 保留在待接单池，并支持按超时时间提醒仓库管理员      |
| 重复接单      | 系统只保留最先成功接单记录，后续接单请求提示任务已被承接 |
| 接单后人员不可用  | 仓库管理员释放接单或转派给其他揽货人员          |
| 接单后超时未揽货  | 标记接单异常，并进入异常处理或转派流程          |
| 可用库存不足    | 阻断库存锁定并提示库存不足                |
| 批次不满足     | 阻断锁定或揽货并提示批次异常               |
| 效期禁售或过期   | 阻断销售出库并提示效期异常                |
| SN重复或不存在  | 阻断揽货或复核并提示SN异常               |
| 库位停用或锁定   | 阻断揽货并提示更换库位                  |
| 揽货缺货      | 生成缺货差异并进入异常处理                |
| 错揽        | 生成错揽差异并进入异常处理                |
| 复核不符      | 生成复核差异并进入异常处理                |
| 发货失败      | 进入发货异常并保留包裹和库存锁定状态           |
| 库存流水生成失败  | 回滚本次出库动作并进入系统异常队列            |

## 11. 验收要点

- 能按出库类型、出库状态、接单状态、揽货状态、复核状态、发货状态、仓库、揽货人员、出库单号、来源单号、SKU编码、商品名称、条码完成查询。
- 能新建、查看、编辑、确认、取消出库单。
- 能执行销售出库、调拨出库、报损出库。
- 出库指令下发后能进入待接单池。
- 揽货人员能手动接单，系统能记录接单人、接单时间和接单状态。
- 同一出库任务不允许多人同时有效接单。
- 仓库管理员能释放接单、转派任务和处理接单异常。
- 出库前能完成库存锁定，锁定数量不超过可用库存。
- 能基于锁定库存生成揽货任务。
- 揽货时能校验库位、SKU、条码、批次、效期、SN和数量。
- 复核时能校验SKU、数量、批次、效期、SN和包裹明细。
- 能维护包裹、重量、体积、面单和物流信息。
- 发货确认后能扣减实物库存和锁定库存。
- 出库扣减后不允许出现负库存。
- 缺货、错揽、破损、复核不符等差异能生成差异记录并进入异常处理。
- 出库单详情可查看接单、锁定、揽货、复核、发货、差异和库存流水。

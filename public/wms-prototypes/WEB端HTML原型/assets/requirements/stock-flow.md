# WMS-WEB 出入库流水简易需求文档

## 1. 基础信息

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 出入库流水 |
| 所属模块 | 库存中心 |
| 页面定位 | 以库存变动事件为主视角的出入库流水查询页，记录每次库存增减及变动时当下余额快照 |
| 页面编码 | `WMS-WEB-014` |
| 适用端 | WMS-WEB 管理端 |

---

## 2. 业务说明

出入库流水用于记录和查询每一次库存数量发生变动时的完整明细，包括变动类型（入库 / 出库）、来源单据、变动数量、**变动前库存**和**变动后库存**（含**变动前可用**和**变动后可用**），形成库存账本视角的流水台账。

与现有功能的定位关系如下：

| 页面 | 主视角 | 核心关注 |
| ---- | ---- | ---- |
| 库存查询（WMS-WEB-012） | SKU + 仓库 | 当前库存汇总量 |
| 库存明细列表（WMS-WEB-013） | 仓库 + 库区 + 货位 | 货位级当前库存状态 |
| **出入库流水（WMS-WEB-014）** | **库存变动事件** | **每次变动的时间、数量、变动前后余额** |

本页面不承载任何库存控制动作，仅提供查询与导出。

---

## 3. 流水生成规则

每次库存数量发生真实变动时，系统自动生成一条流水记录，不可人工新建、删除或修改。

| 触发来源 | 触发节点 | 流水类型 | 变动方向 |
| ---- | ---- | ---- | ---- |
| 入库单提交 | 入库明细入账 | 入库流水 | 增加（+） |
| 揽货 APP 完成发货 | 系统自动生成出库单 | 出库流水 | 减少（-） |
| WEB 端手动出库单提交 | 出库明细扣减 | 出库流水 | 减少（-） |
| 库存调整单提交 | 调整明细入账 | 调整流水 | 增加（+）或减少（-） |
| 盘点差异确认 | 盘点结果入账 | 盘点流水 | 增加（+）或减少（-） |
| 库存冻结 / 解冻 | 冻结 / 解冻操作执行 | 冻结流水 / 解冻流水 | 冻结（锁定变动，实物不变） |
| 订单锁定库存 | 系统自动锁定 | 锁定流水 | 锁定（+）|
| 订单解锁库存 | 订单取消 / 解锁 | 解锁流水 | 锁定（-）|

> **余额快照说明**：每条流水生成时，系统同步记录变动前该 SKU 在该仓库下的实物库存余额，以及变动后的实物库存余额，形成不可篡改的历史快照。

---

## 4. 功能描述

- 支持在库存中心菜单下进入「出入库流水」页面。
- 支持按仓库、SKU 编码、商品名称、商品分类、流水类型、业务类型、来源单号、操作时间范围进行查询。
- 支持重置查询条件。
- 支持导出当前筛选结果。
- 支持以列表方式展示每条流水的变动信息和余额快照。
- 支持点击「查看详情」查看单条流水的完整信息。
- 支持从库存查询页、库存明细列表页点击「查看流水」下钻进入，并自动带入对应 SKU + 仓库筛选条件。
- 支持从入库单详情、出库单详情中直接跳转至对应流水列表。

## 7. 排序与展示规则

- 列表默认按发生时间倒序展示，最新流水在前。
- 同一 SKU 同一时间点若有多条流水（如入库单含多个 SKU），按流水号正序展示。
- 变动数量列正数（增加）使用绿色文字，负数（减少）使用红色文字，加减符号显式展示。
- 来源单号为可点击的文字链接，点击跳转至对应入库单 / 出库单详情页。
- 变动前库存和变动后库存均为历史快照值，不随当前库存变化而更新。
- 当前筛选条件下无数据时，保留查询条件并展示空态。
- 默认每页展示 20 条，支持切换至 50 条 / 100 条。

## 8. 查看详情

点击「查看详情」后，打开右侧详情抽屉，展示以下内容：

| 信息分组 | 展示字段 |
| ---- | ---- |
| 流水基础信息 | 流水号、发生时间、仓库、库区（若有）、货位（若有）|
| 商品信息 | 商品名称、SKU 编码、规格、单位、条码、所属分类（完整路径，如：日化 > 洗护 > 洗衣液）、批次号、效期（若有）|
| 变动信息 | 流水类型、业务类型、变动方向、变动数量 |
| 余额快照 | 变动前：实物库存 / 锁定库存 / 冻结库存 / 可用库存；变动后：实物库存 / 锁定库存 / 冻结库存 / 可用库存 |
| 来源信息 | 来源单号（链接）、来源单类型、关联订单号（若有）|
| 操作信息 | 操作人、操作时间、备注 |

## 9. 关键规则

- 流水记录由系统在库存变动发生时自动生成，**不支持人工新建、编辑或删除**。
- 列表展示**变动前库存**（实物）、**变动后库存**（实物）、**变动前可用**和**变动后可用**四列；详情抽屉余额快照同步展示实物 / 锁定 / 冻结 / 可用完整四项。
- 余额快照为当次变动瞬间的历史值，与当前库存汇总页数据无需实时一致。
- 锁定流水、解锁流水、冻结流水、解冻流水不影响实物库存余额，但会体现在余额快照的锁定 / 冻结字段中。
- 来源单号必须关联到实际入库单 / 出库单 / 调整单，系统自动触发的流水来源单号指向对应业务单。
- 同一来源单号可对应多条流水（一张入库单含多个 SKU，每个 SKU 独立生成一条流水）。
- 查询时间范围最大为 90 天；如需更长周期数据，通过导出功能获取。
- 导出范围为当前筛选结果，单次导出上限 10,000 条。

---

## 10. 数据口径说明

| 字段 | 口径定义 |
| ---- | ---- |
| 实物库存余额 | 该 SKU 在该仓库下账面实际存在的库存总量（含锁定和冻结）|
| 锁定库存余额 | 已被订单或作业任务锁定、尚未出库的库存数量 |
| 冻结库存余额 | 因质检、异常、禁售等原因冻结、不可调用的库存数量 |
| 可用库存余额 | 实物库存 − 锁定库存 − 冻结库存 |
| 变动数量 | 本次事件引起的实物库存净增减数量（锁定 / 冻结类流水此字段为 0，变化体现在快照的锁定 / 冻结字段）|

## 11. 状态规则

| 状态名称 | 状态说明 | 页面表现 |
| ---- | ---- | ---- |
| 正常 | 存在流水数据 | 展示查询区、流水列表、分页与详情能力 |
| 空态 | 当前筛选无结果 | 展示空态文案，保留查询条件 |
| 无权限 | 用户无库存中心权限 | 展示无权限提示，不显示列表 |
| 时间范围过大 | 查询范围超过 90 天 | 提示用户缩短时间范围或使用导出 |

# 库区管理简易需求

## 1. 基本信息

- 功能名称：库区管理
- 所属系统：WMS\_WEB端
- 页面编号：`WMS-WEB-W02`
- 所属模块：仓储管理
- 当前口径来源：`00原型方案/02WEB端HTML版/01WMS_WEB端高保真原型.html`

## 2. 业务目标

维护仓库下的库区主数据，支持库区查询、查看、新建、编辑、启停及通道结构配置，作为货位、上下架策略、波次拣选、盘点分区等业务的库区基础资料来源。

## 3. 功能范围

- 列表查询
- 列表展示与分页
- 新建库区
- 编辑库区
- 查看库区详情
- 启用/停用库区
- 库区下辖通道维护
- 导出

不包含：批量导入、批量启停、库区合并/拆分、库区可视化拓扑图、三方实时同步校验。

## 4. 查询条件

| 字段名称 | 字段类型  | 查询方式 | 说明                          |

## 8. 关键规则

- 列表默认按"所属仓库 + 排序"升序展示，分页区展示总条数、页码、上一页、下一页。
- 翻页后保留当前查询条件。
- 当前筛选结果为空时，展示空态提示。
- 页面初始查询条件中"状态"默认选中"启用"。
- 点击"新建库区"打开新建抽屉；点击"查看/编辑"打开对应模式抽屉。
- 新建/编辑抽屉中"所属仓库"在编辑模式下默认不可修改，避免造成库区下挂数据归属错乱。
- 同一仓库下"库区名称"和"库区编码"均不可重复。
- 下辖通道支持新增/删除行，行内编辑；保存时若通道名称重复，提示错误并定位到第一条冲突行。
- 点击抽屉右上角关闭、取消、遮罩空白处时关闭抽屉；点击抽屉内部非关闭区域不应误关闭。
- 点击"保存"时校验必填字段，保存成功后关闭抽屉并刷新列表。
- 点击"启用/停用"时弹出居中确认框，确认后切换状态。
- 库区被停用后，其下辖货位的可用性由货位侧规则继续控制，本页面不级联修改。

## 9. 状态规则

| 状态 | 含义        | 规则                            |
| -- | --------- | ----------------------------- |
| 启用 | 库区可参与业务   | 可在货位、上架、拣选、盘点等业务中被引用          |
| 停用 | 库区不可参与新业务 | 默认不出现在新增可选范围内，历史数据保留，已有任务可继续完成 |

## 10. 验收要点

- 能按所属仓库、库区类型、库区编码/名称、状态完成查询
- 能打开新建、查看、编辑抽屉
- 能正常关闭抽屉，不出现误关闭
- 同仓库下库区编码、库区名称均唯一
- 下辖通道支持多行新增、删除、行内编辑，重复名称给出提示
- 库区属性中"库存自动精确更新""只允许一单一位"可独立勾选并保存
- 点击保存后抽屉关闭并刷新列表
- 点击启用/停用后弹出确认框
- 分页区展示总条数、勾选数、页码切换

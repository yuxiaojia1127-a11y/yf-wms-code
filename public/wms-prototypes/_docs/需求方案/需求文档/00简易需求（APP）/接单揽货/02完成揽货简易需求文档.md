# 仓库APP-我的任务·完成揽货简易需求文档

> 版本范围说明：本文档覆盖揽货员在「我的任务」中执行揽货作业的全流程，包括查看揽货商品、扫码揽货、标记退差价/换货/退货、整单揽货标记、完成揽货。不涉及接单前流程（见 [00接单揽货简易需求文档.md](./00接单揽货简易需求文档.md)），也不涉及实际退差价资金操作及换货物流流程。

| 项目 | 内容 |
| ---- | ---- |
| 功能名称 | 完成揽货 |
| 所属模块 | 仓库APP > 揽货 > 我的任务 |
| 页面定位 | 揽货员接单后，在任务详情中完成商品拣货、异常标记与揽货提交 |
| 页面编码 | `WMS-APP-002` |
| 适用端 | 仓库APP（揽货配送端） |

## 2. 业务说明

揽货员完成接单后，任务进入「我的任务」列表，状态为「已接单」。点击「去揽货」进入揽货详情页，按揽货指令中的商品清单完成实物拣货。

拣货结果分三类：

- **正常完成**：扫码或手动确认数量完成，系统标记「完成」。
- **退差价**：商品实物与下单时存在差异（如重量不符、规格变化），标记后消费者后续收到差价退款（本期仅标记，不触发实际退款）。
- **换货 / 退货**：商品缺货或损坏，揽货员扫码新商品作为换货品，或标记退货。
- **整单揽货标记**（即采即销仓专属）：若当前库房为即采即销仓，揽货员在完成整单拣货确认无误后可点击「标记为整单揽货」，前置仓随即收到揽货指令可提前开始接单，无需等待即采即销仓真正完成出库确认。

---

## 3. 功能描述

- 在「我的任务」列表点击「去揽货」，进入揽货详情页。
- 揽货详情页顶部展示：订单状态（待接单→已接单→揽货中）、任务ID、订单号、配送信息、库房、收货人、揽货单编号与分张信息。
- 揽货商品区展示当前揽货单的商品清单，包含货位、条码、商品信息、数量。
- 支持扫条码自动累加揽货数量；满足目标数量后自动标记「完成」。
- 支持手动点击「完成」按钮标记该商品拣货完成。
- 支持标记「退差价」（仅标记，不触发退款流程）。
- 支持标记「退货」（仅标记，不触发退款流程）。
- 支持标记「换货」，并通过扫码添加换货商品（换货商品可多种、数量不限，由工作人员自行判断）。
- 若当前揽货指令所属库房类型为即采即销仓，展示「标记为整单揽货」按钮；点击后前置仓揽货任务提前释放至待接单池。
- 所有商品处理完毕后，点击底部「完成揽货」提交结果。
- 完成揽货时若订单已被拦截，提示「订单已拦截，无法继续揽货，请前往拦截订单处理任务」，并禁止提交。
- 底部操作栏包含：「任务指派」（次按钮）、扫码（中央图标按钮）、「完成揽货」（主按钮）。

## 4. 揽货详情页结构

### 4.1 头部信息

与接单详情页共用骨架，新增字段：

| 字段 | 说明 |
| ---- | ---- |
| 页面状态标题 | 已接单 / 揽货中（接单后跳转过来默认「已接单」，首次扫码/操作后变「揽货中」） |
| 揽货单标识 | 「揽货#N ｜ 第N/共N张揽货单」，多张揽货单时展示；「第N」蓝色强调 |
| 整单揽货标记按钮 | 仅即采即销仓类型库房显示，默认浮于商品清单右上角 |

### 4.2 揽货商品列表字段

| 字段名称 | 字段类型 | 是否必填 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 温区 + 货位编码 | 标签文本 | 是 | 常温区 A01-01-1 | 商品存放区域与货位，辅助定位 |
| 条码 | 文本 | 是 | 5748754666 | 商品主条码，用于扫码识别 |
| 商品图片 | 图片 | 否 | — | 辅助识别，约 52-60px |
| 商品名称 | 文本 | 是 | 郁美净鲜奶浴后乳液220g… | 超两行省略 |
| 商品规格 | 文本 | 否 | 10斤/有机/礼盒装 ｜ 0.5KG | SKU 规格描述 |
| 售价 | 金额 | 是 | RM145.00 | 橙红色强调 |
| 成本价 | 金额 | 是 | RM30.00 | 常规颜色 |
| 商品数量（目标） | 数值 | 是 | x3 | 需要揽货的数量 |
| 揽货数量步进 | 步进控件 | 是 | − 1 + | 当前已揽货数量，可手动调整；退货数量同列展示「退货: N」 |

## 5. 商品操作状态

每条商品行支持四种操作，同一商品一次揽货只能处于一种主状态（完成/退差价/退货/换货互斥，选择时切换）：

| 操作 | 触发方式 | 状态表现 | 说明 |
| ---- | ---- | ---- | ---- |
| 完成 | 扫码自动累加满 / 点击「完成」按钮 | 按钮变主色选中态 | 拣货完成，数量满足要求 |
| 退差价 | 点击「退差价」按钮 | 按钮变主色选中态 | 仅标记，不触发实际退款；须由后续流程处理 |
| 退货 | 点击「退货」按钮 | 按钮变主色选中态；揽货数量步进显示「退货: N」 | 仅标记退货数量，不触发退款；退货数量可调整 |
| 换货 | 点击「换货」按钮 | 按钮变主色选中态；出现换货商品扫码区 | 扫码添加换货商品（可多种不限数量），由工作人员判断 |

> 切换状态时，前一状态取消；换货商品区在换货状态下可见，其他状态隐藏。

### 5.1 换货商品区

- 点击「换货」后在商品行下方展开换货区域。
- 已扫码的换货商品展示：条码、商品图、商品名、数量步进、删除入口。
- 底部有「扫码换货商品」触发扫码，或点击中央扫码按钮进入扫码模式。
- 换货商品来自本仓库实物，可多种、数量不限。
- 如换货商品原商品没有揽货标记，展示提示「原商品没有揽货标记了」（橙色小字）。

## 6. 整单揽货标记

| 项目 | 说明 |
| ---- | ---- |
| 展示条件 | 当前揽货指令的库房类型为**即采即销仓** |
| 入口位置 | 揽货商品区右上角「标记为整单揽货」按钮（橙色标签样式） |
| 触发效果 | 前置仓揽货任务从「等待」状态提前释放至待接单池，前置仓揽货员可立即看到并接单 |
| 业务目的 | 即采即销仓拣货完成无缺货/退换，确认可整单履约，提前通知前置仓并行准备 |
| 操作确认 | 点击后弹窗确认：「确认标记为整单揽货后，前置仓将提前收到揽货任务，请确认当前揽货无缺货」 |
| 标记后状态 | 按钮变为「已标记整单揽货」禁用态（灰色），不可取消 |

## 7. 底部操作栏

| 按钮 | 样式 | 触发逻辑 |
| ---- | ---- | ---- |
| 任务指派 | 次按钮（左侧） | 将任务指派给其他揽货员（本期入口预留，功能另行输出） |
| 扫码 | 中央黑底圆形图标按钮 | 唤起扫码，扫到条码自动匹配商品并累加揽货数量；若扫到换货商品时添加为换货商品 |
| 完成揽货 | 主按钮（右侧，主色胶囊） | 提交当前揽货结果；触发订单拦截校验 |

## 8. 完成揽货校验与提交

| 场景 | 系统表现 |
| ---- | ---- |
| 订单正常 | 提交成功，任务状态变为「已揽货」，返回「我的任务」列表 |
| 订单已拦截 | 禁止提交，弹窗提示：「订单已拦截，无法继续揽货，请前往拦截订单处理任务」 |
| 存在未处理商品 | 弹窗提醒「还有 N 件商品未完成揽货标记，确认提交？」，可强制提交 |

## 9. 任务状态流转

| 状态 | 触发条件 | 说明 |
| ---- | ---- | ---- |
| 已接单 | 完成接单操作 | 进入我的任务列表 |
| 揽货中 | 首次扫码或标记任意商品 | 状态升级，表示作业已开始 |
| 已揽货 | 点击「完成揽货」提交成功 | 揽货完成，进入待打包复核流程 |
| 揽货失败 | 提交时订单已拦截 | 不可继续，需前往拦截订单模块处理 |

状态流转：`已接单` → （首次操作） → `揽货中` → （完成揽货） → `已揽货` → 待打包复核

> **多张揽货单合单规则**：同一订单若拆分为多张揽货单，各张独立完成揽货后，系统在打包复核环节将多张揽货单合并为一个打包任务，统一进行打包复核。揽货员只需完成本张揽货单，无需等待其他揽货单，合单由打包复核模块负责。

## 10. 关键业务规则

1. **扫码自动完成**：扫码累计揽货数量达到目标数量时，该商品自动标记「完成」，无需手动点击。
2. **退差价仅标记**：本期退差价功能只做标记，不触发实际退款流程，退款由后续客服/财务流程处理。
3. **换货灵活多品**：换货商品可扫多种不同 SKU，不限数量，由揽货员现场判断可替换商品。
4. **整单揽货标记不可撤销**：一旦标记，前置仓任务即释放，按钮变禁用，不可反向操作。
5. **多张揽货单独立作业**：同一订单拆分为多张揽货单时，每张独立作业，互不干扰；当前揽货单完成后，其他揽货单状态不受影响。
6. **拦截订单优先**：完成揽货提交时实时校验订单拦截状态，拦截态禁止提交并强提示处理入口。

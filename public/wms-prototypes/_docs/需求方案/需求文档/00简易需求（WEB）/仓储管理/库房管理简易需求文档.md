# 库房管理简易需求文档

**版本**：v1.0  
**日期**：2026-06-09  
**模块**：WMS-WEB / WMS-APP

---

## 一、背景与目标

当前系统已有【仓库管理】模块，管理实体仓库信息。  
新增【库房管理】模块，作为仓库的下一级逻辑单元，用于订单履约作业。

**层级关系：**

```
实体仓库（仓库）
└── 库房 A（履约库房）
└── 库房 B（履约库房）
└── 库房 C（履约库房）
```

- **仓库**：对应物理实体仓库，是管理和权限的顶层单位
- **库房**：仓库下辖的作业单元，负责实际订单履约

---

## 二、功能需求

### 2.1 库房基础信息管理

| 字段 | 说明 | 必填 |
|------|------|------|
| 库房编码 | 系统唯一标识，自动生成或手动填写 | 是 |
| 库房名称 | 库房显示名称 | 是 |
| 所属仓库 | 关联上级仓库 | 是 |
| 库房类型 | 如：常温库、冷藏库、危化品库等 | 否 |
| 库房状态 | 启用 / 停用 | 是 |
| 面积（㎡） | 库房物理面积 | 否 |
| 备注 | 补充说明 | 否 |

### 2.2 库房列表

- 支持按所属仓库筛选
- 支持按库房名称、编码搜索
- 展示：库房编码、名称、所属仓库、类型、状态
- 操作：新增、编辑、启用/停用、删除（软删除）

### 2.3 库房新增 / 编辑

- 所属仓库为必选项（下拉，来源：当前用户有权限的仓库列表）
- 同一仓库下库房编码不可重复
- 停用的库房不可作为履约库房使用

## 三、系统改造要点

### 3.1 全局单据补充仓库+库房字段

WMS-WEB 所有单据（入库单、出库单、调拨单、盘点单等）需增加：

- **仓库**（原有字段，确认已存在）
- **库房**（新增字段，关联所属仓库下的库房列表）

库房选项需根据已选仓库动态联动过滤。

### 3.2 WEB / APP 框架选仓逻辑

**现有逻辑（仓库层）：**  
用户登录后选择实体仓库 → 进入仓内作业

**新增逻辑（库房层）：**  
选择实体仓库后 → 在具体作业节点选择对应库房（如：出库作业选择从哪个库房出货）

> 注：是否在登录/切换仓库时同步选择库房，还是在具体单据/作业中选库房，待业务确认。

### 3.3 用户权限（记录要点，暂不展开）

- 工作人员对仓库的访问权限由用户权限模块控制
- 后续可考虑扩展库房级别的权限控制

---

## 四、业务流程说明

```
工作人员登录
    ↓
选择实体仓库（有权限的仓库列表）
    ↓
进入仓内作业（入库 / 出库 / 盘点 / 调拨 等）
    ↓
选择具体库房（该仓库下的启用状态库房）
    ↓
执行作业，单据记录仓库 + 库房信息
```

## 五、待确认事项（已确认）

| # | 问题 | 结论 | 影响模块 |
|---|------|------|---------|
| 1 | APP 端是否需要切换库房的交互入口，还是单据内选择？ | **不需要**，由单据任务指派决定，APP 无需独立切换库房入口 | WMS-APP |
| 2 | 库房是否需要绑定货位（库位）层级？ | **需要**，现有货位管理功能绑定至库房 | 库房管理、货位管理 |
| 3 | 调拨单跨库房调拨时，仓库字段如何处理？ | **仓库+库房均需选择**，源/目标各自独立选择仓库和库房 | 调拨单 |
| 4 | 历史单据数据迁移：是否需要补填库房字段？ | **需要更新**，演示原型阶段历史单据补填库房字段 | 数据迁移 |
| 5 | 库房停用后，关联的在途/未完结单据如何处理？ | **继续执行**，停用不影响已有在途/未完结单据 | 业务规则 |

## 六、确认结论带出的改造影响

### 6.1 货位管理绑定库房
- 货位（库位）层级调整为：仓库 → 库房 → 货位
- 货位管理页面新增"所属库房"字段（联动所属仓库）
- 相关单据中的货位选择，需在选定库房后进行联动过滤

### 6.2 调拨单字段扩展
调拨单需支持跨库房调拨，字段结构调整为：

| 字段 | 说明 |
|------|------|
| 源仓库 | 调出实体仓库 |
| 源库房 | 调出库房（联动源仓库） |
| 目标仓库 | 调入实体仓库 |
| 目标库房 | 调入库房（联动目标仓库） |

### 6.3 APP 端库房逻辑
- APP 无独立选库房入口
- 库房信息通过任务指派带入，工作人员按任务执行，无需手动切换库房

### 6.4 历史数据迁移
- 演示原型阶段：历史单据统一补填库房字段（可设默认库房或手动补录）
- 建议每个仓库至少配置一个默认库房用于历史数据回填

### 6.5 库房停用规则
- 停用库房不影响已创建的在途/未完结单据，继续正常执行
- 停用后该库房不再出现在新建单据的库房选项中

## 七、前端 UI 规范

### 7.1 导航方式

| 操作 | 打开方式 |
| --- | --- |
| 点击库房编码 / 查看详情 | 右侧滑入抽屉（宽度 500px），不离开列表页 |
| 点击新建库房 | 右侧滑入抽屉（新建模式） |
| 查看抽屉内点击"去编辑" | 抽屉内切换为编辑模式，不跳转页面 |
| 保存 / 取消成功后 | 关闭抽屉，列表数据原地刷新 |
| 货位数量链接点击 | 路由跳转至货位管理页，自动带入库房筛选条件 |

### 7.2 列表页布局

- 筛选区 + 可折叠数据总览卡片 + 表格三段式垂直排列
- 数据总览卡片横排 4 个（库房总数 / 启用库房 / 停用库房 / 货位总数），点击卡片可联动筛选对应状态
- 表格行悬停背景变浅，操作列固定右侧（sticky），操作按钮按库房状态动态显示"停用"或"启用"
- 空状态（筛选无结果）：居中提示文案 + 清空筛选引导

### 7.3 抽屉（查看 / 新建 / 编辑）

- 从右侧滑入，宽度 500px，遮罩层不遮挡左侧导航
- **三种模式共用同一抽屉组件**，通过模式参数切换渲染：
  - 查看模式：全字段只读 info 展示，底部显示"关闭 + 去编辑"
  - 新建模式：空表单，底部显示"取消 + 保存"
  - 编辑模式：预填表单，底部显示"取消 + 保存"
- 字段分组：基础信息 / 空间信息 / 关联信息（仅查看模式展示）
- 仓库下拉选择后，库房编码前缀自动更新（新建时）
- 有未保存修改时点击关闭 / 取消 / 遮罩，弹出"放弃编辑"二次确认 Modal

### 7.4 状态 Badge 颜色

| 状态 / 类型 | 背景色 | 文字颜色 | 说明 |
| --- | --- | --- | --- |
| 启用 | `#F6FFED` | `#00ab95`（主题色） | 绿色，库房可参与履约 |
| 停用 | `#FFF2F0` | `#FF4D4F` | 红色，库房不可用于新建单据 |
| 常温库 / 其他 | `rgba(29,29,31,0.05)` | `rgba(29,29,31,0.72)` | 默认灰色标签 |
| 冷藏库 / 冷冻库 | `rgba(37,99,235,0.10)` | `#1d4ed8` | 蓝色标签 |
| 危化品库 | `rgba(199,124,17,0.12)` | `#c77c11` | 黄色警示标签 |

### 7.5 操作反馈

| 操作 | 反馈方式 | 说明 |
| --- | --- | --- |
| 新建保存成功 | 右上角 Toast（绿色，3 秒自动消失） | "库房创建成功" |
| 编辑保存成功 | 右上角 Toast（绿色，3 秒自动消失） | "库房信息已更新" |
| 停用成功 | 右上角 Toast（绿色，3 秒自动消失） | "库房已停用" |
| 启用成功 | 右上角 Toast（绿色，3 秒自动消失） | "库房已启用" |
| 导出触发 | 右上角 Toast（蓝色，3 秒自动消失） | "正在导出，请稍候…" |
| 导出完成 | 右上角 Toast（绿色，3 秒）+ 浏览器下载 | "导出完成" |
| 保存失败（校验） | 字段内联红色边框 + 下方错误文案 | 禁止使用 alert 弹窗 |
| 保存失败（接口） | 右上角 Toast（红色，5 秒自动消失） | "保存失败，请稍后重试" |
| 停用二次确认 | 居中 Modal 弹窗 | 含"停用后在途单据不受影响"说明文案，操作按钮：取消 / 确认停用 |
| 放弃编辑确认 | 居中 Modal 弹窗 | 操作按钮：继续编辑 / 放弃 |

# 仓库APP-发货中英文命名规范

> 更新日期：2026-06-13
>
> 本文档用于统一仓库 APP「发货 / 发货管理 / 订单处理」相关页面的中英文命名。适用范围包括工作台发货卡片、发货列表页（待发货 / 已发货 / 已完成）、发货订单详情页、订单处理弹窗、按钮、状态、字段与筛选项。
>
> **口径决定**：模块名统一使用「**发货 / Shipping**」。当前截图中工作台卡片译为 Delivery、列表页译为 Shipping，二者不一致，统一收敛为 **Shipping**（与中文「发货」对应，避免与「配送 Delivery」混淆）。「配送 / Delivery」仅用于发货之后的物流履约状态（配送中 / 已送达）。
>
> 共享字段（仓库 / 配送方式 / 邮编 / 商品缺货时 / 订单备注 / 用户预约时间等）沿用 [`../接单揽货/04接单揽货中英文命名规范.md`](../接单揽货/04接单揽货中英文命名规范.md) 与 [`../打包复核/02打包复核中英文命名规范.md`](../打包复核/02打包复核中英文命名规范.md) 已确立的口径，保持三模块一致。

## 1. 命名原则

| 原则 | 说明 |
| ---- | ---- |
| 发货统一译为 Shipping | 模块、列表页、状态、动作统一用 Ship / Shipping。工作台不再用 Delivery 作模块名。 |
| 发货 vs 配送分层 | 「发货 Shipping」= 仓库把包裹交给物流/骑手的动作；「配送 Delivery」= 已发货后的物流履约（配送中 In Transit / 已送达 Delivered）。两者不可混用。 |
| 状态避免裸用 Pending | 待发货用 To Ship（短）/ Pending Shipment（完整），不单独写 Pending。 |
| Ship 词形与 Pick / Pack 对齐 | 揽货 Pick（To Pick / Picked），打包 Pack（To Pack / Packed），发货 Ship（To Ship / Shipped），形成自然对照。 |
| 沿用揽货/打包共享字段 | Warehouse 不用 Depot；Delivery Method 不用 Delivery；Scheduled Delivery Time 不用 Reserve Time；Carrier Shipping 不用 Logistics / Standard Ship；Postcode 不用 Postal Code / Zip Code；商品数量标签用 Qty；商品缺货时用 Stockout Handling；订单备注用 Order Note。 |
| 短标签优先短英文，详情可用完整英文 | 工作台与 Tab 用 To Ship；详情页、文档可用 Pending Shipment。 |
| 合单发货语义用 Together | 「统一发货」强调把多张订单合并为一次发货，用 Ship Together，而非 Ship All（后者像"全部发货"）。 |

| 中文 | 推荐英文 | 使用位置 | 备注 |
| ---- | ---- | ---- | ---- |
| 发货 | Shipping | 工作台模块卡片、一级功能模块 | 模块名；当前截图工作台为 Delivery，需改为 Shipping。 |
| 发货管理（列表页） | Shipping | 发货列表页标题 | 与揽货侧 Picking Tasks / 打包侧 Packing Tasks 同层；发货以订单为单位，保留 Shipping 即可，不强制加 Tasks。 |

```text

```

## 9. 不推荐用词

| 不推荐英文 | 推荐替代 | 原因 |
| ---- | ---- | ---- |
| Delivery（作模块名） | Shipping | 模块是「发货」，Delivery 留给配送履约状态。 |
| To Dispatch / Pending（待发货） | To Ship | 与 Ship/Shipping、Pick/Pack 对齐，避免裸 Pending。 |
| Standard Ship / Logistics | Carrier Shipping | 跨模块已确认统一。 |
| Ship All | Ship Together | 合单发货语义。 |
| Delivery（字段名） | Delivery Method | 「配送方式」不能只写 Delivery。 |
| Reserve Time | Scheduled Delivery Time | 沿用揽货/打包规范。 |
| Postal Code / Postal | Postcode | 马来语境统一。 |
| Out of Stock | Stockout Handling | 字段是缺货处理方式。 |
| Remark | Order Note | 沿用规范。 |
| Order By | Ordered By | 语法修正。 |
| Items / Quantity（商品数量标签） | Qty | 与揽货/打包统一。 |
| 未翻译中文（当日配送 / 尽快送达 / 订单处理弹窗整体） | 见第 4.4、第 6 节 | 英文界面需完整翻译。 |

### 10.4 已确认口径

- 模块名：发货 = **Shipping**（工作台 Delivery → Shipping）
- 待发货 = **To Ship**（To Dispatch / Pending → To Ship）
- 物流发货 = **Carrier Shipping**（Standard Ship / Logistics → Carrier Shipping）
- 统一发货 = **Ship Together**（Ship All → Ship Together）
- 配送方式 = **Delivery Method**；用户预约时间/送达时间选择 = **Scheduled Delivery Time**
- 邮编 = **Postcode**；商品数量标签 = **Qty**（件数用 pcs）
- 商品缺货时 = **Stockout Handling**；订单备注 = **Order Note**；下单用户 = **Ordered By**
- 订单处理弹窗英文界面需整体翻译（见第 6 节）

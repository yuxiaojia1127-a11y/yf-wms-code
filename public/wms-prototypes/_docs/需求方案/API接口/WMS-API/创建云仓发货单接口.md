# 创建云仓发货单接口

## 1. 接口定义

| 项目 | 说明 |
| --- | --- |
| API 名称 | 创建云仓发货单 |
| 方法 | `POST` |
| 路径 | `/openapi/v1/shipments` |
| 调用方 | OMS / 第三方电商系统 |
| 幂等键 | `owner_id + channel_id + external_order_no` |
| 优先级 | P0 |

本接口用于把上游待履约订单提交给 WMS，由 WMS 按渠道、履约规则、拆单规则、仓路由和配路由创建发货履约单。

菜鸟云仓下游映射：

| WMS 处理 | 菜鸟能力 |
| --- | --- |
| 创建云仓发货单 | `CAINIAO_GL_WH_EXTERNAL_ORDER_ACCEPT` |
| 需要先拆包/拆单时 | `CAINIAO_GL_WH_EXTERNAL_ORDER_SPLIT` |

## 2. 请求头

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | OpenAPI 访问令牌 |
| `X-Request-Id` | 是 | 请求追踪号 |
| `X-Idempotency-Key` | 建议 | 客户端幂等号；未传时使用接口幂等键 |

## 3. 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `channel_id` | 是 | 渠道标识，如 `easy_supermarket`、`third_party_platform` |
| `business_type` | 是 | 业务类型：`self_operated`、`merchant` |
| `owner_id` | 是 | 货主 ID |
| `store_id` | 是 | 履约店铺 ID |
| `external_order_no` | 是 | 上游订单号 |
| `delivery_mode_required` | 是 | 运输要求：`instant`、`express`、`pickup` |
| `service_level` | 建议 | 时效服务：`2h`、`same_day`、`next_day`、`standard` |
| `split_mode` | 是 | 拆单模式：`by_sku`、`by_sku_qty` |
| `split_delivery_allowed` | 是 | 是否允许分仓履约 |
| `warehouse_route_mode` | 是 | 仓路由：`merchant_assign`、`wms_assign` |
| `delivery_route_mode` | 是 | 配路由：`merchant_assign`、`wms_assign` |
| `preferred_warehouse_id` | 条件必填 | `warehouse_route_mode=merchant_assign` 时必填 |
| `preferred_delivery_mode` | 条件必填 | `delivery_route_mode=merchant_assign` 时必填 |
| `preferred_logistics_code` | 否 | 指定物流商编码 |
| `allow_delivery_adjust` | 是 | 是否允许 WMS 改配 |
| `failure_strategy` | 是 | 失败处理：`reject`、`manual_review` |
| `receiver_info` | 是 | 收货信息 |
| `order_lines` | 是 | 发货商品行 |
| `remark` | 否 | 备注 |

`receiver_info`：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 收货人 |
| `mobile` | 是 | 手机号 |
| `country_code` | 是 | 国家编码 |
| `province` | 是 | 省/州 |
| `city` | 是 | 城市 |
| `district` | 否 | 区县 |
| `detail_address` | 是 | 详细地址 |
| `postal_code` | 否 | 邮编 |

`order_lines`：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `order_line_no` | 是 | 上游订单行号 |
| `sku_code` | 是 | WMS SKU 编码 |
| `quantity` | 是 | 发货数量 |
| `unit_price` | 否 | 商品单价，清关或计费需要时传入 |
| `currency` | 否 | 单价币种 |

## 5. 响应字段

| 字段 | 说明 |
| --- | --- |
| `success` | 是否受理成功 |
| `shipment_order_id` | WMS 发货主单号 |
| `parent_order_id` | WMS 关联的上游订单标识 |
| `external_order_no` | 上游订单号 |
| `fulfillment_rule_code` | 命中的履约规则 |
| `status` | `accepted`、`manual_review`、`rejected` |
| `shipment_orders` | 拆分后的履约子单 |
| `error_code` | 失败码 |
| `error_message` | 失败说明 |

`shipment_orders`：

| 字段 | 说明 |
| --- | --- |
| `shipment_order_id` | 履约子单号 |
| `warehouse_id` | 实际履约仓 |
| `delivery_mode` | 实际配送方式 |
| `logistics_code` | 实际物流商编码 |
| `order_line_refs` | 子单承接的订单行和数量 |

## 7. 处理规则

| 规则 | 处理 |
| --- | --- |
| 商家指定仓 + 商家指定配 | 固定指定仓和指定配，校验库存、配送能力后接单 |
| 商家指定仓 + 云仓路由配 | 固定指定仓，WMS 计算配送方式和物流商 |
| 云仓路由仓 + 云仓路由配 | WMS 按仓网、库存、地址、时效和规则选仓选配 |
| `split_mode=by_sku` | 同一商品行不按数量拆分 |
| `split_mode=by_sku_qty` | 同一 SKU 可按数量拆入多个履约子单 |

## 8. 主要错误码

| 错误码 | 说明 |
| --- | --- |
| `SHIPMENT_DUPLICATE_ORDER` | 重复创建同一上游订单 |
| `SHIPMENT_WAREHOUSE_REQUIRED` | 商家指定仓时未传指定仓 |
| `SHIPMENT_DELIVERY_REQUIRED` | 商家指定配时未传配送要求 |
| `SHIPMENT_SPLIT_NOT_ALLOWED` | 库存或路由需要拆单，但当前请求不允许 |
| `SHIPMENT_OUT_OF_STOCK` | 规则范围内库存不足 |
| `SHIPMENT_ROUTE_NOT_FOUND` | 未找到可执行仓配路由 |
| `SHIPMENT_CAINIAO_REJECTED` | 菜鸟云仓下游拒单 |

## 9. 菜鸟字段映射摘要

| WMS 字段 | 菜鸟字段 |
| --- | --- |
| `external_order_no` | `orderInfo.outOrderId` |
| 实际云仓编码 | `orderInfo.warehouseCode` |
| 实际解决方案/配送方案 | `orderInfo.shippingMethod` |
| `channel_id` | `orderInfo.orderSource` |
| SKU 映射后的云仓货品 ID | `orderInfo.parcel.itemList[].scItemId` |
| `order_lines[].quantity` | `orderInfo.parcel.itemList[].quantity` |
